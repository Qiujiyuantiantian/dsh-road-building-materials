# ch5-steel-fiber — 钢纤维混凝土：砂率是"基体砂率 + 纤维修正"

**卡头必读（六句，顺序不许换）**

1. **钢纤维路线的弯拉部分与路面同式。** 标准值另有一张表，配制均值的算法、水灰比的算法都与路面共用；差别在"用哪个强度符号代进去"。
2. **砂率不是查出来的，是加出来的。** 基体砂率再加一个与体积率成正比的修正项；修正后还要落在一个区间里。

5. **`ρ_f` 在本章出现三种所指。** 粉煤灰密度（kg/m³）、钢纤维体积率（%）、钢纤维密度（kg/m³）；后两种只隔一页，而且同时活在"定砂率"与"求砂石"这两步里。
6. **表 5-40 不能当判据表用。** 掺量有一列重复，另有一列的应力值与正文的方向相反；只能取正文那句门槛。

## R — 原文论点（转述，非摘录）

钢纤维混凝土是在基体混凝土里撒进乱向短纤维。纤维不参与"浆包石"的级配，它要的是更多砂浆把它裹住，所以这一节的所有修正都指向同一个方向：浆要多、砂要粗一点、石子要小一点。

路线本身还是路面的那一套：先由交通等级取弯拉标准值（表 5-41 给四档），再用与路面同一个统计式算出配制均值（只把强度符号换掉），再由弯拉式算基体水灰比（分母里仍是水泥实测抗折），再与耐久性表取小。到这里都与路面一致。

分歧从体积率开始。体积率有一个区间，取值方向由三个条件决定：板厚折减系数小的时候取上限；长径比大的时候取小值；纤维有锚固的时候取小值。三条都是"宜"，没有一条给出"小到什么程度算小"。所以这一节只能要求"声明取哪一端"，不能替人取。

用水量另有一张表，四个基点（长径比、体积率、坍落度、砂细度模数）同时成立才能直接取；不成立就按四条台阶叠：长径比每变十、体积率每变半个百分点、坍落度每变十毫米、细度模数每变零点一，各对应一个用水量增减。台阶的叠加顺序书里没定。

砂率是加出来的：基体砂率加上十倍的体积率（体积率以百分数计），结果宜落在一个区间内。另有一张砂率表可以直接查，但那张表的基点与用水量表的基点不是同一套（体积率高了一倍、水灰比也不同），台阶的步长也不一样。

最后砂石用六项体积法：水泥、纤维、水、砂、石，再加含气量。纤维那一项是"纤维用量除以纤维密度"——**这里的密度符号与上一步体积率的符号是同一个字母**。同一页的两步，一个当百分数用、一个当 kg/m³ 用。

### I.0 符号纪律（本卡最需要改写的一处）

### I.1 路线七步（与路面的同与不同）

| 步 | 动作 | 与路面相同吗 | 断在哪 |
|---|---|---|---|
| ① | 弯拉标准值 | **不同**：另有表 5-41，四档 | 档界按交通等级，与表 5-31 同构不同值 |
| ② | 配制弯拉均值 | **相同**：同一个统计式，换符号 | 统计参数仍要查表 |
| ③ | 基体水灰比 | **相同**：弯拉式，分母含水泥实测抗折 | 输出是水灰比，下一步要灰水比 |
| ④ | 与耐久性表取小 | **不同**：另一张表（表 5-42） | 该表掺灰行也缺 32.5 级那一行 |
| ⑤ | 体积率 | **新增** | 三条"宜"方向相反，只能声明取哪端 |
| ⑥ | 用水量 | **新增**：另一张表 + 四条台阶 | 基点必须同时成立，否则逐条叠 |
| ⑦ | 水泥、砂率、砂石 | **部分相同**：砂率多一项修正，砂石多一项纤维 | 水泥取大；砂率加修正后落区间；砂石六项 |

### I.2 两张表不能共用基点（本卡第一号陷阱）

| 项 | 用水量表（表 5-43） | 砂率表（表 5-44） |
|---|---|---|
| 长径比基点 | 五十 | 五十（同） |
| 体积率基点 | 半个百分点 | 一个百分点（**高一倍**） |
| 坍落度基点 | 二十毫米 | 未列（按水灰比给） |
| 细度模数基点 | 二点五 | 三点零（**不同**） |
| 台阶（体积率） | 每半个百分点对应一个用水量增量 | 每零点一个百分点对应一个砂率增量（**步长不同**） |
| 台阶（长径比） | 每十对应一个用水量增量 | 每十对应一个砂率增量（**方向与量级不同**） |

**共用基点的后果**：把用水量表的体积率基点当作砂率表的基点，砂率基准会被整体挪动一个档；把台阶步长混用，修正量会差数倍。两表只能各用各的基点，且必须写明"从哪个基点出发、叠了哪几条台阶、按什么顺序叠"。

### I.3 砂率修正（一个加法，两个约束）

`钢纤维砂率 = 基体砂率 + 十倍体积率`（体积率以百分数计）。

两条约束：
1. **结果宜落在给定区间内**（区间由书给出，属判据值）。
2. **基体砂率本身要先有出处**。书只给了"基体混凝土的砂率"这个名字，没给"按哪张表、按什么自变量取"；本卡要求：基体砂率要么由用户给，要么明确说明沿用哪张建筑口径的砂率表，不许含混。

**量纲检查**：体积率是百分数，十倍之后仍是百分数；若把密度（kg/m³）代进去，加出来的砂率会是四位数。这是本卡最容易发现、也最容易犯的一处（`g14`、`ce-B01`）。

### I.4 `ρ_f` 三义（本轮补登，verified 未单列第三义）

| 出处 | 所指 | 量纲 | 用在哪一步 |
|---|---|---|---|
| p203 | 粉煤灰密度 | kg/m³（千级） | 掺灰的扣减量与超量部分 |
| p218，式 5-48 | 钢纤维体积率 | %（个位数） | 砂率修正项、取值方向 |
| p219，式 5-49 符号说明 | 钢纤维密度 | kg/m³（千级） | 六项体积法里纤维那一项的分母 |

**第三义的风险**：式 5-49 里同时出现"纤维用量除以 `ρ_f`"与别的项，若沿用上一步的体积率，量纲立刻不成立（用量除以百分数）；反过来若把密度代进砂率修正，砂率会跳到四位数。**同一个字母、相邻一页、两种量纲、两个动作。**

### I.5 表 5-40 为什么不能当判据

表里四列的掺量标签有一列重复（同一掺量出现两次，对应的应力却不同），另有一列的纤维承担应力值出现在非最低掺量上，而正文的表述是"掺量越低、要求越高"。两者方向相反，且无法从表反解出正确的列序。

**可用的只有正文那一句**：最低掺量档对应的纤维抗拉强度门槛。其余三列一律不可引（`ce-A16`）。

### I.6 构造边界（四条硬门槛）

1. **氯盐系外加剂禁用。** 为防锈，钢纤维混凝土不得掺氯盐类外加剂。
2. **海水与海砂禁用。** 同样是防锈；这一条比普通混凝土严。
3. **纤维长度与粗集料粒径互相约束。** 纤维最短要能跨过公称最大粒径的三分之一、最长不宜超过两倍；同时粗集料粒径宜为纤维长度的二分之一到三分之二。两条同时成立。
4. **粗集料公称最大粒径另有上限。** 钢纤维混凝土不宜大于十九毫米（属路面口径的加严档）。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】本卡只做判断：用哪张表的基点、体积率取哪一端、砂率修正项的量纲对不对。不出现任何体积率、砂率、用水量、材料用量的数值结果。

**演练一（想直接查用水量）**
输入：一份配比说明写"长径比与体积率都不是表上的基点，按比例内插"。
→ 判：I.2。表给的是四个基点与四条台阶，不是一张连续曲面；"内插"没有依据，只能是"从基点出发逐条叠台阶"。
→ 输出：**退回**，要求写明从哪个基点出发、叠了哪几条、按什么顺序。
→ 不输出：任何用水量。

**演练二（砂率修正项代错量纲）**
输入：一份计算书写"砂率＝基体砂率＋十倍钢纤维密度"。
→ 判：I.0 与 I.4。修正项要的是体积率（百分数），不是密度。
→ 输出：**停**。先问清这个符号指的是哪一个量；改正后再算。
→ 不输出：任何砂率。

**演练三（体积率取哪一端）**
输入：一份配比同时满足"板厚折减系数小"与"纤维有锚固"，问体积率取上限还是取小值。
→ 判：I.1 第⑤步。两条"宜"在这里给出互斥指令，书没有优先级。
→ 输出：**停**，要求声明取哪一端并给出理由；不许两头取中值当"折中"。
→ 不输出：任何体积率。

**演练四（砂率落不进区间）**
输入：一份配比按修正公式算出的砂率落在给定区间之外，问能不能就用这个值。
→ 判：I.3 第一条。区间是判据，不是参考；落不进去要回去调基体砂率或体积率，不是改区间。
→ 输出：**退回**，调整后重算；调整过程要写出来。
→ 不输出：任何砂率。

**演练五（掺了氯盐外加剂）**
输入：一份钢纤维混凝土配比用了含氯盐的早强剂，理由是"冬天施工"。
→ 判：I.6 第一条。氯盐系外加剂在钢纤维混凝土里是禁用项，不因施工季节开口子。
→ 输出：**停**，换外加剂品种。
→ 不输出：任何替代掺量。

**预期输出表**：`诉求｜第几步｜用哪张表的基点｜叠了哪几条台阶｜体积率取哪端｜ρ_f 指哪一个量｜砂率落在区间内没有｜停／退回｜依据页`

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 交通等级（取弯拉标准值） | 枚举 | 必需 | 缺 → 停（表 5-41 的列就是它） |
| 公路技术等级与抗冻要求 | 二元组 | 必需 | 缺 → 停（表 5-42 的格就是它） |
| 水泥实测抗折 | 数值 | 必需 | 缺 → 水灰比式不可代 |
| 纤维品种、长径比、有无锚固 | 三元组 | 必需 | 缺 → 台阶与取值方向都定不了 |
| 体积率（或声明取哪一端） | 数值 + 枚举 | 必需 | 缺 → 砂率修正项算不出 |
| 板厚折减系数 | 数值 | 条件必需 | 缺 → 取值方向的第一条判不了 |
| 砂的细度模数 | 数值 | 必需 | 缺 → 用水量表与砂率表都无基点 |
| 坍落度要求 | 数值 | 必需 | 缺 → 用水量表基点不成立 |
| 粗集料品种与公称最大粒径 | 二元组 | 必需 | 超十九毫米 → 停 |
| 是否掺掺合料 | 布尔 | 条件必需 | 是 → 表 5-42 的掺灰行可能缺格 |

**步骤**

1. **取标准值**：表 5-41，按交通等级。
2. **算配制均值**：与路面同一个统计式，换强度符号。
3. **算基体水灰比**：弯拉式，分母含水泥实测抗折；与表 5-42 取小。
4. **定体积率**：先声明取哪一端（I.1 第⑤步），再落值。
5. **算用水量**：先验四个基点是否同时成立；不成立则从基点出发逐条叠台阶，并写明叠加顺序。
6. **算水泥**：水灰比与用水量定出后，与表 5-42 最小用量取大，并落在常用区间内、不超过上限。
7. **算砂率**：基体砂率 + 十倍体积率，检查是否落在区间内（I.3）。
8. **解砂石**：六项体积法（水泥、纤维、水、砂、石、含气）；**纤维那一项的分母是密度**。
9. **落声明**：三条必备声明（H2）。

**停判点**（命中任一条即停，不再往后走）

1. **把用水量表的基点当作砂率表的基点** → 停：两张表基点不同、台阶步长不同（`ce-B33`）。
2. **砂率修正项代进密度而不是体积率** → 停：量纲立刻不成立（`g14`、`ce-B01`）。
3. **体积率的三个"宜"给出互斥指令而不声明取哪一端** → 停：书没有优先级（`p16`）。
4. **用水量内插而不是叠台阶** → 停：表只给基点与台阶（`ce-B32`）。
5. **基体砂率没有出处** → 停：书只给了名字，没给入口（`g12`）。
6. **砂率落不进给定区间还照用** → 停：区间是判据（`p17`）。
7. **用氯盐系外加剂、海水或海砂** → 停：三条都是禁令（`ce-B42`）。
8. **纤维长度与粗集料粒径只满足一条** → 停：两条要同时成立（`ce-B43`）。
9. **拿表 5-40 的应力列反解掺量** → 停：该表列序不可反解（`ce-A16`）。
10. **把 `f_cf` 当成实测弯拉** → 停：本卡用的是配制均值（`ce-B02`）。

**输出契约**——字段固定：

`交通等级｜弯拉标准值来源｜配制均值口径｜基体水灰比（与哪张表取小）｜体积率（取哪端）｜用水量（基点 + 叠了哪几条）｜水泥（取大）｜砂率（基体值出处 + 修正项量纲）｜砂石（六项）｜停判点｜依据页`

表下固定三行：

- **公式状态**：式 5-41／5-42／5-48／5-49／5-50〔公式待核〕；`ρ_f` 三义见 I.4。
- **数值状态**：表 5-39 至 5-44 数值〔数值待核原图〕；砂率修正示例为本轮复算。
- **依据页**：p216（表 5-40 与纤维尺寸）、p217（标准值与禁令）、p218（耐久性表与用水量表）、p219（砂率式与体积法）。

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **拿路面那套用水量与砂率直接套。** 钢纤维多两项修正，砂率基准整体上移。
2. **两张表共用基点。** 体积率基点差一倍、细度模数基点不同。
3. **把 `ρ_f` 当同一个量用。** 三义，两种量纲。
4. **用表 5-40 反解掺量。** 列序不可反解。
5. **同时满足两条互斥的"宜"却取中值。** 中值不是书里的选项。
6. **用氯盐系外加剂、海水、海砂。** 三条禁令。
7. **把钢纤维混凝土的弯拉值与普通路面的弯拉值直接比大小。** 基体不同、标准值表不同。

### H2 — 用前必须声明

1. 体积率取哪一端，以及依据哪一条"宜"。
2. 用水量从哪个基点出发、叠了哪几条台阶、按什么顺序。
3. 砂率修正项的符号所指（体积率），以及基体砂率的出处。
4. 纤维那一项的分母是密度（kg/m³），不是体积率。
5. 与耐久性表取小时用的是水灰比还是水胶比（掺灰时不同）。

### 本章缺口对本卡的影响

| 缺口 | 对本卡 |
|---|---|
| 表 5-40 列序不可反解（`ce-A16`） | 只能取正文那一句门槛 |
| 两张表基点不同（`ce-B32`、`ce-B33`） | 每次用表都要写明基点 |
| `ρ_f` 三义（`g14` + 本轮补登） | 每处都要先问量纲 |
| 基体砂率无取值入口（`g12`） | 必须由用户给或显式沿用某张表 |
| 体积率三条"宜"互斥（`p16`） | 只能声明取端，不能取唯一值 |
| 表 5-42 掺灰行缺 32.5 级 | 掺灰时的耐久性校核可能无值 |

**不要用本卡做的事**：给一组钢纤维配合比、给体积率的唯一值、给用水量的内插值、给表 5-40 的列序、给氯盐外加剂的替代方案、给海砂的淡化处理方案。

**已知硬伤（备查）**：表 5-40 掺量重复与方向相反（`ce-A16`）；两张表基点不同（`ce-B32`、`ce-B33`）；`ρ_f` 三义（`g14`）；`β_p` 无入口（`g12`）；`f_cf` 两义（`ce-B02`）；纤维长度与粒径双约束（`ce-B43`）。
