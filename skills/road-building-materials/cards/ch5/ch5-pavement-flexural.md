## R — 原文论点（转述，非摘录）

路面这一节换了控制指标。建筑混凝土看立方体抗压，路面看 28 d 弯拉；只有浇筑后九十天内不开放交通时，才允许用九十天的弯拉值。设计弯拉标准值按概率分布的零点八五分位取，四个交通等级各一档，特重交通的特殊路段经论证可再抬一档（抬的那一档写在表注里，不进表体）。

由标准值到配制均值要过一次统计换算：标准值除以一个与变异系数有关的折减项，再加上保证率系数与样本标准差的乘积。这一步的两个统计参数各有自己的表：保证率系数按公路等级与样本数查，变异系数按变异水平查区间后取代表值。**两个都是"查"，不是"算"**——变异系数不能自己用标准差除均值去凑。

水灰比走弯拉经验式：分母里既有配制弯拉均值，也有水泥实测抗折强度。算完必须与耐久性表的最大水灰比取小。砂率不看水灰比，看砂的细度模数——这是与建筑口径最大的差别；但那张表有四条适用条件（水灰比区间、使用外加剂、级配良好、卵石十九与碎石三十一点五），四条同时成立才可查。

单位用水量走经验式：式子是坍落度、砂率与灰水比的线性组合，**末项是灰水比**。算完与表 5-32（滑模摊铺）或表 5-33（其余三种摊铺方式）的最大用水量取小。水泥用量＝用水量×灰水比，再与最小水泥用量取大。砂石仍用建筑那套两个约束联立。最后加一道独立校核：粗集料填充体积率不宜小于七成。

例题 5-4 把这条链走了六步加一道验算。它的算术在中间几步是对的（砂石那一步复算到小数后一位都对），错在三个地方：第四步把一个"灰水比"的位置代进了"水灰比"；第六步的末行与第五步不同源；验算那一步的商与它自己写的被除数、除数都不合。加上材料栏用了四十毫米碎石（全链的查表口径都是三十一点五），一共四处。

**允许出现的数只有三类**：

2. **表号、式号、页号**——表 5-35、式 5-44、p213。
3. **诊断区的证伪数**——见 I.4，每个都带一句"只作证伪"。

### I.1 七步骨架（每步只写"查哪张表的哪一列 / 与谁取小 / 与谁取大"）

| 步 | 动作 | 取数入口 | 判据形态 | 停了会怎样 |
|---|---|---|---|---|
| ① | 设计弯拉标准值 | 表 5-31，按交通等级定列；表注另有特重特殊路段一档 | 按等级取定值 | 等级没定 → 全链无起点 |
| ② | 配制弯拉均值 | 式 5-41；保证率系数查表 5-36（公路等级×样本数），变异系数查表 5-37（变异水平→区间→代表值） | 两个统计参数都必须"查"，不许自算 | 参数来源混用 → 均值不可比 |
| ③ | 水灰比 | 式 5-42（碎石）／5-43（卵石），分母含水泥实测抗折；再与表 5-35 的最大水灰比取小 | 取小 | 漏取小 → 耐久性闸门失守 |
| ④ | 砂率 | 表 5-38，**按细度模数**；四条适用条件同时成立才可查 | 按模数查区间 | 条件不成立仍查 → 砂率无依据 |
| ⑤ | 单位用水量 | 式 5-44／5-45（末项是灰水比）；再与表 5-32／5-33 上限取小 | 取小 | 代错倒数 → 用水量系统性偏小 |
| ⑥ | 水泥用量 | 式 5-47＝用水量×灰水比；再与表 5-35 最小用量取大 | 取大 | 用错倒数 → 差一个平方量级 |
| ⑦ | 砂石 + 填充体积率 | 式 5-29 两约束联立；再按粗集料振实密度算填充体积率，与下限比 | 联立 + 独立校核 | 不自行复算 → 抄到一个跨题的数 |

### I.2 每步的"口径钉子"（这七句是本卡的承重部分）

1. **①的档界在表里，抬档的话在表注里。** 表体四个值，表注一句"经论证可抬一档"；引用时不许把表注并进表体当成第五档。
2. **②的两个参数是两种"查"。** 保证率系数按"公路等级 × 样本数"查；变异系数按"变异水平"查到一个区间再取代表值。前者是离散的几格，后者是一个区间——**取区间中值这件事必须写出来**。
3. **③的式子里，水泥抗折是"实测值"而不是"等级值"。** 没有实测抗折就没有这一式的入口；等级值不能代。
4. **④不按水灰比。** 建筑口径的砂率表按水灰比与粒径分档，路面这张按细度模数——两张表自变量都不同，互查必错。
5. **⑤的式子末项是灰水比，不是水灰比。** 代入前先把倒数算出来；这是全章第一号符号陷阱，也是例题唯一的硬错。
6. **⑥与③之间必须翻转一次。** ③输出水灰比，⑥要灰水比；例题在③转了一次、在⑥用对了，但在⑤没转。
7. **⑦是独立校核，不是砂率的替代。** 它与砂率各管一头：砂率管砂石比例，填充体积率管粗骨架是否够密。

### I.3 三张耐久性表的分工（不得互查）

| 表 | 服务哪条路线 | 分档维度 | 已知缺格 |
|---|---|---|---|
| 表 5-35（p211） | 路面普通混凝土 | 公路等级 × 抗冻要求 × 水泥强度等级 | "掺粉煤灰·有抗冰(盐)冻·32.5 级"整行不存在（缺三个值） |
| 表 5-42（p218） | 钢纤维混凝土 | 同上 | "掺粉煤灰·有抗冻·32.5 级"整行不存在 |
| 表 5-47（p221–p222） | 碾压混凝土 | **只有二级与三、四级，没有高速与一级** | 高速公路无格可查；掺灰有抗冻那一行方向与同表其余行相反 |

**这三张表长得像，是本章最容易"看错表"的地方。** 同一个公路等级、同一个抗冻要求、同一个水泥等级，三张表给出的上限不同，因为它们服务的路线不同。互查的后果不是误差，是取错闸门。

### I.4 诊断区（只作证伪，不作设计值）

**证据一：符号代入与"取小"规则的冲突。**
式 5-44 的末项在符号说明里明写是灰水比。例题第④步代进去的是水灰比。把倒数按定义代回去，算出的用水量会超过表 5-32 给碎石混凝土的上限；按书自己在 p213 写的"计算值与表值取小"，就必须改取上限，于是水泥用量＝灰水比×上限，与书印的水泥用量差四十余千克。**这条链的每一个数都换掉。** 所以这不是舍入，是规则写了、例题没执行（`ce-A01`）。

**证据二：同一行内的除法不成立。**
例题验算那一行写的是"填充体积＝碎石用量除以振实密度"，被除数与除数都是它自己给的，而商与书印值差两个多百分点。把书印的那个百分数反乘回去，得到的被除数恰好是**上一个例题**的碎石用量。跨题抄数，一步除法即证（`ce-A03`）。

**证据三：两个用水量并存。**
正文第五步用的是一个用水量，末行"初步配合比"里是另一个；末行水泥与用水量之比恰好等于灰水比，而灰水比乘末行用水量恰好等于末行水泥。**末行是"用水量取大了两公斤"那一版的产物**，与第五步不同源。两版差两公斤水、五公斤水泥，不是任何四舍五入关系（`ce-A02`）。

**三条证据的共同点**：都不需要"我会不会算路面配合比"，只需要"同一本书的两处能不能对上"。所以读者可以断定**书上的算例是错的**，而不是自己算不出来。

**第四条（口径级）**：材料栏的粒径与全链查表口径不一致。粒径上限、砂率表的适用条件、含气量表的分行，三处都指向三十一点五；只有材料栏写四十。式 5-44 里没有粒径项，所以用水量不受影响，但砂率与含气量当场取不到（`ce-A04`、`p13`）。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】本卡是判据卡，演练的任务不是算，是**指认**：给一份任务书或一份报告，指出它下一步该查哪张表、哪两步要取小、哪一步必须停。全程不出现任何强度、水灰比、用水量、砂率的数值结果。

**演练一（任务书缺一项，链就起不来）**
输入：一份任务书给了交通等级、摊铺方式、水泥品种与实测抗折、砂的细度模数、集料表观密度与振实密度，但没给样本数与强度变异水平。
→ 判：I.1 第②步的两个统计参数一个按公路等级与样本数查、一个按变异水平查；缺其中任何一个，"标准值→均值"这一跳就没有桥。
→ 输出：**停**。先补样本数与变异水平；补齐后按 I.1 第②步走。
→ 不输出：任何配制均值。

**演练二（报告拿抗压式算路面）**
输入：一份路面配合比报告，水灰比一栏写着"按强度公式计算"，附的式子里出现两个回归系数与水泥抗压值。
→ 判：H1 第一条与 I.1 第③步。路面走弯拉式，分母里应当是配制弯拉均值与水泥实测抗折，不该出现抗压回归系数。
→ 输出：**退回**。指出它用错了路线，并给出应当走的式子与两个入口。
→ 不输出：任何"正确的水灰比"。

**演练三（要引"书上的路面算例"）**
输入：对方说"就按书上那个高速公路的例子，砂石比例照抄"。
→ 判：I.0 封存清单与 I.4 三条证据。该例题的砂石那一步虽然算对了，但它建立在错的水灰比与用水量之上，砂石比例是错链的产物。
→ 输出：**停**。只许引它的流程，不许引它的数；并把三条证伪路径给对方。
→ 不输出：任何取自该例题的数。

**演练四（填充体积率"看起来过了"）**
输入：一份报告写"填充体积率满足不小于七成的要求"，但没给振实密度，也没给算式。
→ 判：I.1 第⑦步与 I.2 第七句。这一项是独立校核，必须自己用粗集料用量除以振实密度算一遍；抄结论等于没校核。
→ 输出：**退回**，要求补振实密度与算式；复算后再判过不过。
→ 不输出：任何填充体积率的百分数。

**演练五（掺灰的路面配比）**
输入：一份路面配比掺了粉煤灰，问取代率能不能按"钢筋混凝土那一档"取。
→ 判：I.3 与越界规则。路面有自己的一套取代率限值，比建筑那一套严；两套并存而书未说谁优先。
→ 输出：**停**，先声明用哪一套，再谈数值；本卡不替它选。
→ 不输出：任何取代率。

**预期输出表**：`诉求｜第几步｜该查哪张表哪一列｜取小还是取大｜条件是否成立｜停／退回／降级｜依据页`

**步骤**

1. **定入口**：按交通等级取设计弯拉标准值；确认是否落在"九十天龄期"的例外里。
2. **过统计桥**：按公路等级与样本数取保证率系数、按变异水平取变异系数代表值（**写明取区间哪一点**），代式 5-41。
3. **算水灰比并取小**：按集料品种选式 5-42 或 5-43，分母用水泥实测抗折；结果与表 5-35 上限取小。
4. **取砂率**：先验表 5-38 的四条适用条件，四条全成立才查；按细度模数定位。
5. **算用水量并取小**：式 5-44／5-45，**末项代灰水比**；结果与表 5-32／5-33 上限取小。
6. **算水泥并取大**：用水量×灰水比；与表 5-35 最小用量取大。
7. **解砂石**：与建筑同一方程组；解完**自己**算一遍填充体积率，与下限比。
8. **落声明**：本卡的全部数值都封存；若用户要数，转 K1 的算法并自行承担"例题不可参照"的后果。

**停判点**（命中任一条即停，不再往后走）

1. **粗集料公称最大粒径超出该品种的上限**（按集料品种分三档） → 停。材料栏写四十而全链查表口径是三十一点五时，不许"按四十继续"（`p13`、`ce-A04`）。
2. **表 5-35 落在"掺粉煤灰 · 有抗冰(盐)冻 · 32.5 级"** → 停。该行不存在，相邻两行（不掺灰的、掺灰 42.5 级的）都不可代（`ce-A14`）。
3. **表 5-47 被用于高速公路或一级公路** → 停。该表只有二级与三、四级两列（`ce-A15`）。
4. **式 5-44／5-45 代入前未标明末项是灰水比** → 停。按定义代进去得到的用水量会超过表 5-32 上限，必须改取上限，全链随之重算（`ce-A01`）。
5. **填充体积率照抄、未用"粗集料用量÷振实密度"自行复算** → 停。书印值与该式不合，且那个值可追溯到上一个例题（`ce-A03`）。
6. **同一份报告里出现两个用水量** → 停。先定用哪一版；两版之差不是舍入（`ce-A02`）。
7. **有人以例题 5-4 的四个数为范例** → 停。该组数全面禁引（`ce-A01`～`ce-A04`）。
8. **用式 5-26（抗压回归）算路面，或反过来用式 5-42 算建筑** → 停。两条路线各有一套式，互不通用（`ce-B13`、`ce-B14`）。
9. **表 5-38 的四条适用条件有一条不成立仍查表** → 停。适用域之外查表等于自造砂率（`ce-B25`）。

## B — 边界

### H1 — 硬边界（四条，写死）

1. **不得用式 5-26（带两个抗压回归系数的水灰比式）算路面。** 路面走弯拉式；两式的自变量一个是抗压配制强度、一个是弯拉配制均值加水泥实测抗折（`ce-B13`）。
2. **不得用四十毫米这一档。** 粒径上限按集料品种分三档，砂率表的适用条件与含气量表的分行都只到三十一点五；材料栏写四十即出域（`p13`、`ce-A04`）。
3. **不得引末行那四个数。** 它们是"另一版用水量"的产物，与第五步不同源（`ce-A02`）。
4. **三张耐久性表不得互查。** 普通、钢纤维、碾压各一张，分档维度不同（`ce-B31`）。

### H2 — 用前必须声明

1. 本卡的控制指标是 28 d 弯拉；抗压只作参考，不可反过来当控制指标。
2. 两个统计参数都是查表得来；变异系数取区间哪一点必须写明。
3. 用水量上限的来源要写明是哪一张表（滑模一张、其余摊铺方式一张）。
4. 掺灰时的取代率限值要写明用哪一套（建筑一套、路面一套，两套并存）。
5. 本卡不产出数值；凡引用本卡得出的数值，必须注明"非本卡产出"。
6. 例题 5-4 只可当"流程示意"，不可当"数值范例"；引用它就要同时引用三条证伪路径。
