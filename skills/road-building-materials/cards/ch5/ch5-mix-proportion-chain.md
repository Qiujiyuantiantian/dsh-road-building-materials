## R — 原文论点（转述，非摘录）

这一节回答的是"给一个强度等级和一堆原材料，怎么凑出一方混凝土"。书的答法分五段：先定设计指标，再算初步配合比，再试拌出基准，再拿三个水灰比做强度曲线定设计值，最后按现场含水率折成施工值。读者最容易漏掉的是这五段之间是**串联**的：第二段任何一步取错，后面四段全是白算。

第二段本身是七判。配制强度要把等级抬到均值，抬多少取决于标准差从哪来——有统计资料按同品种同等级二十五组以上算并设下限，没资料查表 5-11 的三档；水灰比按强度式算完必须与表 5-12 的上限取小；单位用水量查表 5-14，表里按粗集料品种与公称最大粒径分列，并给了中砂基准（细砂加、粗砂减）；砂率查表 5-15，按水灰比与粒径分档，坍落度大过六十毫米时每增二十毫米再加一个百分点；水泥用量由水除水灰比得，再与最小用量取大；砂石最后靠两个约束联立——绝对体积和为一、砂率定义——缺一个都解不出两个未知量。

第三、四段的判据是"开关"而不是"修正项"。试拌只许动浆量、不许动水灰比；三个水灰比取基准上下各零点零五，用水量三组不变（这是固定用水量定则在 p171 的用处）；成型后拿灰水比与强度做线，反解出配制强度那一点上的灰水比；最后算表观密度，实测与计算之差不超过百分之二就照用，超过就四项同乘一个系数。

第五段只有三条改动：砂石按含水率增重、水泥不动、拌合水扣掉砂石带入的水。书在这一段的公式与例题的代入口径不一致——公式要干料重，例题代了湿料重，差不到半公斤，但动作做反了。

例题 5-1 把这条链走了二十四行。它逐行都能对，只有两处：一处是试拌后水泥浆加百分之三那一步差 0.006 kg，一处是施工水差 0.38 kg（口径问题）。真正的缺口不在算术，在取数：定灰水比要读图 5-22，图没了；定用水量要查 31.5 mm 档，那一档是空的。

### I.2 七张表的体检（这一节的价值在"能用哪一格"，不在"有哪些格"）

**表 5-11（p190，标准差三档）**：三档的档界是"低于 C20／C20 至 C35／高于 C35"；同一页另有一条"算出来后取下限"的规则，档界是"C20 与 C25／C30 及以上"。两套档界不重合，跨档时取哪个书里没说；表还缺表号。→ 本卡把"用查表还是用下限"写成输入项，由用户声明。

**表 5-12（p190，最大水灰比与最小水泥用量）**：单位印成 kg/cm³，按字面读最小用量会到十的八次方量级；表头八列而"潮湿环境·无冻害"那一行挤进九个格。→ 先按 kg/m³ 读，再把那一行整行右移一格核对。这一条在例题里没暴露，是因为例题只取了"有冻害"那一行。

**表 5-13（p190，回归系数）**：碎石一组、卵石一组，两个系数各两列。表本身干净，风险在下游——这两个系数只服务抗压式，搬去弯拉式必错。

**表 5-14（p191，单位用水量）**：八值列（卵石 10／20／31.5／40，碎石 16／20／31.5／40）× 七行（VB 稠度三行、坍落度四行）。**干硬性三行的 31.5 两列印"—"，共六格**；坍落度四行的 31.5 两列有值。阶段 1.5 的记法是"两列七行全空、缺十四个值"，与本轮逐格核对的结果不符，本卡按源文写六格，并把"那六格是真空还是 OCR 丢格后补的占位"标为待核。→ 无论取哪种记法，结论相同：**干硬性档的 31.5 取不到表值**。

**表 5-15（p191，砂率）**：只有卵石 10／20／40 与碎石 16／20／40 六列，**没有 31.5 列**。这是横向缺口，比表 5-14 的六格更硬：31.5 是路面规定的碎石粒径，而这张表连列都不给。→ 只能自定插值规则，或退回 40 档并在结果里声明；两条都不许静默进行。

### I.3 三道开关（都是二值，不是修正项）

1. **2% 开关**：计算表观密度由四项（掺灰后五项）相加，实测与计算之差不超过计算值的百分之二 → 前面算的就是设计配合比；超过 → 四项（五项）同乘一个系数。例题正好超，所以校正这一步被用上了。
2. **三水灰比开关**：基准上下各零点零五，三组；**用水量三组不变**（固定用水量定则），每组不少于三块、标准养护到 28 d；拿灰水比与强度回归，反解出与配制强度等高的那个灰水比。
3. **施工水开关**：砂石按含水率增重，水泥不变，拌合水＝设计水 −（干砂×砂含水率 + 干石×石含水率）。"干"是这个式子的关键词；代湿料重就把扣水量算多了。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】本章唯一能算到底的例题已经被上一段拆成骨架，下面四段换掉材料与诉求，只输出"走不走得通、停在哪一步、缺什么"，**不出现任何强度、用水量、砂率、含水率的数值结果**。

**演练一（原材料给了一半）**
输入：一份任务书给了强度等级、水泥实测抗压、砂的表观密度与细度模数、碎石的表观密度与振实密度，但粗集料只写了"碎石"、没写公称最大粒径；施工和易性写"干硬性"。
→ 判：I.2 表 5-14 与表 5-15 这两张表的入口都以粒径为自变量，一个缺列、一个缺格。
→ 输出：**停**。先补粒径；若坚持干硬性档，则用水量在三十一点五处无表值，砂率在任何粒径的三十一点五处也无表值。
→ 不输出：任何用水量、任何砂率。

**演练二（要求"给我一条能直接施工的配比"）**
输入：委托方要一组可以直接下发到拌合站的质量比，材料参数齐全，但没给现场砂石含水率。
→ 判：I.1 第五段与 I.3 第三道开关。施工配合比的入口是含水率，缺它只能停在设计配合比。
→ 输出：**降级交付**——给到设计配合比为止，并声明"施工那一栏待含水率实测后另算"。
→ 不输出：任何施工配合比的数、任何"按经验取含水率"的替代。

**演练三（复算别人的报告，卡在取数）**
输入：一份报告声称"由强度—灰水比曲线定出灰水比"，附了三个水灰比与三组强度，但没附曲线图，也没写读数方式。
→ 判：I.4 末段。曲线本身缺失时，替代只能是回归或线插，而两种替代给出的值不同；报告若不给方法，就无法判断它的灰水比是读出来的还是算出来的。
→ 输出：**退回**，要求补"读数方式 + 三个点 + 拟合式"；补齐后按替代法复核，并注明"复核值不等于原图读数"。
→ 不输出：任何"我替你读出来"的灰水比。

**演练四（现场改了含水率）**
输入：设计配合比已定，现场实测砂石含水率各一个值，问要不要动水泥。
→ 判：I.3 第三道开关与 I.5 第一句。水泥不动，砂石增重，拌合水扣**干料**带入水。
→ 输出：**只改三栏**，并在结果里写明"扣的是干料带入水"；若对方给的是湿料重，先换算再扣。
→ 不输出：任何重算后的质量数。

**预期输出表**：`诉求｜段｜缺哪个入口｜落在哪张表哪一列｜是否空档｜停／降级／退回｜依据页`

| 各材料表观密度、粗集料振实密度 | 数值组 | 必需 | 缺 → 体积法／密度法不可解 |
| 施工和易性（坍落度或 VB 稠度，择一） | 数值 | 必需 | 缺 → 停（决定查哪三行） |
| 环境条件与结构物类别 | 二元组 | 必需 | 缺 → 表 5-12 那一行取不到 |
| 标准差来源（统计资料／查表／自定） | 枚举 | 必需 | 未声明 → 停（两套档界不重合） |
| 现场砂石含水率 | 数值对 | 条件必需 | 只算到设计配合比时可不给；要施工值则必需 |
| 假定表观密度取值（仅密度法） | 数值 | 条件必需 | 未给 → 只能走体积法 |

**步骤**

1. **定指标**：按和易性选测法（坍落度／常规 VB／改进 VB／捣实因数），再定配制强度与耐久性双限（I.1 第一段）。
2. **算配制强度**：等级加保证率余量；标准差来源必须已声明（I.2 表 5-11）。
3. **算水灰比并与上限取小**：式 5-26 给计算值，表 5-12 给上限，取小者；注意式内是水灰比。
4. **查用水量**：按品种与粒径定位表 5-14 的列，按流动性定位行；中砂基准，细砂加、粗砂减。
5. **查砂率**：表 5-15 按水灰比与粒径；坍落度大过六十毫米按每二十毫米加一个百分点。
6. **算水泥并与下限取大**：用水量除以水灰比，再与表 5-12 的最小用量比。
7. **解砂石**：绝对体积方程与砂率定义联立；两法（体积法／密度法）互证。
8. **试拌出基准**：小体积试拌，只调浆量、不动水灰比；记录实际加水量。
9. **三个水灰比定设计值**：上下各零点零五、用水量不变、每组不少于三块；回归后反解灰水比（**图缺，必须声明替代法**）。
10. **2% 校正**：算表观密度、与实测比；过则照用，不过则四项同乘系数。
11. **折施工值**：砂石增重、水泥不动、拌合水扣干料带入水（I.3 第三道开关）。
12. **落声明**：三条必备声明（见 H2）。

**停判点**（命中任一条即停，不再往后走）

1. **粗集料公称最大粒径落进 31.5 且拌合物为干硬性** → 停：表 5-14 该格是"—"，不许当零、不许拿 40 列代（`ce-A12`、`ce-B23`）。
2. **要按 31.5 取砂率** → 停：表 5-15 无该列，只能声明插值方式或退回 40 档（`ce-B24`）。
3. **读表 5-12 前没数格** → 停：八列头对九格，先整行右移核对，再按 kg/m³ 读（`ce-A13`）。
4. **标准差来源未声明，或同时引用两套档界** → 停：查表与取下限是两条规则，先声明用哪条（`f04`、`p04`）。
5. **水灰比算完没与表 5-12 上限取小** → 停：这一步是耐久性闸门，不是可选项。
6. **用水量算完没与表 5-15 的砂率调整规则对齐**（坍落度大过六十毫米） → 停：砂率还差一个增量。
7. **要"从图 5-22 读出灰水比"** → 停：图只剩图注；改用回归或线插，并在结果里写明"非原图读数"（`ce-A17`）。
8. **三组试件的用水量被改了** → 停：固定用水量定则是三组可比的前提（`ce-B38`）。
9. **施工水用湿料重去扣** → 停：扣的是干料带入水；例题在这一步与公式相反（`p08`）。
10. **掺灰或掺外加剂后仍直接套表 5-12 的水灰比上限** → 停：表注写的是"替代前"的水灰比与用量，掺灰后要回到掺灰卡的口径（越界，转 K4）。
11. **把本卡的表 5-15 与路面卡的表 5-38 互查** → 停：同义不同源，自变量都不同（`ce-B09`）。

## B — 边界

### B.1 为什么全章只有这一条链能算（唯一性交代）

闭合要同时具备四件，缺一件就掉出去：

1. **入口有真实材料参数，而且参数与判据项一一对得上。** 例题 5-1 把水泥实测抗压、砂石表观密度、细度模数、坍落度、环境条件全给了——本章其余五个例题都缺其中至少一项。
2. **每一步都有式或有表，且式与表的口径互相对齐。** 八个式子全带式号，七张表全带表号；四法、三档、双限都能定位到具体格。
3. **两个未知量由两个约束联立，不是"估一个再校一个"。** 砂石那一步是方程组，不是经验配比。
4. **结论对唯一未写的规则不敏感。** 假定表观密度的取值区间、表 5-15 的插值方式都不影响"这道题能不能走完"，只影响末位。

二十四行里二十二行独立复现，是本卡唯一性的实测支撑。**但它不等于"全链可复现"**：第 16 步的图缺了，第 4 步的 31.5 档缺了，这两处一个靠替代、一个靠绕行，所以本卡的强度是"能算完"，不是"能算准"。

### H1 — 出现下列情形就别用本卡

1. **用式 5-11／5-12 的灰水比形式去替代式 5-26。** 一个是抗压回归、一个是弯拉回归，系数结构不同；搬过去量纲过得去、数值必错。
2. **把本卡的式 5-26 用到路面混凝土上。** 路面走弯拉式，是另一张卡（K2）的地盘。
3. **拿表 5-14 的 31.5 空格当零，或用 40 列的数顶替。** 空格的语义是"无此值"，不是"此值为零"。
4. **拿表 5-15 的 40 列直接当 31.5 用而不声明。** 声明了是"退回 40 档"，没声明就是篡改入口。
5. **用湿料重去扣拌合水。** 扣水式的分子是干料重。
6. **把 2% 开关当修正项**（"差一点也乘一下"）。它是二值：不过就乘，过了就不乘。
7. **三组试件改用水量。** 固定用水量定则一破，三组强度不可比。
8. **在标准差来源未声明时给出配制强度。** 两套档界不重合，跨档取值会直接改变水灰比。
9. **把本卡的 MPa 拿去与砂浆、路面弯拉的 MPa 比大小。** 试件、基体、控制指标都不同（跨卡不可互引）。

### H2 — 用前必须声明

1. 本卡的强度是 28 d、立方体抗压这一套口径；离了这套口径就不是同一个量。
2. 表 5-14 的 31.5 两列在干硬性三行为空、表 5-15 无 31.5 列；凡用到 31.5 的结论都带这一句。
3. 第 16 步的灰水比若用回归或线插替代，必须写明"非原图读数"及所用三点。
4. 表观密度校正一旦触发，四个（掺灰后五个）数全部改变，不许只改水泥。
5. 施工配合比的三栏改动以"现场含水率实测"为前提；未实测只能交付到设计配合比。
6. 结果写成"段 + 取小／取大 + 卡在哪一格"，不许压缩成一个质量比了事。
