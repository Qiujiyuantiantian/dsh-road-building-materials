# ch5-strength-evaluation — 混凝土强度评定：三条互斥的路

> **卡型：判据卡（三条路互斥，选路先于算数）**——本卡不评具体某批混凝土，交付的是"先定走哪条路、再谈代哪条式"。三条路的符号、组数、判据式各不相同；选错一条，合格会被判成不合格。
>
> **主要取材**：p173–p175（强度分布、表 5-2）、p179–p181（三条评定路线、式 5-13 至 5-23、表 5-3、表 5-4）
>
> **挂靠 verified（自有 8 条）**：`f03`、`f15`｜`ce-A19`｜`ce-B04`、`ce-B10`｜`g21`、`g22`、`g23`
>
> **跨卡共用（不计入自有）**：`g01`（`f_cu` 系的七个下标变体，在 K1 展开）、`g08`（变异系数两处同名，在 K2 展开）、`g31`（等级与标号三套写法，在 K1 展开）

**卡头必读（六句，顺序不许换）**

1. **三条路互斥：已知标准差、未知标准差、非统计。** 不是"三种精度"，是三套判据；同一批数据只能走一条。
2. **选路的判据不是式子简繁，是"生产稳不稳 + 组数够不够"。** 前者是定性话，后者是硬数。
3. **两个标准差符号分管两条路。** 一个由批内极差算，一个由组间平方和算；符号不同、算法不同、入口不同。
4. **`t` 与 `P` 必须成对取。** `t` 取整了，`P` 就不能用未取整的那个；书里那句示范正是这么错的。
5. **表 5-2 本身没病。** 十六组对应关系与标准正态分布的最大偏离在千分之一以内；错的是那句话的配套关系。
6. **表 5-3 的空格不是缺值。** 最大组数那一档只用第一个系数，第二个系数在该档不适用。

> **公式**：式 5-1 至 5-7（分布与保证率）、5-13 至 5-23（三条评定路线）〔公式待核〕。
>
> **数值**：表 5-2、5-3、5-4 与各判据系数〔数值待核原图〕，条件为"强度以 MPa 计、标准差以 MPa 计、保证率以小数计、组数为试件组数"。本卡自算的十六组偏差最大值标"本轮复算"。

## R — 原文论点（转述，非摘录）

强度是一个随机量，所以"合格"不能用单块试件说话。书先给分布：均值、标准差、变异系数三个参数，把设计等级写成"均值减去若干倍标准差"的分位值；再给一张表，把无量纲化后的偏离与保证率对应起来。这张表是本章少数几处可以逐格验算的地方。

然后是评定。评定不是"算一个数比一个门槛"，而是先分路：

**路一，已知标准差。** 前提是"较长时间内生产条件一致、同品种强度稳定"——这是定性话，没有量化判据。走这条路的验收批由连续三组试件组成，要同时满足三个不等式：均值、最小值、还有一个"最小值不低于等级的某个百分比"。最后这一条按等级分两档，两个百分比不同。标准差由批内极差累加得到，要求数据批数不少于十五。

**路二，未知标准差。** 前提是生产条件不能长期一致，或者上一个检验期没有足够数据。这条路的验收批不少于十组，两个不等式：均值减去系数乘标准差、最小值不低于系数乘等级。两个系数查同一张表，按组数分三档。标准差由组间平方和算，统计周期内的组数另有一个下限（不少于二十五组），算出来小于一个很小的值时按那个值取。

**路三，非统计。** 不走标准差，直接两个固定百分比：均值不低于等级的一个倍数、最小值不低于等级的另一个倍数。

三条路的差别不在"严不严"，在"用哪种不确定性"。路一用历史标准差，路二用本批离散，路三不承认有足够数据。所以选错路不是精度问题，是判据对象变了。

书中还有一句示范：给定等级、均值、标准差，算出一个无量纲偏离，取了整，再去表里查保证率——查出来的那个保证率对应的是没取整的那个偏离。表是对的，这句话把两个精度混在了一起。

## I — 判据骨架

### I.1 三条路对照（先选路，再代数）

| 项 | 路一 · 已知标准差 | 路二 · 未知标准差 | 路三 · 非统计 |
|---|---|---|---|
| 前提 | 生产条件长期一致、强度稳定 | 条件不能长期一致，或上期数据不足 | 数据不足，不走统计 |
| 验收批组数 | 连续三组 | 不少于十组 | 按验收批实际组数 |
| 标准差来源 | 批内极差累加（式 5-17），数据批数不少于十五 | 组间平方和（式 5-20），统计周期组数不少于二十五 | 不用 |
| 判据个数 | 三个不等式，其中"最小值"一条按等级分两档 | 两个不等式 | 两个不等式 |
| 系数 | 无（直接用标准差） | 两个系数查表，按组数分三档 | 两个固定百分比 |
| 符号 | 一个带零下标的标准差 | 一个大写带下标的标准差 | 无 |

**注意两处"组数"不是一回事**：路二的验收批"不少于十组"与统计周期"不少于二十五组"是两个不同的计数，一个是本批、一个是历史。把它们当成同一个数，是这条路上最常见的错。

### I.2 表 5-3 与那个空格

三个组数档、两个系数。前两档两个系数都有值；**最大组数那一档只有第一个系数，第二个系数是空的**。

这个空的语义是"该档不使用这一条判据"，不是"缺值待补"。理由在路二的两个不等式里：组数越多，最小值那一条的约束方式越不同。**把空格当缺值去补一个数，就是自造判据**（`g23`）。

### I.3 表 5-2 的体检（十六组全对）

十六组无量纲偏离与保证率的对应，与标准正态分布的尾概率逐组比对，最大偏离在千分之一以内（本轮复算）。**表没有病。**

病在那句示范：它把一个偏离取了整，又用未取整那个值对应的保证率。两种取法各有一组配套答案——取了整的偏离配它自己那一档，未取整的偏离配它自己那一档；**二者取一即可，混用则保证率会偏零点七个百分点上下**（`ce-A19`）。

**这一条的意义**：它证明本章的错不都是"表坏了"。有时候表是对的，错的是"读表的习惯"；而这种错最容易被"我又算了一遍表，没错啊"掩盖过去。

### I.4 三个 `t`，三个入口

| 出处 | `t` 是什么 | 怎么得到 | 用来干什么 |
|---|---|---|---|
| 强度分布那一节 | 无量纲偏离 | 由均值、标准差与等级算出 | 查表得保证率 |
| 路面那一节 | 保证率系数 | **直接查表**（按公路等级与样本数） | 算配制均值 |
| 回归那一节 | 统计检验量 | 由回归算出 | 判显著性 |

**三者入口完全不同**：一个是算出来的，一个是查出来的，一个与强度无关。混用的后果不是误差，是"查错了表"（`ce-B04`）。

### I.5 等级、标号、保证率：三套写法不许简称

- **等级**按立方体抗压标准值分十二级，数字是 MPa。
- **抗渗标号**六级，数字是零点一兆帕的级序。
- **抗冻标号**九级，数字是循环次数。

三套数字放在一起时，同一个数字含义完全不同；本章一律要求写全"等级／标号 + 数字"（`g31`）。

### I.6 本卡不做什么

本卡不判"这批混凝土该不该拆"、不给处置方案、不做钻芯或非破损的强度推定、不把本章的评定系数挪到砂浆上去（砂浆那套系数在 K8）。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】本卡只做判断：这批数据该走哪条路、符号有没有串、`t` 与 `P` 有没有成对。不出现任何强度、标准差、保证率的数值结果。

**演练一（生产稳不稳，没人说得清）**
输入：一份评定报告走了"已知标准差"那条路，理由写"我们有历史资料"。
→ 判：I.1 前提栏。"有历史资料"不等于"生产条件长期一致"；后者是定性话，须由委托方确认，且数据批数还有一个下限。
→ 输出：**停**，要求确认前提并核对数据批数；确认不了就走"未知标准差"。
→ 不输出：任何判定结论。

**演练二（两个组数被当成一个）**
输入：一份报告写"验收批不少于十组，统计周期也不少于十组"。
→ 判：I.1 末段。一个是本批、一个是历史，两个下限不同。
→ 输出：**退回**，分别写明两个数。
→ 不输出：任何判定。

**演练三（`t` 取了整，`P` 没取整）**
输入：一份示范算例，偏离取了整，查出来的保证率却对应未取整的值。
→ 判：I.3。两种配套各有一组答案，混用则保证率偏移千分之七上下。
→ 输出：**二选一**——要么两个都取整，要么两个都不取整；并在报告里写明取了哪一种。
→ 不输出：任何保证率。

**演练四（表里的空格被补了数）**
输入：一份报告在最大组数档用了第二个系数，并说"表里空着，我按上一档借的"。
→ 判：I.2。该档不使用这一条判据。
→ 输出：**停**，删掉那一条判据，只用该档适用的那一条。
→ 不输出：任何系数值。

**演练五（把路面的保证率系数搬到建筑评定上）**
输入：一份建筑混凝土评定报告，保证率系数是按公路等级与样本数查来的。
→ 判：I.4。三个 `t` 三个入口；建筑评定这一节的 `t` 是由均值与标准差算出来的。
→ 输出：**退回**，换回本节的入口。
→ 不输出：任何系数。

**预期输出表**：`诉求｜哪条路｜前提确认了没有｜验收批组数｜统计周期组数｜标准差符号｜t 与 P 是否成对｜表里的空格怎么处理｜停／退回｜依据页`

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 强度等级（C 几） | 枚举 | 必需 | 缺 → 停（所有判据都以它为基准） |
| 本批试件组数与每组块数 | 数值对 | 必需 | 缺 → 停（决定走哪条路） |
| 各组强度值 | 数值组 | 必需 | 缺 → 均值与最小值都算不出 |
| 生产是否长期一致（定性确认） | 布尔 | 必需 | 未确认 → 不许走"已知标准差" |
| 历史数据批数（走已知标准差时） | 数值 | 条件必需 | 不足下限 → 停 |
| 统计周期组数（走未知标准差时） | 数值 | 条件必需 | 不足下限 → 停 |
| 强度等级与标号写法 | 枚举 | 必需 | 混写 → 先改成"等级／标号 + 数字" |
| 评定目的（合格判定／质量水平／处置） | 枚举 | 必需 | 要处置 → 转出本卡 |

**步骤**

1. **选路**：先确认前提，再核对组数（I.1）。
2. **定符号**：按路取一个标准差符号，不许两个都用（I.1 表末两行）。
3. **算标准差**：按所选路的算法；注意两个不同的组数下限。
4. **逐条比判据**：路一三条、路二两条、路三两条；"最小值"那一条按等级分档。
5. **查系数**：路二查表，按组数定档；最大档的空格按"不适用"处理（I.2）。
6. **若用分布表**：`t` 与 `P` 成对取，声明取整方式（I.3）。
7. **落结论**：合格／不合格；不合格的处置不属本卡。

**停判点**（命中任一条即停，不再往后走）

1. **前提未确认就走"已知标准差"** → 停：那一栏是定性话，须委托方确认（I.1）。
2. **两个组数下限被当成同一个数** → 停：本批与历史是两个计数（I.1 末段）。
3. **两个标准差符号同时使用** → 停：分管两条路，同一批不能并用（`ce-B10`）。
4. **最大组数档的空格被补了一个数** → 停：该档不使用该条判据（`g23`）。
5. **`t` 取了整而 `P` 用了未取整的值** → 停：两者必须成对（`ce-A19`）。
6. **用路面的保证率系数代本节的值** → 停：三个 `t` 三个入口（`ce-B04`）。
7. **等级与标号混写、或只写数字** → 停：三套写法数字含义不同（`g31`）。
8. **把本卡的评定系数挪到砂浆上** → 停：砂浆那套系数在 K8（`p20`）。

**输出契约**——字段固定：

`哪条路｜前提确认｜本批组数｜历史组数｜标准差符号与算法｜判据条数与分档｜系数（含空格处理）｜t 与 P 的取整方式｜结论｜停判点｜依据页`

表下固定三行：

- **公式状态**：式 5-1 至 5-7、5-13 至 5-23〔公式待核〕。
- **数值状态**：表 5-2／5-3／5-4 与系数〔数值待核原图〕；十六组偏差最大值为本轮复算。
- **依据页**：p173–p175（分布与表 5-2）、p179–p181（三路与两张表）。

**本卡不产出材料数值；若需配合比，回 K1。**

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **不确认生产是否稳定就选路。** 选路先于算数。
2. **两个标准差符号并用。** 两条路各有自己的符号。
3. **给表 5-3 的空格补数。** 那是"不适用"，不是"缺值"。
4. **`t` 与 `P` 一个取整一个不取整。** 保证率会偏零点几个百分点。
5. **把路面的保证率系数拿来用。** 入口不同。
6. **拿单块试件或单组试件下评定结论。** 三条路都要"批"。
7. **用本卡的系数评砂浆。** 砂浆用另一套系数。
8. **把"不合格"当成"低一级"。** 判定与处置是两件事。

### H2 — 用前必须声明

1. 走哪条路，以及前提是怎么确认的。
2. 两个组数（本批／历史）各是多少。
3. 用的标准差符号是哪一个，算法是哪一条式。
4. `t` 与 `P` 的取整方式（都取整或都不取整）。
5. 最大组数档的空格按"不适用"处理，没有补值。
6. 结论只到"合格／不合格"，处置另议。

### 本章缺口对本卡的影响

| 缺口 | 对本卡 |
|---|---|
| 前提是定性话、无量化判据（`f15`） | 选路必须由委托方确认，卡不能替判 |
| 表 5-3 最大档空格（`g23`） | 该档少一条判据，不许补 |
| 那句示范的配套关系错（`ce-A19`） | `t` 与 `P` 成对取，并声明取整方式 |

| 两个标准差符号（`ce-B10`） | 按路取一个 |

**不要用本卡做的事**：给处置方案、做钻芯或非破损推定、评砂浆、把等级与标号互换、给"综合评分"。

**已知硬伤（备查）**：示范句 `t` 与 `P` 不配套（`ce-A19`）；表 5-3 最大档空格（`g23`）；三个 `t`（`ce-B04`）；两个标准差符号（`ce-B10`）。
