# ch5-superplasticizer — 掺减水剂：一个减水率只能兑现一个目标

> **卡型：判据卡（三目标互斥，交付"选哪一个 + 怎么回验"）**——本卡不设计配合比，只回答两件事：同一个减水率能换到哪三种结果、以及换完之后怎样用砂率把标签验回来。例题 5-2 的三个方案数值全对，错在两处砂石标签；本卡把它当"标签反了也能算对"的标本。
>
> **主要取材**：p191（式 5-27、减水率的第一个单位口径）、p204–p205（三个目标与例题 5-2）、p197（图 5-23，只剩图注）、p213（式 5-46、减水率的第二个单位口径）
>
> **挂靠 verified（自有 4 条）**：`f09`、`p09`、`ce-A05`、`g11`
>
> **跨卡共用（不计入自有）**：`g10`（砂率定义，回验就靠它）、`ce-B09`（砂率两套表）、`ce-B39`（坍落度大过六十毫米的砂率增量）、`ce-B05`（两种水灰比写法）、`ce-B27`（掺外加剂后用水量的上限仍受表值约束）

**卡头必读（六句，顺序不许换）**

1. **同一个减水率只能兑现一个目标。** 省水泥、提流动性、提强度，三选一；书用三个并列方案写，是"三条路"，不是"三个步骤"。
2. **三者的差别只在"哪两个量固定"。** 省水泥：水与水泥同降、水灰比不动；提流动：配合比一项不改、坍落度上抬；提强度：水降、水泥不动、水灰比下降。
3. **例题 5-2 的数值十项全对，错在两处砂石标签。** 这正是最难发现的一类错——你复算每一步都对，只有栏名反了。
4. **照抄的后果不是误差，是方向反转。** 砂率是百分之三十二时，砂必然轻于石；照抄那两栏，砂率会被读成百分之六十八。
5. **回验只要一句话：砂石算完，用砂率回头验一遍。** 落不到题面给的那个砂率，就是标签反了；这一条把"建议换标签"变成了"可判定的约束"。
6. **减水率在本章有两个单位口径。** 建筑那一节标百分数，路面那一节写"以小数计"；代入前先声明用哪个，否则差一百倍。

> **公式**：式 5-27（掺外加剂后的用水量）〔公式待核〕；式 5-46 与之同构，只换了单位口径。体积法方程组与砂率定义〔公式待核〕，出处 p192。
>
> **数值**：例题 5-2 的全部数值〔数值待核原图〕，条件为"由例题 5-1 的基准配合比改写、减水剂掺量以水泥质量百分数计、减水率以百分数计、坍落度以 mm 计"。本卡自算的砂石两栏与两个砂率标"本轮复算"。

## R — 原文论点（转述，非摘录）

减水剂在不增加用水量的前提下把拌合物变稀，于是同样稀度下可以少用水。书由这一个物理事实推出三个方案，每个方案固定两个量、放开两个量：

**方案一**：坍落度与强度都不变 → 水按减水率下降，水泥按新水除原水灰比下降，水灰比不动。落到数上就是"省水泥"。
**方案二**：强度不变 → 配合比一项不改，只让坍落度上抬。书在这里不给算式，因为确实没有算式：同一组材料，减水剂掺进去，坍落度自然变大。
**方案三**：坍落度不变 → 水下降、水泥不动，于是水灰比下降、强度上升。

三个方案互斥。书在三个方案之后又补了一句，说掺减水剂也能做到省水泥的同时把强度提上去。那句容易被读成"还有第四条路"；实际它讲的是**两个目标一起动，就得两个量一起改**，已经出了三方案的范围。

例题 5-2 拿例题 5-1 的基准配合比做底，把三个方案各算了一遍。前两步（用水量、水泥用量、减水剂掺量）都按式子走；第四步"按体积法计算砂石"给两个数，方案一给砂一三一零、石六一七，方案三给砂一二九四、石六零九。而题面明写砂率是零点三二。

问题就在这里：砂率三成二意味着砂占总集料的三成二，砂必然轻于石。书给的两栏恰好相反。按体积法复算，方案一是砂六一六点九、石一三一一；方案三是砂六零八点九、石一二九三点九——**四个数与书印值的差都在一公斤上下，只有栏名对调**。

同一段还有一句"强度由三十七点八提高到四十三点五，提高了百分之十一以上"。按两个数算，提高幅度是一成五；"百分之十一以上"字面为真、但把一个可以精确说出的数说成了不等式。

## I — 判据骨架

### I.0 符号与口径（本卡只用五个）

| 书内写法 | 本卡写法 | 断在哪 | 出处 |
|---|---|---|---|
| `β_ad` | 减水率，**先声明是百分数还是小数** | 式 5-27 标百分号，式 5-46 写"以小数计"，同章两口径 | p191、p213 |
| `m_w,ad` | 掺减水剂后的单位用水量 | 与未掺的 `m_w0` 只差一个下标，混淆即把"掺后"当"基准" | p191 |
| `m_c,ad` | 掺减水剂后的水泥用量 | 方案一里它随水降，方案三里它不动 | p205 |
| `W/C` | 水灰比（本卡全程用它，不换灰水比） | 三个方案的差别可以全部用"水灰比动不动"说清 | p190 |
| `β_s` | 砂率，定义是砂除以砂石之和 | 回验的唯一依据；两套取表入口见 `ce-B09`，本卡只用定义 | p171、p192 |

### I.1 三方案对照（固定什么、放开什么、结果是什么）

| 方案 | 固定 | 放开 | 算式动作 | 判据 |
|---|---|---|---|---|
| 一 · 省水泥 | 坍落度、强度（即水灰比） | 水、水泥 | 水×（1−减水率）；水泥＝新水÷原水灰比 | 水灰比必须不变；砂石按体积法重解 |
| 二 · 提流动 | 强度（配合比全不动） | 坍落度 | 无算式 | 只报"坍落度上抬"，不报数 |
| 三 · 提强度 | 坍落度（水降） | 水泥不动、水灰比降 | 水×（1−减水率）；水泥沿用基准值 | 水灰比必须下降 |

**三条互斥的判定法**：看"水泥动不动"。水泥降 → 方案一；水泥不动且水降 → 方案三；水泥与水都不动 → 方案二。三者不可能同时成立。

### I.2 为什么互斥（一句话的逻辑）

省水泥要求水灰比不变，提强度要求水灰比下降，提流动要求水灰比与用水量都不变。三个要求落在同一个减水率上，只能满足一个。书用三个并列小节写，是给人选，不是给人依次做。

### I.3 例题 5-2 的标签检验（本卡的骨干）

| 方案 | 本轮复算砂／石 | 书印砂／石 | 复算砂率 | 照抄后砂率 |
|---|---|---|---|---|
| 一 · 同流动同强度 | 616.9 / 1311.0 | 1310 / 617 | 32.00% | 67.98% |
| 三 · 同流动提强度 | 608.9 / 1293.9 | 1294 / 609 | 32.00% | 68.00% |

四个数与书印值差不超过一点一公斤，**两栏整体对调**。题面砂率零点三二，与复算砂率严格一致；照抄则得到六成八。**二者非此即彼**，所以"标签反了"不是推测，是可判定的结论。

同一段的强度那句：两个强度值之差除以下限，得一成五；书说"百分之十一以上"。数字不算错，但把可精确表述的结果写成了不等式，读者无法据它判断方案三的实际收益。

### I.4 减水剂的三个适用域（取数前先过）

1. **掺量**以水泥质量的百分数计（例题取百分之零点五）。
2. **减水率**由试验确定，不是产品说明书上的标称值；路面那一节另有两个门槛（高效减水剂与引气减水剂各一个下限），属路面口径，本卡不代填。
3. **砂率**：掺外加剂的混凝土，砂率"应经试验确定"（p191 第三条），不许直接查表；坍落度大过六十毫米时，表值每二十毫米加一个百分点——这条是查表路径的补充，掺外加剂路径不走它。

### I.5 本卡与相邻卡的边界

- 减水剂**不改变**耐久性双限（表 5-12 的水灰比上限仍然管着用水量），只是让水更容易达标。
- 减水剂**不改变**水灰比定则的适用域；它只改"在给定水灰比下水用多少"。
- 掺减水剂后又掺粉煤灰，两条改写会叠在一起：先按掺灰卡定取代率，再按本卡定水——顺序反了会互相拆台。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】本卡的演练只做一件事：**判断对方要的是哪一个目标，以及他给的答案有没有做过砂率回验**。不出现任何用水量、水泥用量、砂石用量、砂率的数值结果。

**演练一（三目标被写成三个步骤）**
输入：一份方案说明书写"先按方案一省水泥，再按方案三提强度，两步一起做"。
→ 判：I.1 与 I.2。省水泥要水灰比不变，提强度要水灰比下降，两个要求同时提，等于要求水灰比既不变又下降。
→ 输出：**停**。要求对方选一个目标；若要"又省又强"，那是同时改两个量，不在三方案之内，须另立口径。
→ 不输出：任何"两步合一"的配比。

**演练二（数值全对，栏名反了）**
输入：一份复算报告，砂石两栏给了一对质量，用水量与水泥用量都对，砂率一栏空着。
→ 判：I.3。空着砂率就是没做回验；回验只需一步除法。
→ 输出：**退回**，要求补砂率；若补出来与题面给的不符，先查两栏是否对调，再谈别的。
→ 不输出：任何砂率数值。

**演练三（减水率的单位没说）**
输入：一份报告写"减水率取八"，既没写百分号也没写小数。
→ 判：I.0。两个口径差一百倍；本章两处就是这么写的。
→ 输出：**停**，先声明单位；声明后再代。
→ 不输出：任何掺后用水量。

**演练四（掺了减水剂还想直接查砂率表）**
输入：一份配比说明写"掺减水剂，砂率按表查得"。
→ 判：I.4 第三条。掺外加剂的砂率应经试验确定，不许直接查表。
→ 输出：**退回**，要求给试拌结果或试验依据。
→ 不输出：任何砂率。

**预期输出表**：`诉求｜哪个目标｜固定哪两个量｜水灰比动不动｜砂率回验做了没有｜减水率单位｜停／退回｜依据页`

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 目标（省水泥／提流动／提强度） | 枚举 | 必需 | 缺或给两个 → 停（停判点一） |
| 基准配合比（水、水泥、砂、石、水灰比、砂率） | 六元组 | 必需 | 缺 → 停（三个方案都从它改写） |
| 减水剂品种与掺量 | 二元组 | 必需 | 缺掺量 → 停（掺量以水泥质量百分数计） |
| 减水率（含单位口径） | 数值 + 枚举 | 必需 | 未写百分数或小数 → 停（停判点三） |
| 各材料表观密度 | 数值组 | 必需 | 缺 → 砂石不可重解 |
| 是否同时掺掺合料 | 布尔 | 条件必需 | 是 → 先走掺灰卡，顺序不得颠倒 |
| 坍落度要求 | 数值 | 条件必需 | 方案二必需；其余方案用于校核 |

**步骤**

1. **定目标**：三选一，写清固定哪两个量（I.1）。
2. **统单位**：减水率先声明百分数还是小数（I.0）。
3. **算水**：基准水乘（1−减水率）。
4. **定水泥**：方案一按新水除原水灰比；方案三沿用基准水泥；方案二不动。
5. **算掺量**：水泥用量乘掺量百分数。
6. **重解砂石**：体积法（或密度法）方程组，砂率用**基准砂率**（三个方案都不改砂率定义下的比例关系，只改浆量）。
7. **回验砂率**：用解出的砂石算一遍砂除以砂石之和，必须落回基准砂率；落不到就是标签反了（I.3）。
8. **落声明**：两条必备声明（H2 第 1、4 条）。

**停判点**（命中任一条即停，不再往后走）

1. **同时要两个目标** → 停。三方案互斥；"又省又强"要另立口径（I.2）。
2. **砂石算完没做砂率回验** → 停。回验是唯一能抓出标签对调的步骤（I.3、`ce-A05`）。
3. **减水率的单位没声明** → 停。两个口径差一百倍（`g11`）。
4. **掺外加剂后直接查砂率表** → 停。掺外加剂的砂率应经试验确定（I.4）。
5. **拿掺后的用水量去与表 5-12 的水灰比上限比** → 停。要比的是水灰比，不是用水量；用水量的上限是另一张表（`ce-B27`）。
6. **方案二被要求给一个数** → 停。方案二的结论是"坍落度上抬"，本身不产数（I.1）。
7. **先掺减水剂再按掺灰卡倒推取代率** → 停。顺序必须是先定取代率、再定水（I.5）。
8. **把砂率的两套取表入口混用** → 停。建筑一张、路面一张，自变量不同（`ce-B09`）。

**输出契约**——字段固定：

`目标｜固定哪两个量｜减水率单位｜掺后用水量｜水泥动不动｜掺量｜砂石（用哪法）｜砂率回验结果｜停判点｜依据页`

表下固定三行：

- **公式状态**：式 5-27／5-46〔公式待核〕；方案二无公式，属观察判。
- **数值状态**：例题 5-2 全部数值〔数值待核原图〕；砂石复算与两个砂率为本轮复算。
- **依据页**：p191（式 5-27 与砂率第三条）、p204–p205（三方案与例题）、p213（式 5-46 的单位口径）。

**本卡不产出配合比数值；若需数值，回 K1 的算法并注意砂石栏名。**

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **要一次兑现两个目标。** 三方案互斥，同时要两个就得同时改两个量，那已经不是本卡的范围。
2. **照抄例题 5-2 的砂石两栏。** 会得到六成八的砂率，与题面三成二相反（`ce-A05`）。
3. **把减水率的两个单位口径混用。** 一个百分数一个小数，差一百倍（`g11`）。
4. **用减水剂替代耐久性校核。** 水灰比上限仍然管着。
5. **把方案二的"坍落度上抬"当成一个可以算出的数。** 书在这里没有算式。
6. **在掺减水剂的同时直接查砂率表。** 应经试验确定。
7. **把"提高百分之十一以上"当精确结论引用。** 两个强度值给出的是一成五。

### H2 — 用前必须声明

1. 本卡的基准是例题 5-1 那一套材料与口径；换材料则基准配合比要重算。
2. 三个方案的水灰比走向必须写明（不变／下降／不动），这是判"选了哪个方案"的唯一依据。
3. 砂石两栏的栏名在本书该例题里是反的；引用时必须先回验砂率并注明"已换回"。
4. 减水率的单位必须写明；掺量以水泥质量百分数计。
5. 掺减水剂又掺掺合料时，顺序是"先取代率、后水"。

### 本章缺口对本卡的影响

| 缺口 | 对本卡 |

| 减水率两个单位口径（`g11`） | 每次代入前都要声明 |

| 掺外加剂的砂率须试验确定 | 本卡给不出砂率，只能给"怎么验" |
| 方案二无算式 | 该方案只能定性 |

**不要用本卡做的事**：给三个方案的完整配合比、给砂率、给减水率标称值、给"又省又强"的合成方案、给图 5-23 的读数。

**已知硬伤（备查）**：砂石两栏对调（`ce-A05`）；减水率两口径（`g11`）；"提高百分之十一以上"与两个强度值不符（本轮复算一成五）；砂率两套表（`ce-B09`）。
