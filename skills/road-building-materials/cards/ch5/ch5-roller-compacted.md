6. **改进 VB 与常规 VB 是两台仪器。** 出机读数与碾压时读数也是两个时点；两者都叫 VB，数值不可比。

## R — 原文论点（转述，非摘录）

碾压混凝土是"零坍落度 + 振动碾压成型"，所以和易性的量纲换了：不用坍落度，用改进 VB 值（圆盘上加配重，另读下沉量）。拌合物也从"浆包石"变成"石挤石"，于是控制配合比的不是砂率，而是粗集料能填到多少体积——填充体积率。

简捷法分两支。不掺灰那支七步：由改进 VB 值算用水量、由弯拉强度与水泥实测抗折算水灰比（与耐久性表取小）、由灰水比乘用水量得水泥（与最小用量取大）、按砂细度模数查填充体积率、乘振实密度得粗集料、砂按体积法补足、最后算外加剂。掺灰那支八步：先定粗集料与取代率，再由改进 VB 值、取代率、填充体积率三个参数算用水量，由弯拉强度与三个参数算胶凝材料总量，再拆成水泥与粉煤灰，再算水胶比、砂、外加剂。

正交法是给重大工程用的。定四个因素：用水量、胶凝材料基准量、碎石堆积体积，以及粉煤灰取代率；每个因素三水平、排 L9 九组；逐组按简捷法算配合比、测改进 VB 与压实度与两个龄期的抗折；然后**按每一行实际所处的水平归组**，把同一水平的三个测值相加得 K 值，三个 K 值取极差得 R；R 越大该因素越主要。最后做回归、综合定案，必要时反解用水量。

这套流程的成败全在"归组"两个字。表里有三处会把人带偏：因素水平表只印了第一个水平（后两个水平整列空），配合比表里紧跟代号的"水平取值"数字从第四行起与代号不符，试验结果表有一个压实度印错。三处之中只有最后一处能确定地改对——因为改完之后四列十二个 K 值全部对上，而这种"全对上"不可能是巧合。

## I — 判据骨架

### I.1 三个替代量（碾压不用砂率，用这三个）

| 量 | 管什么 | 入口 | 断在哪 |
|---|---|---|---|
| 改进 VB 值 | 拌合物的干硬程度 | 出机一个读数、碾压时一个读数 | 与常规 VB 不同仪器；两个时点不可混 |
| 粗集料填充体积率 | 粗骨架填到多少 | 按砂细度模数查表 | 表只给四个模数点，中间值无插值规则 |
| 水胶比 | 强度与耐久性 | 由弯拉强度式算、与耐久性表取小 | 掺灰支里胶凝材料是"水泥 + 粉煤灰" |

### I.2 简捷法两支（对照）

| 步 | 不掺灰支 | 掺灰支 |
|---|---|---|
| 1 | 用水量（由改进 VB 值） | 先定粗集料与取代率 |
| 2 | 水灰比（由弯拉强度与实测抗折） | 用水量（由改进 VB 值、取代率、填充体积率） |
| 3 | 水泥（灰水比×用水量） | 胶凝材料总量（由弯拉强度与三个参数） |
| 4 | 填充体积率（查表） | 拆成水泥与粉煤灰 |
| 5 | 粗集料（振实密度×体积率） | 水胶比 |
| 6 | 砂（体积法补足） | 砂（体积法补足） |
| 7 | 外加剂 | 外加剂 |

**两支的共同断点**：式 5-54 给的是水灰比，式 5-55 要的是灰水比，同页相邻两式互为倒数，书没有把这一步显式化（`ce-B19`）。

### I.3 正交法的四步与三处表病

**四步**：定因素水平 → 排 L9 九组并逐组算配合比 → 按实际水平归组算 K 与 R → 排序 + 回归 + 定案。

**三处表病，按"能不能救"排序**：

| 病 | 现象 | 能救吗 | 救法 |
|---|---|---|---|
| 因素水平表丢列（`ce-A09`） | 两个因素只印第一个水平，后两个水平整列空 | 不能按表排 | 只能从配合比表反推三个水平（各出现三次，符合均衡） |
| 配合比表取值错位（`ce-A11`） | 代号列是对的，紧跟代号的数字从第四行起与代号不符 | 能 | **按代号回因素水平表取值**，不读紧邻的数字 |
| 试验结果表一格错（`ce-A08`） | 第 3 号压实度印九十三点四 | **能，且唯一** | 改为九十四点四，见 I.4 |

**两条叠加的死路**：要按代号取值，就得有因素水平表；而因素水平表的水平 2、3 丢了。所以"按代号回表"这条路本身也断——唯一的出路是从配合比表反推水平值，再用反推值去核代号。

### I.4 那一格：九十三点四 → 九十四点四（本卡的确定值）

| 因素 | 用原值复算（K₁／K₂／K₃，R） | 用修正值复算 | 书印 |
|---|---|---|---|
| 用水量 | 280.2 / 289.8 / 283.1，R 9.6 | 281.2 / 289.8 / 283.1，R 8.6 | 281.2 / 289.8 / 283.1，R 8.6 |
| 胶凝材料 | 282.9 / 285.7 / 284.5，R 2.8 | 282.9 / 285.7 / 285.5，R 2.8 | 282.9 / 285.7 / 285.5，R 2.8 |
| 碎石体积 | 284.1 / 283.2 / 285.8，R 2.6 | 284.1 / 283.2 / 286.8，R 3.6 | 284.1 / 283.2 / 286.8，R 3.6 |
| 取代率 | 284.6 / 285.7 / 282.8，R 2.9 | 284.6 / 285.7 / 283.8，R 1.9 | 284.6 / 285.7 / 283.8，R 1.9 |

**三条独立旁证**：

1. **四组差的全是同一个数**：按原值复算，四个 K 各差一点零；它们的公共成员只有第 3 号测点。
2. **九个测点的合计**：原值版八百五十三点一，修正版八百五十四点一；而书印四列中任一列三个 K 之和都是八百五十四点一。**书的 K 表是按修正值算的，错的只是那一格。**
3. **级差与主次**：四个 R 全对之后，三个考核指标的因素主次排序一个都不变。**这说明它错得干净——改一格不动任何设计结论。**

**为什么这一条珍贵**：全章十九处硬断点里，十八条只能"标停"，只有这一条能"改对"，而且改法唯一（四个同时差一点零的组，交集只有一个测点）。

### I.5 三张耐久性表里，碾压这张最缺

表 5-47 只有二级与三、四级两列，**没有高速公路与一级公路**；"掺粉煤灰 · 有抗冻抗盐冻"那一行给出二级与三、四级的两个值，后者反而大于前者——同表其余各行都是等级越低要求越小，唯独这一行反向（`ce-A15`）。两条都不能靠"相邻格代"解决：一条是无格可查，一条是方向可疑。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

**步骤**

1. **选路线**：一般工程走简捷法，重大工程走正交法。
2. **定支**：掺灰与否决定七步还是八步（I.2）。
3. **算用水量**：由改进 VB 值（掺灰支再加取代率与填充体积率）。
4. **算水灰比并取小**：式 5-54 给水灰比，与表 5-47 取小；注意下一步要的是灰水比。
5. **算水泥并取大**：灰水比乘用水量，与表 5-47 最小用量取大。
6. **查填充体积率**：按细度模数查表；中间值必须声明插值方式。
7. **算粗集料**：振实密度乘体积率。
8. **补砂**：体积法。
9. **算外加剂**：掺量以小数计。
10. **正交法另加**：排九组、逐组算、按**代号**归组、算 K 与 R、排序、回归；归组前先核对"每个水平各三次"。
11. **落声明**：三条必备声明（H2）。

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **要砂率。** 这条路线没有这个量；用砂率套碾压，等于把有坍落度的混凝土算法搬到零坍落度上。
2. **照表直读排 L9。** 因素水平表丢了两列。
3. **读紧邻代号的数字。** 从第四行起与代号不符。
4. **把四个 K 的同步偏差当自己的算术错。** 先找公共测点。
