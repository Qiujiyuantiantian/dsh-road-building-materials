# ch4-blend-entry-check — 掺混合材：掺量定品种，四个入口先体检

**这个判据管哪几件事**

1. **掺量落位**：六个代号各自的掺量区间与替代规则，一句话能把一个代号判出来。
2. **四个入口体检**：分母（对比水泥）、口径（龄期与基体）、门槛（单值占列位）、层级（产品标准／施工规范／跨章式）。

- **不给掺量与剂量的换算**：掺多少水泥是为品种，掺多少石灰／水泥到土里是第 6 章。
- **不判强度等级**：那是卡 1。

## R — 原文论点（转述，非摘录）

六个代号不是六个名字，是六个掺量区间。硅酸盐水泥分两型：一型不掺，二型掺不超过百分之五（石灰石，或磨细的粒化高炉矿渣）。普通硅酸盐水泥从百分之六起，到百分之十五止；掺活性料时上限十五，其中允许用不超过百分之五的窑灰、或不超过百分之十的非活性料来顶替；掺非活性料时上限降到百分之十。矿渣水泥从百分之二十到七十，允许用窑灰、石灰、粉煤灰、火山灰质料中的一种顶替，顶替量不超过百分之八，顶完矿渣还不能少于百分之二十。火山灰质水泥从百分之二十到五十，粉煤灰水泥从百分之二十到四十。

然后是四张表：矿渣粉的质量要求、粉煤灰的质量标准、掺混合材水泥的强度标准、掺混合材水泥的技术标准。四张表里最要紧的不是数，是"这个数的分母是谁"。

矿渣粉的活性指数被定义成一个比值：掺矿渣粉那一组的胶砂抗压强度，除以对比组的胶砂抗压强度；流动度比同理。火山灰质料有一个抗压强度比，粉煤灰也有一个。四个比值的分母都写着"硅酸盐水泥胶砂"，可是**用哪一种硅酸盐水泥、哪个等级、哪一批，全书没有规定**。分母不定，比值就不定——这是这一节最贵的一句话。

第二贵的是表 4-9 的排版：密度、比表面积、氯离子、含水量、三氧化硫、烧失量这几个单值，各占一格，而这一格横跨三个级别；读的人若把它当成某一级专有，就会给另外两级也套上同一个数。

第三贵的是表 4-13：十个使用场合、六个品种、五档说法。五档说法里没有一个在本章被定义过；表里还有两格是空的；密度与装填密度那两行，六个品种只给了五个值。

再往后是"其它水泥"：高铝、快硬、膨胀与自应力、白色与彩色。这一节**一张表都没有**——高铝给了四个标号名、白色给了两个标号名，都没有门槛值；快硬与膨胀连标号序列都没有。

最后是表 4-1：题名写的是生料成分，可是四个氧化物的上下限加起来，下限九十个点、上限一百零二个点。生料里还有烧失量，四个氧化物合起来不该是这个量级——这张表只能当熟料级看。

### I.2 四个入口体检（本卡的主表）

| 入口 | 具体是什么 | 本章给了什么 | 缺了会怎样 |
|---|---|---|---|
| **分母** | 四个相对指标的对比水泥（活性指数、流动度比、两个抗压强度比） | 只写"硅酸盐水泥的胶砂" | 分母不定，比值不可引、不可比（`p04`、`ce-A09`、`g12`） |
| **口径** | 龄期与基体：活性指数分 7 d 与 28 d 两套门槛；基体是胶砂 | 龄期给了，基体给了 | 7 d 与等级判定的 3 d／28 d 串用；7 d 全章只在此出现（`p01`） |
| **门槛** | 表 4-9 的六个单值各占一格、横跨三级；表 4-10 分两级 | 值给了 | 把单值当成某一级专有，另两级被误套（`ce-B08`） |
| **层级** | 表 4-1 题名与量级不符；表 4-15 引施工规范；矿渣 K 引第一章 | 题名与引用都在 | 把熟料级当生料级、把施工规范当产品标准、把跨章式当本章式（`p11`、`ce-B30`） |

**四个入口的错法是同一个**：拿一个分母不明、口径不对、或缺门槛的参照物去比。所以体检的顺序不能换——**先查分母，再查口径，再查门槛，最后查层级**。

### I.3 表 4-13：十个场合、五档词、两格空白

- 结构：十个使用场合 × 六个品种（P·I、P·II、P·O、P·S、P·P、P·F），跨 p160–p161 两页，中途"续上表"。
- 五档词共五个：不得使用、不宜使用，往上两档是可以选用与可以使用，最高一档是优先选用。**五个词在本章没有一处定义或排序**（`ce-B07`）。
- 可判的只有两端：**优先选用**（推荐）与**不得使用**（禁止）；**不宜使用**可按字面当"不推荐"用。
- **不可判的**：**可以使用**与**可以选用**并列时，本章裁决不了二者孰优（E02）。
- **两格空白**（登记为干燥环境一行与厚大体积一行各一格）：写"空白，不可判定"，**不许按邻近格推**（E02、`ce-B06`）。
- 另有两行（密度、装填密度）六个品种只给五个值，读时须知道同值格是合并的（`ce-B06`）。

### I.4 表 4-11：掺混合材的六档，与表 4-4 的差

表 4-11（p159）给矿渣、火山灰质、粉煤灰三类水泥共用六档（32.5 起到 52.5R），四行（两龄期 × 两项）。与表 4-4 普通型同档相减：28 d 两项**六档差全为 0**；3 d 抗压逐档 −1.0、−1.0、−1.0、−2.0、−1.0、−3.0；3 d 抗折 0、0、0、0、−0.5、−0.5。

**用途有两个**：一是它替表 4-4 的回填做了独立验收（卡 1 I.2a）；二是它说明"掺了混合材，早龄期让一点、二十八天持平"这条关系在本章是可复算的，不是口号。

### I.5 两个开区间之间的空档

粉煤灰按氧化钙含量分低钙与高钙两档，两个区间都是**开**的，中间那一段**没有归属**。这不是笔误可解释的（`f11`、`ce-B29`）：一处写"低于"，一处写"高于"，中间留了一条带子。**入卡只写"中间带本章无归属"，不替它归入任何一档。**

### I.7 表 4-1 的层级错位

题名说生料，四个氧化物给的是四段范围。把四段的下限相加得 90、上限相加得 102（本轮复算，四个数都取自表内）。生料还要带烧失量（碳酸盐分解跑掉的二氧化碳），四个氧化物不可能占到这个量级；**所以这张表只能当熟料级看**（`p11`、`ce-A07`、`ce-B02`）。引用时若照题名当生料成分，配料的量级会整体错位。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】**本卡为何不产生数值**：这一节的四个相对指标全部分母不明，五个档位词全部无定义，四个"其它品种"全部无门槛。**比值没有分母、档位没有次序、标号没有门槛——三样都没有，就产不出任何数值结论。** 本卡的动作是"在体检表上打勾"，不是算。

**演练一（掺量与代号对不上）**
输入：一份报告写"掺了混合材，属矿渣水泥"，掺量明显低于矿渣水泥的下限，却高于普通水泥的上限。
→ 判：I.1。P·S 的下限在百分之二十；这个掺量既出 P·O 的上限，又不到 P·S 的下限。
→ 输出：**停**。掺量落不到任何代号上，先回去核掺量与品种。
→ 不输出：任何代号、任何掺量值。

**演练二（比值没有分母）**
输入：报告引"活性指数达到某一档"，据此说矿渣粉合格。
→ 判：I.2 第一行。分母是"硅酸盐水泥胶砂"，但用哪种硅酸盐水泥、哪个等级，全章未规定。
→ 输出：**停**。分母不定，这个比值不可引、不可比。
→ 不输出：任何比值、任何"合格"。

**演练三（龄期串用）**
输入：报告拿七天龄期的强度比去判水泥等级。
→ 判：I.2 第二行。七天这个龄期在本章只出现在矿渣粉活性指数里，是比值的龄期；等级门槛在三天与二十八天。
→ 输出：**停**。龄期坐标错。
→ 不输出：任何折合、任何等级。

**演练四（表 4-13 的空白格）**
输入：报告说"干燥环境可以用矿渣水泥"，依据是表 4-13 的相邻格。
→ 判：I.3。那一格是空白，本章不给判定；相邻格也不能外推。
→ 输出：**不可判定**。
→ 不输出：任何"适宜／不适宜"的结论。

**演练五（表 4-1 当生料）**
输入：报告引表 4-1 说"生料里四个氧化物占多少"，据此配料。
→ 判：I.7。四个氧化物的上下限相加越界，这张表只能当熟料级。
→ 输出：**停**。层级错位，配料量级会整体偏。
→ 不输出：任何配比。

**预期输出表**：`诉求｜掺量与代号对不对｜比值有没有分母｜龄期是哪一套｜门槛属哪一级｜层级对不对｜表 4-13 判到哪一端｜停判点｜依据页`。

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 诉求类型（判代号／判相对指标／查使用场合／查标号／审报告） | 枚举 | 必需 | 缺 → 先问；判相对指标 → 直接进停判点 2 |
| 掺量（数值＋"按水泥质量计"是否写明） | 数值＋布尔 | 条件必需 | 未写计量基准 → 停 |
| 代号或品种（P·I 起六个，或四个"其它品种"） | 枚举 | 必需 | 缺 → 先问 |
| 比值的分母（对比水泥写没写） | 枚举（写了／未写） | 条件必需 | 未写 → 停（I.2 第一行） |
| 比值的龄期（7 d／28 d／未写） | 枚举 | 条件必需 | 与等级判定混用 → 停 |
| 表 4-13 的档位词（五选一／空白） | 枚举 | 条件必需 | 空白 → 判"不可判定"；"可以使用"与"可以选用"并列 → 本章不可裁决 |
| 引用表的层级（生料／熟料／产品标准／施工规范） | 枚举 | 必需 | 题名与量级不符 → 停（I.7） |
| 是否要标号门槛 | 布尔 | 条件必需 | 为真且属"其它品种" → 停（I.6） |

**步骤**

1. **先判代号**：按掺量区间落位（I.1）；落不到任何区间 → 停。
2. **体检分母**：凡比值，先问对比水泥（I.2 第一行）。
3. **体检口径**：龄期与基体对不对（I.2 第二行）；7 d 不进口等级判定。
4. **体检门槛**：单值占列位的，先问它属哪一级（I.2 第三行）。
5. **体检层级**：表 4-1、表 4-15、矿渣 K 三处逐一对（I.2 第四行、I.7）。
6. **查场合**：表 4-13 只判两端；空白与并列词按 I.3 处置。
7. **写声明**：四个相对指标的分母未规定、五档词无定义、四品种无门槛（H2）。

**停判点**（命中任一条即停）

1. 掺量落不到任何代号区间 → 停（I.1）。
2. 比值没有分母就往下判 → 停（I.2）。
3. 7 d 进了等级判定 → 停（I.2、卡 1）。
4. 把关口词"可以使用"与"可以选用"排出优劣 → 停（I.3）。
5. 表 4-13 的空白格按邻近格推 → 停（I.3）。
6. 表 4-1 当生料用 → 停（I.7）。
7. 要高铝／白色／快硬的标号门槛 → 停（I.6）。
8. 要把掺量与石灰剂量互推 → 停（第 6 章）。
9. 用矿渣 K 而不回第一章 → 停（`ce-B30`）。

**输出契约**——字段固定：
