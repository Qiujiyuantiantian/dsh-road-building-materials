> **卡型：计算卡（全章唯一一张）**——有输入（一组 3 d 与 28 d 的读数）、有门槛（表 4-4 的十二格）、有输出（一个等级名加一个型号名）、有卡点（哪一格把上溯拦住）。其余五张是判据卡，有适用范围、有覆盖边界、有停判点，不产生数值结论。

**卡头必读（六句，顺序不许换）**

1. **龄期只有两个：3 d 与 28 d。** 7 d 在**本章**的唯一出处是表 4-9 的矿渣粉活性指数（p157），那是"比值"的龄期，不是判等级的龄期。把 7 d 塞进等级判定，就是龄期串用。
2. **表 4-4 的四行全部错位。** 从第 6 格起，每一格装的是本该往右一格的值，末位值被挤到行尾。四行合计 28 格受影响，其中 **19 格真错**、**9 格因为相邻两档本来就同值而碰巧重合**。
3. **所以抽查一两格"对得上"不能证明这张表没问题**——碰巧重合的那九格正好会给出假阳性。唯一稳妥的读法是整行重排后再读。
4. **门槛全是下限。** 说明句写的是"不得低于"，判定不是"哪一行最像"，而是"四格全过的最高那一行"。
5. **受压面积与代表值取法在本章都无定义。** 这两件不影响本例（四组极值都落在均值 ±10% 内），但换一组离散大的数据就会影响。
   **它们不是全书都没有——试验篇把它们结掉了**：受压面积 `A=40×40=1600 mm²` 写死于式 11-4，代表值有 ±10% 两级剔除规则（六值→五值→整组作废），见 `test-mortar-strength`（印刷 316–329）。**本章判不了的那一步，那一张卡能判。**
6. **本卡只做等级与型号，不做处置档。** 废品与不合格品是另一套规则（I.7），别把"不合格品"当"低一级"。

> **公式**：本卡无公式。全章 0 条可代入的计算式；式 4-1～4-13 全是化学反应式，其中 4-7 缺号（p151 正文写"由式(4-7)表示"，式子本身没有印出来）。等级判定是查表加合取，不是代入求值〔公式待核：无〕。

> **数值**：表 4-4 与表 4-16 的每一个数都标〔数值待核原图〕，条件写在表题注里。本轮自己算的四个代表值、十九与九的格子计数、六档跨表差、三对比值，都是复算，**不是**书里的结论。

## R — 原文论点（转述，非摘录）

本章回答"这块水泥是几级"只用了两样东西：一张按龄期排开的门槛表，一句"不得低于表列数值"。门槛表把硅酸盐水泥切成六档（42.5 起，每档配一个早强型），把普通硅酸盐水泥也切成六档（32.5 起）。于是判定动作只能是：对每一档，把 3 d 抗压、28 d 抗压、3 d 抗折、28 d 抗折四个门槛与实测值逐项比；四格都过才算够这一档；能过的最高那一档就是等级。型号（普通型／R 型）不另判一次，它跟着"过不过 R 那一行"走——p153 给的定义是 3 d 抗压能到 28 d 的一半上下，且比同等级的普通型高出一成以上。

试验口径跨了两页。p152 末尾给胶砂：水泥与中国 ISO 标准砂按 1:3、水灰比 0.5；p153 开头给试件与养护：40 mm×40 mm×160 mm，20±1 ℃、相对湿度不低于 90%（或水中），到 3 d 与 28 d 各测抗折与抗压。抗压那一步的受压面积没有定义——压的是 40×40 还是夹具后的 40×80，书里没说。

表 4-4 的排版坏了。四行数据行各有一格被挤出行外：从第 6 格起整体左移一格，本应属于 62.5R 那一格的值跑到了行尾。于是 62.5R 整列看起来是空的，而它左边那一格（普通型的最低档）被读成了 62.5R 的 3 d 抗压，字面读出来的数只有真值的三分之一上下。

表 4-16（p167）是复习题 4-15 的原始数据：三行试件，每行给一个 3 d 抗折值、一个 28 d 抗折值、两个 3 d 抗压值、两个 28 d 抗压值。这是全章唯一一组"给了数、且数与判定项对得上"的数据。

### I.2 回填的三条独立验收（这一节是本卡的骨干）

**（a）与表 4-11 相减。** 表 4-11 是掺混合材料水泥的六档（p159），与品种二的六档一一对应。逐格相减：28 d 抗压、28 d 抗折**六档差全为 0**；3 d 抗压逐档 −1.0、−1.0、−1.0、−2.0、−1.0、−3.0；3 d 抗折 0、0、0、0、−0.5、−0.5。方向对得上——掺了混合材，早龄期低一点，二十八天持平。

若照字面读（不重排），品种二的 3 d 抗压会变成普遍**高于**表 4-11（差 +1 到 +9），方向整个反过来：掺混合材的水泥早期强度反而更高。**错位表会自己把物理方向翻个个儿**，这是它最阴的地方。

**（b）R 型三对。** 抗压 3 d 三对是 22/17、27/23、32/28；抗折 3 d 三对是 4.0/3.5、5.0/4.0、5.5/5.0。六对全部大于一，与 p153"高出一成以上"相容。回填后 R 型 3 d 抗压占其 28 d 抗压的 51.8%、51.4%、51.2%，也落在"一半上下"这句话上。字面读则 62.5R 的 3 d 抗压只剩 11.0，占比掉到一成七，与同一页的定义句当场打起来。

**（c）十九与九。** 逐格对照 28 格：19 格真错，9 格同值重合。重合的位置集中在"相邻两档本来就同值"的地方（28 d 抗压有三格、28 d 抗折有三格、3 d 抗折有两格、3 d 抗压有一格）。**这就是"抽查一两格很可能正好抽到重合那格"的算术来源**：九比十九，近三分之一的概率抽到一个假的"没问题"。

### I.3 判定的动作形式（合取，不是择优）

写成筛选：候选集 = 该品种的六档；对每一档，四项门槛逐格比，四格全过则保留；取保留集里最高的一档；型号名随该行走。

三条纪律：

1. 不能"最接近"、不能"总分最高"、不能"综合评分"。
2. 不能只看最强项。本例的陷阱正是最强项（28 d 抗压）已经越过了高一档的门槛，而正解留在低一档。
3. 不能用"某项超出很多"去补偿另一项不过。四项是"与"，不是"或"，也不是加权。

### I.4 龄期坐标

四格对应两个龄期各两项，缺一不可。7 d 在表 4-9（p157）出现两次，是矿渣粉活性指数的两个龄期之一（另一个是 28 d），它不属本章任何等级门槛。把 7 d 拉进来，会同时犯两个错：门槛取错、比值口径也取错。

### I.5 代表值：书里没有这条规则

表 4-16 每行给两个抗压读数、一个抗折读数，三行合计 18 个读数（抗压两个龄期各六个、抗折两个龄期各三个）。书里没写怎么从几个读数得到一个代表值。

本轮的做法是算术平均，并公开这条假设。敢用它的理由不是它正确，而是它可检验：四组代表值的极值都落在均值 ±10% 以内，所以"算术平均"与"剔除超 ±10% 再平均"给出同一个结论。**换一组离散大的数据，这条链立刻降级为"半"。**

### I.6 两套写法与两个"普通"

- **强度等级**（42.5、52.5…）与**标号**（425、525…）是同一件事的两种称法，按 28 d 抗压门槛逐档对应，四组全部成立。
- **普通型／R 型**是型号，对同一等级而言。
- **普通硅酸盐水泥（P·O）**是品种，另一套六档。
- 复习题 4-15 的答案写"42.5 级（普通型）"，那个"普通型"是**非 R 型**，不是 P·O。按两套六档分别判，结论同为 42.5；差别在被判掉的"下一行"不同：P·I 列上溯落到 52.5 那一行，P·O 列落到 42.5R 那一行，两行都栽在同一个门槛上。

### I.7 处置档不是等级档

初凝、氧化镁、三氧化硫、安定性四项里任何一项不合，判**废品**；细度、终凝、不溶物、烧失量中任一项不合，或混合材掺量超过上限，或强度低于所标等级，判**不合格品**（p153）。等级判定只解决最后这一项。把"不合格品"当"低一级"是两套规则混用。

### I.8 审查清单（拿它审一份定级报告）

1. 龄期写的是 3 d＋28 d，还是混进了 7 d？
2. 按哪一品种的六档判的？写了没有？
3. 四项是逐项比的，还是只挑了最强的一项？
4. 表 4-4 是按十二列直读的，还是整行重排后读的？
5. 代表值怎么取的？有没有写规则？离散多大？
6. 试件尺寸、配比、养护写了没有？受压面积写了没有？
7. 结论是"等级＋型号"，还是被写成了"合格／不合格"？

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】本章没有一道完整算例，唯一可算的一组读数在复习题 4-15 与表 4-16。下面四段给"一份资料加一个诉求"，输出"走不走得通／停在哪一步"，**不出任何数值结果**（等级值、代表值、差值一律不写）。

**演练一（只给最强项，要高档）**
输入：一份定级报告只写了二十八天抗压，并说这一项已越过更高一档的门槛，问能不能就按高档报。
→ 判：I.3 第 2 条。四格合取，缺三格；"某一项超出"不构成补偿。
→ 输出：**停**。要报高档，必须把另外三项补上并逐格比。
→ 不输出：任何等级名、任何"差不多够"的判断。

**演练二（照字面读表 4-4，要 R 型）**
输入：四项读数都给了，报告说按表 4-4 数下来是早强型。
→ 判：I.2。该表四行错位，第 6 格起全部左移；不整行重排，R 那两行的三天门槛取的就不是 R 的值。
→ 输出：**停**。先重排，再判；重排后 R 那两行的三天门槛会变。
→ 不输出：任何"卡在哪一格"以外的数字。

**演练三（龄期串用）**
输入：报告拿七天强度定等级，说"早期就能看出来了"。
→ 判：I.4。等级门槛只在三天与二十八天上；七天这个龄期在本章属矿渣粉活性指数。
→ 输出：**停**。龄期坐标不对，后面的比较全部作废。
→ 不输出：任何"七天折合二十八天"的换算。

**演练四（代表值不明）**
输入：报告每项只给单块试件的读数，问能不能定级。
→ 判：I.5。代表值规则书里没有；单块读数连离散都看不出来。
→ 输出：先问取法；若给不出一组读数或不给离散信息，**停**；若给了，要按 I.5 的验收条件过一遍再走。
→ 不输出：任何代表值、任何等级。

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 品种（P·I／P·II 走六档一，P·O 走六档二） | 枚举 | 必需 | 缺 → 先问；两套都过一遍并写清按哪套判 |
| 龄期组（3 d 与 28 d，同一批试件） | 布尔对 | 必需 | 缺一项或混进 7 d → 停（停判点 1） |
| 四项读数（抗压两龄期、抗折两龄期；各几块） | 数值组 | 必需 | 缺任一项 → 停 |
| 试件与配比（40×40×160、1:3、0.5、养护条件） | 四元组 | 必需 | 未写 → 结论降级为"仅在该口径下成立" |
| 代表值规则（算术平均／剔异常／其他） | 枚举 | 必需 | 未写 → 先问；按 I.5 的 ±10% 验收 |
| 受压面积（40×40／40×80／未写） | 枚举 | 条件必需 | 未写 → 标"本章未定义"，不许自行换算 |
| 判定目的（等级／型号／合格与否／处置档） | 枚举 | 必需 | 要处置档 → 转 I.7，别混进等级 |

**步骤**

1. **定列**：按品种选六档表；写清按哪一套判（I.1）。
2. **验龄期**：确认四格分别落在 3 d 与 28 d 上（I.4）；混进 7 d 即停。
3. **整行重排**：把表 4-4 按"末位回到第 6 格、其后整体右移一格"重排；不重排不许往下走。
4. **验收重排**：用 I.2 的三条（表 4-11 相减、R 型三对、十九与九）确认重排方向没反。
5. **取代表值**：按声明的规则算四个代表值；规则未声明则先问，并按 I.5 的 ±10% 判敏感不敏感。
6. **逐档合取**：六档逐一比四格，保留全过的档，取最高一档；型号随行（I.3）。
7. **落名**：写"等级＋型号"，并单列"卡在哪一格"；不要写成"合格／不合格"。
8. **加声明**：两条必备声明（H2 第 1、2 条）。

**停判点**（命中任一条即停，不再往后走）

1. 只给一个龄期，或用 7 d 顶替 → 停（龄期串用，I.4）。
2. 只凭单选最强项定档 → 停（合取不补偿，I.3）。
3. 照十二列直读表 4-4 → 停（I.2）。
4. 用抽查一两格"对得上"就断言表没问题 → 停（九格假阳性，I.2c）。

## B — 边界

### B.1 为什么全章只有这一张能算（唯一性交代）

全章候选链 14 条，只有 1 条闭合。闭合要同时具备四件，缺一件就掉出去：

1. **入口有真实数据。** 表 4-16 的 3 行 × 6 格 = 18 个读数，是本章唯一一组"给了数、且数与判定项一一对得上"的数据。
2. **出口有量化门槛。** 表 4-4 的十二格，每一格都是一个可比的下限，不需要再解释"多少算好"。
3. **判据逐项合取。** 四格全过，可机械执行：不加权、不排序、不判"哪一项更重要"。
4. **结论对唯一未写的规则不敏感。** 代表值取法书里没有，但四组极值全在均值 ±10% 内，算术平均与剔除后平均给出同一结论。

其余 13 条至少缺一件：**有式无料 3 条、可算但与书冲突 1 条、断 5 条、不可算 3 条、可判非算 1 条**。

**所以本卡不是"本章特例"，而是"本章唯一合格的那一条"。** 它能不能算，取决于上面四件同时成立，而不取决于它的主题恰好叫强度。换一组离散大的读数，第 4 件立刻不成立，这张卡就要降级成"半"。

### H1 — 出现下列情形就别用本卡

1. **把 7 d 写进等级判定。** 7 d 在本章只属矿渣粉活性指数（p157）。
2. **只凭 28 d 抗压或任一单项定级。** 这是全章最贵的误判方向：报高了不报错，只让按等级定价、按等级选料的动作整体偏移（`ce-A01`）。
3. **用"某项超出"补偿另一项不过。**
4. **照十二列直读表 4-4。** 62.5R 会读成 11.0 对 32.0，差 2.9 倍（`ce-A03`）。
5. **用抽查一两格来证明表正确。** 28 格里 9 格是同值重合，抽中它等于没抽（E01）。
6. **把本章 MPa 当混凝土立方体抗压或路面弯拉强度用。** 试件、基体、受压面积全不同，跨章不可互引。
7. **把"普通型"读成 P·O。** 一个是型号，一个是品种（I.6）。
8. **在受压面积未定义时做绝对值换算**（40×40 换 40×80 之类）。本章没有这个入口。
9. **拿代表值规则不明的数据下结论**（离散大时）。换一组数据这条链就断（I.5）。

### H2 — 用前必须声明

1. 本章的 MPa 属 40×40×160 mm 胶砂、1:3、W/C 0.5、20±1 ℃、3 d 与 28 d 这一套口径；离了这套口径就不是同一个量。
2. 本章抗压受压面积无定义（试验篇 `test-mortar-strength` 给了 40×40=1600 mm²），本章的抗压值只能在本章内部相对比较。
3. 代表值取算术平均是本轮为走通链路加的假设，书里没有这条规则（I.5）。
4. 表 4-4 已按 E01 重排；引用任何一格都要说明"原书四行错位"。
5. 等级与型号是两件事；处置档（废品／不合格品）是第三件事，三者不互推。
6. 结论写成"等级＋型号＋卡在哪一格"，不许压缩成"合格"。
