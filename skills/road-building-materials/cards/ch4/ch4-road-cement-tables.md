## R — 原文论点（转述，非摘录）

道路水泥被定义成"熟料＋不多于十分之一的活性混合材＋石膏"，而这个熟料的要求与普通硅酸盐熟料不同：铁铝酸钙要多，铝酸三钙要少。理由是三条排序——抗折强度这一项，硅酸三钙最好、铁铝酸四钙次之、铝酸三钙最差；干缩这一项恰好反过来，铝酸三钙最糟；耐磨这一项又是硅酸三钙领头、铁铝酸四钙跟上。三条排序合起来指向同一个配方方向：高铁低铝。

三张表把这件事落成数字。第一张（表 4-6，p155）管熟料：铝酸三钙压到很低，铁铝酸四钙抬到较高，另附三氧化硫、氧化镁、烧失量、碱含量，以及熟料里游离氧化钙按窑型分的两个上限。第二张（表 4-7，p155）管强度：三个标号，各给 3 d 与 28 d 的抗压、抗折。第三张（表 4-8，p156）管其余：初凝、终凝、安定性、干缩率、磨损量，强度一栏回指第二张表。

处置段只有一档：矿物三项不合、或干缩与耐磨不合，叫不合格品。**没有废品这一档**——这与硅酸盐水泥那节（先分废品、再分不合格品）、掺混合材那节（同样两档）结构不同，三套处置段各写各的。

最要紧的缺口在这里：干缩率与磨损量各有一个上限，但这两项**怎么做**，本章一个字都没有。四条关里，矿物关可以按熟料化学算（如果给了化学分析），强度关可以按胶砂试件测，物理关只能看别人给的结论。

还有一处同名不同物：本章两次出现"水化热"。一次在讲四种矿物时，配图 4-2，那幅图只有图注；一次在石灰那节，写消化放热，数值在 p164。两处不是同一个量，不能互引。

## I — 判据骨架

### I.1 四关与三张表的分工

| 关 | 管什么 | 在哪张表 | 页 | 可执行性 |
|---|---|---|---|---|
| 矿物关 | C₃A、C₄AF、熟料 f-CaO（按窑型） | 表 4-6 | p155 | 可判（需熟料化学分析） |
| 化学关 | SO₃、MgO、烧失量、碱含量 | 表 4-6 | p155 | 可判（碱一格缺不等号，见 I.3） |
| 强度关 | 三标号 × 两龄期 × 两项 | 表 4-7 | p155 | 可判（须按胶砂口径） |
| 物理关 | 初凝、终凝、安定性、干缩率、磨损量 | 表 4-8 | p156 | **干缩与耐磨不可执行**（I.5） |

**四关全过才算合格**——这句话是真的，但"全过"里的两关在本章内验不了。

### I.2 表 4-7 与表 4-4 的逐档对照（可完全复算，`R8`）

道路 425／525／625 三个标号，对硅酸盐水泥的 42.5R／52.5R／62.5R 三档：

| 项 | 425 对 42.5R | 525 对 52.5R | 625 对 62.5R |
|---|---|---|---|
| 3 d 抗压 | 差 0 | 差 0 | 差 0 |
| 28 d 抗压 | 差 0 | 差 0 | 差 0 |
| 3 d 抗折 | 差 0 | 差 0 | 差 0 |
| 28 d 抗折 | **+0.5** | **+0.5** | **+0.5** |

九格差为零，三格各高半兆帕——**高出的那一点全在 28 d 抗折上**。这不是巧合，而是"道路水泥要高抗折"这句话在数字上的唯一落点。它同时说明：道路水泥的强度门槛并不整体更严，只在抗折这一项上抬了半格。

### I.3 表 4-6 的八格对位（表头两行，`ce-B10`）

表头是两行：第一行把「熟料矿物含量」五个字横跨前两格，把"游离氧化钙"横跨后两格（旋窑、立窑）；中间四格各占一项。读数时必须按"矿物两格＋化学四项＋f-CaO 两格"共八格对位，否则会把化学项读到矿物格上。

其中碱含量一格**没有不等号**（其余各格都有）。方向按表 4-5 与注文取上限，进卡写"≤0.60（原表缺不等号，方向按表 4-5 与注文取上限）"，不许直接补符号而不注明（E11）。

### I.4 处置段：三套结构不同（`p15`、`ce-B11`）

| 节 | 页 | 处置档 | 触发项 |
|---|---|---|---|
| 硅酸盐水泥 | p153 | 废品＋不合格品两档 | 废品：初凝、MgO、SO₃、安定性；不合格品：细度、终凝、不溶物、烧失量、掺量、强度 |
| 掺混合材 | p159 | 两档 | 与上同构 |
| 道路水泥 | p156 | **只有不合格品一档** | 矿物三项、干缩、耐磨 |

**道路水泥没有废品档**——这不是漏印一句话的问题，它是三套文本的结构差异。把硅酸盐水泥的废品规则套到道路水泥上，会凭空造出一档本章不存在的处置。

### I.5 两关不可执行

表 4-8 给了干缩率（28 d）与磨损量各一个上限，却没有给：试件尺寸、养护龄期怎么算起、干缩怎么量、磨损用什么仪器与磨料、磨多少转。**本章只有判据值与方法名（第 11 章另见）。**

因此"干缩性和耐磨性符合表 4-8"这句话，在本章内只能核"有没有人给过这个数"，不能核"这个数是怎么来的"。这是四关里唯一一处"门槛清楚、入口没有"。

### I.6 排序不是函数（`ce-A08`、`p06`）

三条排序（抗折、干缩、耐磨）都只给矿物次序：

- 抗折：C₃S ＞ C₄AF ＞ C₃A
- 干缩：C₃A ＞ C₃S ＞ C₄AF ＞ C₂S（越靠前越糟）
- 耐磨：C₃S ＞ C₄AF ＞ C₃A

排序**没有系数**（"多一个百分点换多少兆帕"没有），**没有基准含量**（"以什么矿物的什么含量为基准"没有），也**没有交互项**（几项同时变时怎么合没有）。所以"由目标抗折强度反算 C₄AF 含量"在本章内没有入口。

### I.7 "水化热"一词两义（`g19`、E18）

| 出处 | 什么热 | 有没有数 |
|---|---|---|
| 图 4-2，p147 | 四种矿物的水化放热随龄期 | **零数值**，只有排序 |
| p164 | 石灰消化放热 | 有一个数，但单位存疑（卡 5） |

两处不可互引：一个是水泥矿物的水化热，一个是石灰的消化热；一个没有数，一个数有问题。

### I.8 审查清单（拿它审一份道路水泥报告）

1. 三张表都引了吗？还是只引了强度表？
2. 熟料矿物给的是化学分析结果还是"推定"？C₃A／C₄AF 怎么算出来的写了没有？
3. f-CaO 对的是旋窑那一档还是立窑那一档？窑型写了没有？
4. 碱含量那一格补了不等号吗？补了有没有注明原表缺？
5. 干缩率与磨损量是实测还是引用？测法能不能说清？
6. 结论写的是"不合格品"还是"废品"？道路水泥只有前者。
7. 有没有用"道路水泥强度门槛整体更高"这种说法？只有 28 d 抗折高半格。
8. 有没有把图 4-2 的"水化热"当数据引？

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】**本卡为何不产生数值**：四关里两关只有限值没有测法，矿物关需要熟料化学分析而本章不给算法，强度关的读数属卡 1 的口径。本卡能交付的只有"这四关分别在哪、哪一关验不了、这句话能不能写"，**本卡的输出是缺口清单，不是数**。

**演练一（只给强度的"合格"报告）**
输入：一份道路水泥报告只附了强度试验结果，结论写"各项合格"。
→ 判：I.1。四关只碰了一关；矿物、化学、物理三关全缺。
→ 输出：**退回**。结论改成"强度关合格，其余三关未覆盖"。
→ 不输出：任何"合格"的整体判断。

**演练二（干缩率"满足要求"）**
输入：报告写"干缩率满足表 4-8 要求"，没写怎么测的。
→ 判：I.5。限值有、测法无；本章核不了这个数的来路。
→ 输出：**停**。先问测法（第 11 章另见）；答不出，这一关只能标"未核"。
→ 不输出：任何干缩值。

**演练三（由抗折反算矿物）**
输入：报告说"按抗折强度要求反算，铁铝酸四钙应达到某个含量"。
→ 判：I.6。三条排序只给次序，没有系数、没有基准含量。
→ 输出：**停**。这个反算在本章内没有入口。
→ 不输出：任何含量、任何"大致取多少"。

**演练四（"水化热"被当数据引）**
输入：报告引"本章图 4-2 的水化热数据"来论证道路水泥水化热低。
→ 判：I.7。图 4-2 零数值；且道路水泥的三条排序里没有水化热这一项。
→ 输出：**停**。方向可以引文字，数值不可引。
→ 不输出：任何热值。

**预期输出表**：`报告覆盖哪几关｜缺哪关｜缺的是限值还是测法｜窑型｜碱格写没写｜能不能复算｜处置档写对没有｜停判点｜依据页`。

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 判定目的（矿物关／化学关／强度关／物理关／整体） | 枚举 | 必需 | 缺 → 先问；"整体"须四关齐才可答 |
| 熟料化学分析（有无、怎么算 C₃A／C₄AF） | 布尔＋方法 | 条件必需 | 无 → 矿物关只能标"未核" |
| 窑型（旋窑／立窑／未写） | 枚举 | 条件必需 | 未写 → 停（f-CaO 对不上号） |
| 干缩与耐磨的测法来源 | 枚举（本章／第 11 章／未写） | 条件必需 | 未写 → 标"未核"，不许当已过 |
| 强度读数口径（40×40×160、1:3、0.5、3 d／28 d） | 五元组 | 条件必需 | 不齐 → 转卡 1 先定等级 |
| 处置档（废品／不合格品） | 枚举 | 必需 | 写"废品" → 停（道路水泥无此档） |
| 是否要引水化热的数 | 布尔 | 条件必需 | 为真 → 停（I.7） |

**步骤**

1. **分关**：把诉求落到四关中的一关或几关（I.1）。
2. **查表**：按关取表，注意表 4-6／4-7 在 p155、表 4-8 在 p156。
3. **对位**：表 4-6 按八格对位（I.3）；碱格缺号按 E11 写法。
4. **核强度关系**：需要与硅酸盐比时，用 I.2 的逐档对照，别写"整体更严"。
5. **点缺口**：物理关两行标"限值有、测法无"（I.5）；矿物关若无化学分析，标"未核"。
6. **守排序边界**：凡"反算含量"一律停（I.6）。
7. **定处置档**：只写"不合格品"；不造废品档（I.4）。

**停判点**（命中任一条即停）

1. 只要一个"道路水泥合格"的结论而四关不齐 → 停（I.1）。
2. 要求干缩或耐磨的测法或复核 → 停（I.5，第 11 章另见）。
3. 要求由性能反算矿物含量 → 停（I.6）。
4. 未写窑型却要对 f-CaO → 停（I.3）。
5. 写"道路水泥是废品" → 停（I.4）。
6. 要引图 4-2 的水化热数 → 停（I.7）。
7. 说"道路水泥强度门槛整体更高" → 停（只有 28 d 抗折高半格，I.2）。

**输出契约**——字段固定：

`诉求落在哪关｜用了哪张表与页｜八格对位对不对｜窑型｜碱格写法｜强度对照｜缺的是限值还是测法｜处置档｜停判点`

表下固定三行：

- **公式状态**：本卡无公式；三条排序为次序关系，不可写成函数。
- **数值状态**：三表各格一律〔数值待核原图〕，条件分矿物／胶砂强度／28 d 干缩与磨损三类。
- **依据页**：p154（排序）、p155（表 4-6、表 4-7）、p156（表 4-8、处置段）、p147（图 4-2）、p164（石灰消化热）。

**本卡不产出数值；若需数值，回卡 1 或第 5／6 章。**

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **把"四关全过"写成已验证。** 其中两关在本章内不可执行（I.5）。
2. **给干缩率或磨损量的测法、给复核。** 本章只有上限（`g20`）。
3. **由目标性能反算矿物含量。** 排序不是函数（`ce-A08`、`p06`）。
4. **说道路水泥强度门槛整体更严。** 只有 28 d 抗折高半格（I.2）。
5. **造一个"废品"档。** 道路水泥只有不合格品（I.4、`ce-B11`）。
6. **引图 4-2 的水化热数。** 零数值（`g19`、`ce-B22`）。
7. **把碱含量格直接补 ≤ 而不注明。** 原表缺不等号（E11、`ce-B13`）。
8. **把道路水泥的 MPa 与混凝土路面弯拉强度并排。** 两者不同物。

**H2 — 用前必须声明**

1. "道路"落点在熟料矿物与两项物理指标上，不只是一张强度表。
2. 干缩与耐磨两关只有限值，测法不在本章。
3. 三条排序只给方向，无系数、无基准含量。
4. 道路水泥的强度门槛与硅酸盐 R 型几乎逐格重合，唯一抬高的是 28 d 抗折。
5. 处置只有不合格品一档。
6. "水化热"在本章指两个不同的量，一个没有数、一个数存疑。
