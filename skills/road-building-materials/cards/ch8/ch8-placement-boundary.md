## R — 原文论点（转述，非摘录）

p278 的节首导语先把范围划出来：道路工程里出现频率最高的一类材料是改性沥青，并且当场说明这一条本教材第二章已经讲过；此外拿它改善水泥混凝土的性能或做聚合物混凝土、作胶结与嵌缝密封材料、作加强土基与基层的格栅。导语点到四种落点。

正文实为五块：聚合物混凝土（p278–p279）、胶粘剂（p279–p280）、裂缝修补与嵌缝（p280–p281）、土工合成材料（p281）、膨胀与弹性支座（p281）。**「四类」这个字样书上并没有，是从导语里数出来的**（更正值 E3）。

五块的份量差得很远：土工那一块两百来字，支座那一块七十来字，两块加起来不到全章三个百分点；胶粘剂九百多字、裂缝修补一千多字。份量决定能交什么——前两块只剩「有哪些品种、凭什么能加筋」这一层；后两块有品种、有做法、有选型理由，仍然没有一个数。

章际线是本章最该记的一层，因为四条里有三条是书自己划的：

- 改性沥青——书明写归第二章（p278）；
- 水泥型的聚合物混凝土，做法和普通水泥混凝土同路，配合比与强度要回第五章（p279）；
- 土工格栅的加筋设计参数不在本章，p281 那两百来字讲的是为什么要取向（→ 第六章，`ce-B24`）；
- 试验方法：本书四个试验章分别是石料、沥青、水泥、无机结合料，没有一章管聚合物，所以「这个试验怎么做」在本章与全书都没有落点。

还有一层是本章的性质决定的：三张名录表的末段装的全是相对评价，全章没有一处「≥」或「≤」。这意味着任何一句从表里抄下来的「特性」都停在比较级上，往上一格就是门槛，而那一格没有书页支撑。

引表之前还得先验表。表 8-3 的表头五格、表体六格：缺的那一格是「缺点」，于是表体第四格是优点、第五格是缺点、第六格是用途。逐列往下读，每一句都通顺——九个品种的缺点被当成特性、用途被当成缺点，读起来完全不像错。表 8-4 的表头只有三格，末格是特性，正文却说特性与用途都在这张表里，用途那一列不存在。p281 的代号整体错开一格。

术语上还有两处边界：提要里那个词与正文里那个词不是一件事；「软化」在本章出现两次，但软化点一次也没有。

### I.6 术语边界（`g13`、`ce-A10`、`ce-B04`、`ce-B21`）

1. **胶结剂与胶粘剂是两个词、两件事。** 提要用的是前一个（3 处：p271、p274、p275），正文用的是后一个（24 处：p277、p279、p280、p281）。前者说的是树脂在塑料里起黏结作用，后者说的是一类专门用来粘东西的材料。**把两个词当同义词，会让「胶粘剂」这一节被误读成「胶结材料」的泛论。**
2. **「软化」两处不等于「软化点」。** p273 说交联得浅的受热可能软下去，p276 说增塑剂又叫软化剂。两处都不是热学判据。**写「软化点零命中」时不能顺手写成「本章没有软化」。**
3. **小结的定义比正文窄。** 小结只把聚合物说成不饱和低分子经聚合而来，这漏掉了缩聚那一路与环状开环那一路（p272）。引用定义时要说明取的是窄的那一条还是宽的那一条（`ce-B21`）。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】**本卡为何不产生数值结果**：本章能交的是「这块地方归谁、能答到哪一档」，而档位不是数。六行落点里五行只能定性；剩下那一行的「能答」也只是分类与工艺。要给出一个数值，必须从别的章搬——搬进来就不再是本章的判据，而是替第二章或第五章答题。所以本卡演练的是「分档」与「指路」，不是算数。

**演练一（改性沥青的掺量方案）**
输入：一份方案写着某改性剂掺量若干，要求用本章校核。
→ 判 I.3 第一条、`ce-B05`：书里只说了这块归第二章，本章关于改性只有一句定性。
→ 输出：**停**，并把这一格标「回第二章」；本章能签的只有「为什么选这一种改性剂」。
→ 不输出：掺量、效果数值、任何比值。

**演练二（嵌缝材料选型表只写形容词）**
输入：一张选型表，每行的评语是「耐候性好」「柔韧性好」这类词，要求判「能不能用」。
→ 判 I.4：形容词在本章只有两种合法用法——同表内排序、当选型理由。
→ 输出：**降级**为「给出排序与理由」，不给出合格结论；再把两个能判的窗口挑出来（胶泥的施工温度、烯烃类的固化时间）。
→ 不输出：任何「合格／不合格」。

**演练三（照表 8-3 逐列抄特性）**
输入：有人按表 8-3 的表头五格逐列填了一张卡，每行都读得通。
→ 判 I.5：表体是六格，缺的那格表头是「缺点」，所以第五格读出来的东西其实是缺点。
→ 输出：**退回重读**，按六格重排；抄出来的「特性」里凡是负面词，都要挪到缺点栏。
→ 不输出：任何「这九类里哪一类最好」。

**演练四（要格栅的抗拉参数）**
输入：一份加筋方案要填格栅的强度与模量，问本章取值。
→ 判 I.2 第五行、`ce-B08`：p281 那两百来字只有取向机理与三类制品的形态。
→ 输出：**停**，标「回第六章」；本章能交的是「为什么取向能提高强度」。
→ 不输出：任何参数值。

**演练五（拿小结定义当全章定义）**
输入：一份名词解释把聚合物说成「只能由不饱和低分子聚合而来」。
→ 判 I.6 第三条：这是小结的窄定义，漏掉缩聚与开环两路。
→ 输出：**改写法**，注明取窄定义还是宽定义，二选一。
→ 不输出：任何「哪种说法是对的」的裁决。

**预期输出表**：`落点｜档位（能答／只能定性／回别章）｜本章给了什么｜缺什么｜代号出处｜停在哪一步｜依据页`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 这一条落在哪一块（六行之一） | 枚举 | 必需 | 对不上 → 进停判点 1，先定位 |
| 诉求是「是什么／为什么」还是「多少」 | 枚举 | 必需 | 为「多少」→ 先看 I.2 该行的档位 |
| 引的数据是不是本章的 | 布尔 | 必需 | 不是 → 标「非本章」，不许混写 |
| 有没有引代号 | 布尔 | 条件必需 | 有 → 要表号，且先查 p281 串位 |
| 有没有引表 8-3 或表 8-4 的格 | 布尔 | 条件必需 | 有 → 先进 I.5 验表 |
| 是不是要改性沥青的数 | 布尔 | 条件必需 | 是 → 停判点 3、4 |
| 要不要一个门槛 | 布尔 | 条件必需 | 为真 → 停判点 1 |

**步骤**

1. **定位**：先把诉求对到 I.2 的六行之一。对不上，说明它不在这章的地图上。
2. **看档位**：那一行写的是「能答」还是「只能定性」还是「回别章」。
3. **验表**：凡从表 8-3 取格，按六格读；凡从表 8-4 取格，不要找用途列（I.5）。
4. **查代号**：凡出现 PE／PP／PVC 或 SI／PC，先问表号（I.6、K1 的 I.5）。
5. **分形容词**：把「好／差／优」留在排序与选型理由里，不许转成区间（I.4）。
6. **挑窗口**：能从本章直接判的只有两个工艺窗口，其余一律不给区间。
7. **指路**：缺的那一项写清回第几章；若无处可回，写「全书无对应章」，不要含糊成「另见规范」。
8. **定措辞**：结论只能写到「这块归谁、能答到哪一档」。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **要门槛 → 停。** 合格线、掺量、等级、设计参数，本章一个都没有（`ce-B01`）。
2. **要改性沥青的掺量与效果。** 本章三次提「改性剂」，零个数；书自己说这一块归第二章（`ce-B05`、`ce-B22`）。
3. **要格栅、织物、膜的力学参数。** p281 只有取向机理（`ce-B08`）。
4. **要纤维混凝土指标。** 表 8-4 末列只有相对评价（`ce-B10`）。
5. **要聚合物的试验方法。** 本章与全书都没有（`ce-B02`）。
6. **把表 8-3 当五列读。** 表头五格、表体六格，逐列读会把缺点当特性（`ce-A02`）。
7. **去表 8-4 找用途列。** 那一列不存在（`ce-A03`）。
8. **用 p281 的代号。** 整体串一格（`ce-A04`）。
9. **把本章的「软化」接到沥青软化点上。** 两章概念不同，本章零命中（`ce-A10`、`ce-B04`）。
10. **把提要和正文的两个近义词当一件事。** 胶结剂 3 处、胶粘剂 24 处（`g13`）。

**H2 — 用前必须声明**

1. **把比较级当门槛 → 错。** 三张名录表的末段全是相对评价（「较好」「较差」「最优」「尚好」），全章 0 处「≥／≤」。把「耐热性差」读成「不耐多少度」、把「比 PE 好」读成「高多少」，都是替作者补数；本章的形容词语料里，能给的只有排序与选型理由（`p01`）。
2. 六行落点里五行只能定性；「定性」不等于「没用」，它等于「先筛掉明显不合适的」。
3. 章际线四条里只有第一条是书自己写的，另三条是本卡的推论，引用时要分开说。
4. 三张表里两张有结构缺陷（表 8-3 多一格、表 8-4 少一列），引表前先验表。
5. 「四类落点」是本卡从导语数出来的，书上没有这个字样（更正值 E3）。
6. 本章不写标准，所以本章的判据不能改写成「须满足某标准」的句式——那种句式在本章无依据。
7. 缺陷与边界要分开说：漏表头、漏用途列是**书上漏了**（B 段管）；不判合格、不给耐温是**本卡不做**（卡头管）。
