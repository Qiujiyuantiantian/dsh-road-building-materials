## R — 原文论点（转述，非摘录）

本章把受拉过程切成四段：弹性、屈服、强化、颈缩（p259，图 7-1）。头一段里曲线的斜率是常数，这个常数叫弹性模量，书上在行内给了它一个式子、没编式号。第二段有两个峰：上峰叫屈服上限，下峰叫屈服下限；下峰稳、好测，所以取它对应的应力当屈服点 σ_s。第三段的最高点对应极限抗拉强度 σ_b。第四段里断面在某处变细，到某个点断开。

屈强比由式 7-1 定义（p260）：n 等于 σ_s 除以 σ_b。紧接着的两句是方向话——比值小一点，结构更保险；比值太小，材料又白搭。所以这一段给出的是一个取舍方向：安全那一头守住之后，把利用率往高里推。这是一句权衡，不是一条线。

伸长率由式 7-2 定义（p260）：断后将两截拼回去，量断前与断后的标距，用差值比原标距。δ 大说明塑性强；塑性强的好处是偶发超载时先变形、应力重新分布，不因局部集中而断。

中碳钢与高碳钢没有明显的屈服段，应力随应变一路升到断（p260，图 7-2）。这一句解释了为什么表 7-9 的屈服列要写成「σ 或 σ0.2」——没有明显屈服点的材料，得另找一个替代量。

判据值散在十三张表里，按钢材种类分派：碳素结构钢走表 7-1／7-2／7-3；桥梁用结构钢走表 7-4／7-5／7-6；低合金高强度结构钢走表 7-7／7-8；热轧钢筋走表 7-9；热处理钢筋走表 7-10；冷轧带肋钢筋走表 7-11／7-12；冷拔低碳钢丝走表 7-13。冷拉钢筋只有一句冷拉率上限，没有表。

表 7-2 的排法值得单说：它的表头分四层展开，逐层格数是 5／5／5／14；数据行一律 15 格，比最深一层多一格。缺的那一格是 σ_b 那一组的占位格。按「行头格数 ＋ 各块列数」重建：6 档 σ_s ＋ 1 个 σ_b 窗口 ＋ 6 档 δ ＝ 15，唯一。所以这张表缺格但可读（I.5）。

表 7-9 是本章唯一齐整的判据表：段数、格数、每行的写法都稳定。但它把公称直径的两个档挤在同一个格里换行，弯心直径的两个值也在同一个格里换行（详卡 3 的断点三）。

### I.2 前置判据：相除之前的三查（这是门，不是注意事项）

要算 n ＝ σ_s/σ_b，动笔之前先过三查：

| 查 | 问什么 | 不过的后果 |
|---|---|---|
| 查一 | **分母有上限吗？** | 只给 ≥ ⇒ 比值没有下界 ⇒ 停 |
| 查二 | **分子有上限吗？** | 没有 ⇒ 只能得下界，拿不到上界 |
| 查三 | **两个数同表、同行、同厚度（直径）档吗？** | 否则根本不是同一个 n |

**形式化依据（这一段不可省，它替代不了任何试验，但一次就能把一条链判死）：**

设 σ_s ∈ [a, ∞)、σ_b ∈ [b, ∞)。

- 把分母钉在 b、让分子趋于无穷 ⇒ n → ∞：**没有上界**。
- 把分子钉在 a、让分母趋于无穷 ⇒ n → 0：**下确界是零**。

所以 n 的可行集是 (0, ∞)。于是 a/b 这个商**算得没错**——错在它不是一个界：既不是上界，也不是下界，也不是任何一个有判据地位的点值。它在 (0, ∞) 里只是随便一个点。**问题不在取值，在形式。**

> 这一条必须进 I 段而不是 E 段：它是「能不能算」的前置，不是「算到哪停」的后置。

### I.3 σ_b 的四种口径（入口判据：不先认口径，就会去算）

| 口径 | 出处 | 写法 | 可算性 |
|---|---|---|---|
| 窗口（两端都给） | 表 7-2、表 7-8 | 「375 ~ 460」这类 | **可出一个下界**（分子无上限 ⇒ 无上界） |
| 单值 | 表 7-6 | 「390」这类 | **只能整行引用**；本章没有一句说它是名义值还是下限，故不参与比值、不跨表比大小 |
| 只给下限、符号是 σ_b | 表 7-9 | 「370」配 ≥ | **不可算**：分母无上限 |
| 只给下限、符号换了 | 表 7-10（裸 σ）、表 7-12（σ0） | 「≥1325」「≥550」 | **不可算**；且 σ0 在两表里指两样东西（表 7-12 指抗拉，表 7-9 指屈服，带 0.2 偏移） |

**窗口宽度不一样，不要拿它当钢的差别。** 表 7-2 的窗口是 1.22~1.25 倍，表 7-8 是 1.31~1.46 倍〔复算 R5〕。同一个或相近的牌号在两表上各算一次，两个结果不可直接对照——差的是窗口的宽窄。

### I.4 标距三轨：一个 δ 挂三套量法

| 轨别 | 在哪几张表出现 | 表头写的符号 |
|---|---|---|
| δ5 | 表 7-6、表 7-9、表 7-10 | 表 7-6 写 δ5；表 7-9 与表 7-10 写成 **σ5** |
| δ10 | 表 7-12、表 7-13 | δ10 |
| δ100 | 表 7-12 | δ100 |
| 未声明 | 表 7-2、表 7-8 | 只写 δ，**没有下标** |

「标距」一词全章 3 次命中，**没有一处规定它怎么取**。四条纪律：

1. **表 7-2 与表 7-8 的 δ 不得默认成 δ5**，只能写「本章未声明轨别」。
2. 三轨并列时**按轨别分栏**，不按指标分栏——它不是三个指标，是一个指标的三套量法。
3. 表 7-12 的 δ10 与 δ100 **按牌号互斥**：第一个牌号只给 δ10，其余只给 δ100。
4. δ5 与 δ10 之间**没有换算**（本章无系数、无公式、无锚点），所以跨轨比大小一律作废。

### I.5 能算的那一个：表 7-2 窗口型 → 一个下界

**结构先重建（缺格但可读）。** 表头逐层 5／5／5／14，最深一层 14 格；数据行一律 15 格。缺的是 σ_b 那一组的占位格。按「行头格数 ＋ 各块列数」重建：6 档 σ_s ＋ 1 个 σ_b 窗口 ＋ 6 档 δ ＝ 15，**唯一**，所以可读。

> 注意判据不是「表头格数等于数据格数」。表 7-2 恰好不等而最好读；表 7-6 前半「20 行一致 13 格」看起来整齐，却因为缺的两列无从指认而不可重建。判据是**能否唯一重建**。

**动作（三步，可机械执行）：**

1. 取该牌号该厚度档的 σ_s 表值；
2. 取该牌号那一行的 σ_b 窗口**上限**；
3. 相除：**下界 ＝ σ_s（该档）÷ σ_b（该行窗口上限）**〔公式待核〕。

**另一端的性质要分开说。** 用窗口**下限**去除，得到的是**加了假设的端点**，那条假设是「σ_s 恰等于表中值」——**书上没有这句话**。不加假设，那一端不存在。于是「端点对」与「无假设的下界」是两件事，写作时不许合并成一个「区间」。

**三条必须公开的声明：**

1. **这不是实测比值。** 本章没有任何一处给出同一试件的 σ_s 与 σ_b 配对实测；表 7-2 的 σ_s 与 σ_b 是**同一个牌号同一个厚度档上的两条要求**。所以这里得到的是「两条要求之比」，不是任何一块钢实测出来的 n。
2. **端点对的宽度由窗口宽窄定**（表 7-2 是 1.22~1.25 倍、表 7-8 是 1.31~1.46 倍）〔复算 R5〕，不由钢的性能定。
3. **表 7-2 里 Q195 的两格印作 (195)、(185)，括号的含义本章一句没说。** 进卡只按面值参与，并注明「括号义未说明」。

26 个厚度档都能照这个动作做一遍（Q195 两档、其余四个牌号各六档）〔复算 R2，非书值〕。书上没有一个 n。

### I.6 黑名单那条链长什么样（为什么「提醒」拦不住它）

（原先此处并列四个由两列下限相除得到的商作为「指纹」；按本节 E-1 的规则，凡分母带 ≥ 的商一律按形式判停，不靠数值比对，故不再印出具体数值——印出来反而给了可被抄走的数）

| 特征 | 后果 |
|---|---|
| 除法不报错 | 商无量纲、落在零与一之间，看上去完全合法 |
| 与真值巧合相近 | 实际钢材的屈强比大致也在这个区间，所以「看起来合理」 |
| 趋势也对 | 四个商单调递增，与 δ5 递减、d/a 递增同向，连定性结论都不露馅 |

**所以唯一抓得住它的是形式检查（I.2 查一），不是数值自查。** 任何靠「这个数看起来对不对」做的筛子，对这四个值一律失效。

## A1 — 演练（合成场景，非书中案例，**0 个数值结果**）

【合成演练，非书中案例】本章没有一道算例，也没有一处同一试件的 σ_s 与 σ_b 配对实测。下面六段各给「一份资料加一个诉求」，产物是**走不走得通、停在哪一步**。**本段数值结果 0 个**——不出现任何商、任何区间、任何端点。

**演练一（两列都带 ≥，要一个屈强比）**
输入：一张只有「σ_s ≥ 某个值、σ_b ≥ 某个值」两列的牌号表（表 7-9 的形态），诉求是算出该牌号的屈强比。
→ 判：I.2 三查里的第一查不过——分母没有上限。
→ 输出：**拒绝**。理由写清：可行集是整条正半轴（下确界为零、上不封顶），商不构成界；这不是取值取错，是它从来不是一个界。**这就是本卡要的产物：一份拒绝理由，不是一个数。**
→ 不输出：任何商、任何区间、任何「大约」。

**演练二（换成窗口型，仍然要求「给一个数」）**
输入：牌号、厚度档、窗口型 σ_b 都齐了，诉求是「给一个屈强比」。
→ 判：I.5。可以给，但只到**下界**；另一端要一条书上没有的假设。
→ 输出：**降级**。写「下界」，并同时写牌号与厚度档、σ_b 的口径、性质标注（三件齐）。
→ 不输出：不写「区间」，不写「约为」，不把两条要求之比说成实测比值。

**演练三（跨厚度档拼一个 n）**
输入：σ_s 取一档、σ_b 取同牌号另一档，问能不能算。
→ 判：I.2 第三查不过。不同档不是同一个 n。
→ 输出：**拒绝**。
→ 不输出：任何商。

**演练四（两种标距的 δ 比大小）**
输入：一份报告拿 δ10 的读数去与表 7-9 的 δ5 比，说塑性更好。
→ 判：I.4。一个 δ 挂三套量法，本章没定义标距取法；轨别不同不可比，也没有换算。
→ 输出：**拒绝**。
→ 不输出：任何换算系数、任何「折算后」。

**演练五（要一个「合格／不合格」）**
输入：n 的下界拿到了，问该牌号的屈强比是否合格。
→ 判：B 段 H1 第 1 条。本章 0 个 n 限值；两句方向话是定性权衡。
→ 输出：**拒绝判收讫**。可以说「两个候选哪一个更可靠」，不能说「这一个过没过」。
→ 不输出：任何限值、任何合格线。

**演练六（问「有没有别的办法看出塑性」）**
输入：同上，但诉求改成「不报 n，也要说哪两个牌号塑性好差」。
→ 判：I.7 反向锚。
→ 输出：**可答**。用表 7-9 的 d/a 与 δ5 两列各自的单调次序作答，全程不出现 n。
→ 不输出：任何比值的商。

**预期输出表**：`诉求｜入口表｜分母有上限否｜同行同档否｜标距轨别｜判到哪一步｜停判点｜依据页`

## B — 边界

### B.1 本章 0 个 n 限值（写死）

**本章没有给 n 的合格线。** 正文只有两句方向话——比值小一点更保险、比值太小又白搭材料。那是**定性权衡**：可以用来在两个候选之间挑，不能用来判一个材料过不过、更判不了收讫。

所以：凡见「屈强比应不大于 0.8」这类写法，**都不是本章的话，不得挂本章页码**。要写合格线，得另外指名出处，而那个出处不在本书这一章。

### B.2 为什么只有这一条链能算（唯一性交代）

全章能走到数值的链只此一条。它同时具备四件，缺一件就掉出去：

1. **入口有真实表值**：表 7-2 的 26 个厚度档与 5 个窗口。
2. **出口的形式明确**：σ_b 两端都给，所以「分母有上限」这一查过。
3. **动作可机械执行**：两端各除一次，不需要判断力。
4. **结论对唯一未写的规则有一个可陈述的依赖**：σ_s 取表中值。

其余链各断一处：断在标距（δ 三轨）、断在量纲（冲击是比功、表给总功）、断在方向与格位（冷弯四表）、断在 0 个值（E 与疲劳）、断在分母无上限（表 7-9 的 n）。**所以本卡不是「特例」，是本章唯一合格的那一条。**

第 4 件同时也是本卡的软肋：声明的读法一变（不承认要求表的单值即下限），连这个下界也拿不到，本卡立刻降级为纯判据卡。

### H1 — 出现下列情形就别用本卡

1. **要判屈强比合格与否。** 本章 0 个 n 限值；两句方向话是定性权衡，不能判收讫。
2. **把表 7-9 的两列相除。** 可行集是整条正半轴（I.2），商不构成界。
3. **跨表比 n。** 表 7-2 与表 7-8 的窗口宽度不同（1.22~1.25 对 1.31~1.46），同牌号两表的结果不可直接对照。
4. **默认表 7-2 的 δ 是 δ5**，或在 δ5／δ10／δ100 之间换算。
5. **把表 7-6 的单值 σ_b 当名义值或下限。** 本章没说，它只能整行引用。
6. **在 σ_s 无上限时给 n 的上界。** 那就是把假设当结论。
7. **用「数值合理性」筛 n。** 四个假值就落在常识区间里，且趋势也对。
8. **把本章的 MPa 与第 5 章的混凝土强度、书 4 的设计值并排。** 本章 MPa 是验收门槛，不带分项系数、不分标准值与设计值。
9. **把「两条要求之比」说成「实测比值」。** 本章没有一处同一试件的 σ_s 与 σ_b 配对。

### H2 — 用前必须声明

1. 本章 MPa 是验收门槛：不带分项系数、不分标准值与设计值、不含构件尺寸与受力形态。跨出处只写「另见」与「不可互换」。
2. 表 7-2 的 σ_s 列未印 ≥；「要求表的单值即下限」是本卡的**读法声明**，不是书上原话。不作此读法，下界也拿不到。
3. 「下界」与「加假设的端点」是两件事；端点对的上端依赖「σ_s 恰取表中值」这条书上没有的假设。
4. Q195 的两格 (195)、(185) 括号义未说明，只按面值参与。
5. 本卡的结果是「两条要求之比的下界」，不是任何一块钢的实测屈强比。
6. 结论只能写成「下界 ＋ 三件」，不能压缩成一个屈强比。
