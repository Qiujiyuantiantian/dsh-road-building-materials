## R — 原文论点（转述，非摘录）

作者把定最佳沥青用量写成一条四步链。

第一步，以估计值为中值、按固定间隔取五个沥青用量，成型试件，测密度、稳定度、流值。第二步，把五个量与沥青用量画成关系曲线，从曲线上取三个量：稳定度峰值对应的用量、密度峰值对应的用量、以及设计要求空隙率区间中值对应的用量，三者平均得初始值 OAC₁〔公式待核〕。第三步，在同一组曲线上找出「各项指标都进标准」的用量区间，取其中点得 OAC₂〔公式待核〕。第四步，先检查 OAC₁ 是否落在这个区间内，落进去才允许把 OAC₁ 与 OAC₂ 平均；落不进去，作者的写法是应当调整级配、重做试验，直到各项指标都能符合。此外给了三条偏移规则：一般取平均；热区、渠化交通、预计车辙的路段可在中限与下限之间取，但不宜低于中限减一个固定量；寒区与旅游区可在中限与上限之间取，但不宜高于中限加另一个固定量〔数值待核原图〕。

（见 p112–p113，§第二节 四、2–3；检验回路在 p114、p118）

> **口径提醒**：全段最要紧的一句不是公式，是「先检查 OAC₁ 在不在窗口内」。这句话把 OAC₁ 从「一个待平均的数」变成了「一张否决票」——而本章的例题恰恰是在窗口边缘通过的。

## I — 判据骨架

### I.1 这条链有四个关口，不是一个公式

| 关口 | 动作 | 交付物 | 失败即停的条件 |
|---|---|---|---|
| 一 | 抄标准行（五项：空隙率、饱和度、间隙率、稳定度、流值） | 一张写着**出处表号**的标准行 | 出处未写 → 停 |
| 二 | 从五条曲线上取 a₁／a₂／a₃ | OAC₁ | a₁ 被当成可复算值 → 停 |
| 三 | 求各项指标同时合格的用量区间 | OAC₂ | 区间靠「目测阴影」而无逐项边界 → 记一处不可复核 |
| 四 | 验 OAC₁ 是否在区间内，再定 OAC | OAC 或「退回改级配」 | OAC₁ 在区间外仍取平均 → 停 |

### I.2 标准行必须显式：这是一张登记表，不是一句「按规范」

本章同时存在两套标准，且不是同一张表：

| 来源 | 位置 | 五项各是什么 |
|---|---|---|
| 表 3-16 与表 3-17 | p110 | 击实次数分两档；空隙率按层位与交通分档；饱和度与间隙率转查另一张表〔数值待核原图〕 |
| 表 3-23 末行 | p117 | 五项并列成一行，**无出处、无表题、无交通与层位条件**〔数值待核原图〕 |

两套不是一回事：空隙率区间不同、稳定度门槛不同、流值区间不同、间隙率门槛不同。**「标准取自哪张表」因此不是注释，是第 1 步的必填输入。**

### I.3 同一组数据、换本章自己的标准表，OAC 从 5.4 变 5.2〔复算〕

这是本卡的核心证据。用例题 3-1 的五个沥青用量与五组实测指标（p117，表 3-23，〔数值待核原图〕）：

| 项 | 按表 3-23 末行（书中做法） | 按表 3-16／3-17（本章自己的标准，假定「密级配—重交通—夏炎热」那一列） |
|---|---|---|
| 空隙率区间 | 3~6〔数值待核原图〕 | 4~6〔数值待核原图〕 |
| 稳定度下限 | 7.5 kN〔数值待核原图〕 | 8 kN〔数值待核原图〕 |
| 流值区间 | 20~40（零点一毫米）〔数值待核原图〕 | 1.5~4 毫米，换算后下界反而更宽〔复算〕 |
| 沥青饱和度 | 70~85〔数值待核原图〕 | 60~75〔数值待核原图〕 |
| 矿料间隙率 | 不小于 15〔数值待核原图〕 | 按设计空隙率双坐标转查另一张表〔数值待核原图〕 |
| 合格用量窗口 | 书中给的窗口 | 上界被饱和度卡住、下界被稳定度卡住〔复算〕 |
| OAC₁ 是否落在窗口内 | 是 | **否**（落在窗口上界之外）〔复算〕 |
| OAC | 5.4（书中值） | 约 5.2〔复算〕 |

**两个结论必须同时记住**：

1. 差 0.2 个百分点不是算术错，是**标准行换了**。同一组数据能得出两个设计结果，说明「OAC」这个数在没写标准来源时是不确定的。
2. 换表后 OAC₁ 落到窗口之外。按本章自己的规则，此时**不许取平均**，应当退回改级配——也就是说，正确输出不是「5.2」，而是「该级配在本标准下不通过，须重做」。5.2 只是「若硬把平均做完会得到什么」〔复算〕。

**这个 5.2 还带一个前提，必须一起写出来**：复算先得假定一列，因为表 3-16 的列头三层已丢（见 I.5），「该取哪一列」在本章不可判。若假定换一列（空隙率区间改取另一档），同样的算术会把 OAC 送回到 5.4 附近〔复算〕——0.2 个百分点的差可以整块消失。

这不是复算不稳，而是**列不可判，则 OAC 也不可判**。所以本卡把「标准表」与「表里的哪一列」一起列为第 1 步的输入，不是两件事、是一件事。

### I.4 a₁ 是读图值，不是复算值

作者明写 a₁ 由五曲线图取（图 3-24），而图缺。本章可核的只有一件事：表 3-23 的稳定度峰值落在 5.5 那一档（8.7 kN），而书中给的 a₁ 是 5.4，两者相差 0.1〔数值待核原图〕〔复算〕。

所以 a₁ 必须单列为**输入类型：读图值**。把 a₁ 当成「可以算出来的数」，会让整条链的可复现性被高估——它其实是五个量里唯一一个由人眼从曲线上读出来的。

### I.5 表 3-16 的列头三层丢了，「该取哪一列」在本章不可判

表 3-16 的列头本来是三层叠在列上：类型层（热拌密级配、稳定碎石、半开级配、排水式开级配）、交通层（中轻／重）、气候层（夏炎热／夏热与夏凉）。源文里只剩交通层一段残片，气候层整行不在，而数据行还要按层位再分两行（深与浅）——两种分法叠不到一起，结果就是每行给出九个格而列头对不上。

结果：九个格无法一对一回填到列头。具体到最常用的一问——「夏炎热区、重交通、上面层的密级配该取第几列」——**在本章内不可判定**。这不是读者没找到，是表本身丢了这一层。

因此本卡对表 3-16 的处置是：可以引用它的**存在**（这确实是普通热拌混合料马歇尔标准的所在地），不可以引用它的**某一列**；要具体列，回原图。

### I.6 三处表号与单位问题

1. **无题表**：施工粘度那张表（p99）没有表号也没有表题，正文却按号引用它〔数值待核原图〕。凡引用裸表，必须写「无题表」。
2. **规范代号混写**：同一部规范的四种写法里有一种是旧代号（p112），其余三处是现行代号。引用时统一到一种，并注明版本待核。
3. **流值两套单位**：标准表用毫米，例题汇总表用零点一毫米，同章并存，差十倍。报流值不带单位，一律退回。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章那道配合比例题的算术能复算，但它的标准行取自那张无出处的末行，正是本卡要拦的对象，所以**不进本段**。下列三场只演「先登记、再算、再否决」，**0 个数值结果**，段内不出现任何数字。

**演练一（正常路径：标准行先登记）**
输入：一份待复核的配合比报告，附一张五项标准行与一张五组试件实测表。
① 先问标准行出自哪张表、有没有交通与层位条件；
② 若出处写明 → 记下五项门槛，进入取初始值；
③ 取初始值时逐项标注来源：哪一项是曲线峰值读的、哪一项是区间中点算的；
④ 输出「标准行可定位／OAC 可算」，仍不输出数值。

**演练二（否决：标准行没有出处）**
输入：报告只写「各项指标满足规范要求」，附的标准行没有表号。
→ 输出「**停**」：本章同时存在两套不同的标准行，出处不写，OAC 没有唯一解；要求补表号与表题，或退回原图。

**演练三（否决：初始值落在窗口外还继续取平均）**
输入：报告给出初始值、窗口两端、以及二者的平均值，且初始值明显高于窗口上界。
→ 输出「**出局**」：本章规则是初始值必须落在窗口内才允许平均；落在外面应当退回改级配，取平均属越界。

**演练四（半覆盖：初始值靠读图）**
输入：报告写明某个量「由图得」，而图未提供。
→ 输出「**不可复现**」：读图值只能作为给定输入被接受，不能声称算出来了；本卡要求把这个量单列一栏并标「读图值」。

**输出表固定五列**：`量｜它是读图值还是复算值｜门槛出处（表号）｜能不能核｜缺什么`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入计算）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 标准行出处（表号＋表题＋**哪一列**） | 文本 | **必需（第 1 步）** | 缺 → 停，OAC 作废 |
| 五项门槛值（空隙率、饱和度、间隙率、稳定度、流值） | 数值组 | 必需 | 缺一项 → 该项不判，记「不可判」 |
| 标准行的适用条件（类型、层位、交通、气候） | 文本 | 必需 | 缺 → 该列不可定位，只能报区间不能报列 |
| 五个沥青用量与对应的五项实测 | 数值表 | 必需 | 缺 → 停 |
| a₁／a₂／a₃ 的取法 | 枚举：读图／给定／复算 | 必需 | 缺 → 一律按「读图值」处理 |
| 配合比表示法 | 枚举：油石比／沥青含量 | 必需 | 缺 → 与标准行的门槛不同量纲，停 |
| 击实次数与读温 | 整数／数值 | 条件必需 | 缺 → 记「未交代」 |
| 流值单位 | 枚举：mm／0.1mm | 条件必需 | 缺 → 退回 |

**步骤**

1. **抄标准行并登记出处**：写表号、表题、适用条件。**这是第 1 步，不是附注。**
2. **统一量纲**：把配合比表示法与标准行的表示法对齐；流值单位统一。
3. **取三个量**：a₁（读图值，必须标注）、a₂、a₃。
4. **算 OAC₁**〔公式待核〕。
5. **求合格窗口**：逐项定上下界，取交集；交集为空或过窄，直接判「该级配不成立」。
6. **算 OAC₂**〔公式待核〕。
7. **验否决票**：OAC₁ 是否落在窗口内。落在外面 → 退出，写「须改级配重做」，**不许取平均**。
8. **取 OAC 并按三条偏移规则调**〔数值待核原图〕；调整幅度要写出来。
9. **写「不推出的项」**：这套配合比是否通过性能检验（水稳定、车辙、低温），本卡不判。

**停判点**

1. **标准行没写出自哪张表** → 停。本章有两套不同的标准行，出处不写，OAC 没有唯一解。
2. **把 a₁ 当成复算值** → 停。它由图得，图缺；只能作读图值接受。
3. **OAC₁ 落在窗口外仍继续取平均** → 停。正确输出是「该级配在本标准下不通过」。
4. **要求本卡给出表 3-16 的某一列** → 停。列头三层丢失，「该取哪一列」在本章不可判，只能回原图。
5. **流值没有单位** → 停（毫米与零点一毫米差十倍）。
6. **要求本卡复现五曲线图或 OAC₁ 的三个读图点** → 停：图缺，只能由表反算或接受给定用量，**不得声称复现**。
7. **标准行的适用条件与工程条件对不上**（层位、交通、气候有一项不符） → 停，不许「就近取一档」。

**输出契约**——两段，先标准后结果：

第一段（标准登记）：`表号｜表题｜适用条件（类型／层位／交通／气候）｜五项门槛｜单位`
第二段（结果）：`量｜值｜读图值还是复算值｜依据页｜能不能核`

表下固定三行：

- **公式状态**：式 3-17／3-18 与三条偏移规则 `〔公式待核〕`；偏移规则的幅度〔数值待核原图〕。
- **不推出的项**：性能检验是否通过、该配合比是否可施工。
- **依据页**：p110（标准表）、p113（流程与三条规则）、p117（例题汇总）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **标准行没有出处**：本章两套标准行互不相同，出处一缺，OAC 就没有唯一解——这是本卡唯一一条「一票否决」。
2. **想用表 3-16 的某一列**：列头三层丢失，回填不唯一；只能用「存在」不能用「某列」。
3. **想把 a₁ 算出来**：它由图取，图缺。凡声称复算出 a₁ 的，都是在替作者补图。
4. **初始值在窗口外还想取平均**：按本章规则应退回改级配。
5. **想用本卡判性能**：水稳定、车辙、低温三项检验是另外的事（K6／K7／K8）。
6. **想要一个「放之四海」的 OAC**：本卡的输出永远绑定一个标准行与一组条件。

**H2 — 用前必须声明**

1. **标准表出处**（表号＋表题＋适用条件），这是第 1 步。
2. **五个量的取法**：哪个是读图值、哪个是复算值。
3. **表示法**（油石比／沥青含量）与**流值单位**，两者都会改数。
4. **公式状态**：式 3-17／3-18〔公式待核〕；偏移规则的幅度〔数值待核原图〕。
5. **本条 OAC 的适用范围**：哪一层、什么交通、什么气候；换一个条件就重算。
6. **本卡未覆盖的**：生产配合比与试铺验证两个阶段（本章只讲目标配合比）。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 图 3-22／3-24 无内容 | OAC₁ 的三个读图点全部不可复现；本卡因此把 a₁ 立为「输入类型」，并要求四类标签 |
| 表 3-16 列头三层丢失 | 标准行列不可定位——这是本卡第 1 步就要登记的字段，不是收尾的注释 |
| 表 3-14 续页全空 | 级配范围取不到，本卡的上游（选级配）要靠 K3；级配一换，OAC 全部作废 |

**不要用本卡做的事**：算体积参数（转 K1）、判 SMA 用量（转 K5）、判水稳定与车辙（转 K7／K6）、给生产配合比。
