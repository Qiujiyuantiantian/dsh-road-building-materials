## R — 原文论点（转述，非摘录）

作者先给两个间隙率的定义：捣实状态下的粗集料骨架间隙率，由装填密度与该档粗集料自身的加权平均密度之相对差给出〔公式待核〕；压实混合料内的粗集料间隙率，由试件的实测密度、粗集料所占比例与上述加权平均密度三者组合给出〔公式待核〕。

然后给出判据：压实状态下混合料的粗集料间隙率必须不大于捣实状态下骨架的间隙率〔公式待核〕。作者把这一条称作判断石与石之间接触成不成立的那道关——若不能满足，说明骨架被玛蹄脂撑开了，可能玛蹄脂过多，也可能骨架间隙过小。他进一步说，这个间隙率实际上控制了玛蹄脂的总体积。

紧接着另起一段：矿料间隙率足够大是加足沥青的前提；沥青饱和度反映用量是否合适；空隙率影响使用性能与耐久性。世界各国的空隙率控制值并列了五国区间，我国规范建议一个区间，并说应按气温与荷载综合确定。

设计流程里，判据的用法是：三组初试级配里挑出同时满足骨架不等式与矿料间隙率要求的那几组，若不止一组，取关键筛孔通过率大的那组。

（见 p122–p123，§第三节 三、1(2)；式 3-19／3-20／3-21 均在 p122）

> **口径提醒**：作者写「关键」二字时用的是「必要」的意思，没有说这一条通过就等于合格。卡片必须把这句话顶到最前面——因为本章的算例正是把必要条件当成了合格判定。

## I — 判据骨架

### I.1 SMA 的判据是成套的，不是一条

| 判据 | 管什么 | 形态 | 本章能不能判 |
|---|---|---|---|
| 粗集料间隙率不等式 | 骨架有没有被撑开 | 混合料值 ≤ 捣实值 | 形态可判，**数值不可复算** |
| 矿料间隙率 | 沥青有没有地方待 | 不小于某值（本章给 16.5% 这个下限〔数值待核原图〕） | 门槛可读 |
| 空隙率 | 落点与耐久性 | 区间 | 本章有两套区间，先声明用哪套 |
| 沥青饱和度 | 用量是否合适 | 区间 | 本章有两套区间，先声明用哪套 |
| 稳定度与流值 | **不是**主指标 | — | 作者自述 SMA 通常稳定度低、流值高 |

**判据只有一条**：不等式通过 ＋ 矿料间隙率达标 ＋ 空隙率与饱和度落区间，四项同时成立才谈得上「这组级配可用」。任何一项单独成立都不构成合格。

### I.2 必要条件被当成合格判定——这是本卡的靶心

不等式 `混合料间隙率 ≤ 捣实间隙率` 的含义只有一句：**骨架没有被玛蹄脂撑开**。它不是一个充分条件：

- 它不检查玛蹄脂够不够（那是矿料间隙率与饱和度的事）；
- 它不检查空隙率落点（那是第三、第四项）；
- 它甚至不检查粗集料本身够不够（那是集料指标的事）。

本章算例的走法是把这一条加上矿料间隙率，就判「满足要求」，并据此选定设计级配；空隙率与饱和度只是「同时能够满足」地被带过，没有逐项列边界。**这就是把必要条件当成了合格判定**：一处通过被读成四项通过。

### I.3 P_ca 必须先声明：两种读法给出相反的设计级配

式 3-20 里有一个比例，符号说明只写「混合料中粒径不小于关键筛孔的粗集料比例」，**没有写分母是什么**。两种读法都通：

| 读法 | 分母 | 后果 |
|---|---|---|
| 甲 | 混合料总质量 | 该比例的数值更小 → 间隙率算得更大 → 不等式更难通过 |
| 乙 | 矿料总质量（不含沥青） | 该比例的数值更大 → 间隙率算得更小 → 更容易通过 |

把两种读法各自代进例题的三组初试级配，得出的设计级配**正好相反**：读法乙下 **No.1** 也过、于是取关键筛孔通过率最大的 **No.1**；读法甲下 No.1 不过、退到 **No.2**〔复算〕。两种读法都能自圆其说，书里也没说哪一种，而书中给的是 No.2。

**所以本卡的规矩是**：`P_ca` 的基准写成显式输入，全程不变；两种读法给出的结论不同时，判「不可判」，不许挑一个报出去。

### I.4 数值止步：表里的间隙率复算不出来

用式 3-20 的两种读法分别复算例题三组，结果与表 3-32 相差 **0.8~3.0 与 4.5~6.4 个百分点**〔复算〕——不是舍入能解释的量级。这说明式与表不同源：要么式里的某个量另有取法，要么表里的数另有来源。

处置只有两条：**接受给定值**，或**判该数不可判**。第三条「自己算一个」不成立。

另有一条不用原图就能用的强证据：式 3-20 对混合料密度是减函数（密度越大，间隙率越小），而表 3-33 三行的间隙率却随密度同向递增〔复算〕。符号检验即可证伪，不需要重新测。

### I.5 两条自检（只证伪、不证真）

1. **捣实间隙率与沥青用量无关**：同一批级配，换油石比，这个值不应变。变了就是测法或级配变了。
2. **矿料间隙率减空隙率应等于沥青体积百分率，饱和度乘间隙率也应等于它**：两条都得闭合。例题的三组差 0.26~0.36 个百分点〔复算〕，超一位小数的报告精度——**这三行数据不可验**。

### I.6 两套标准并存，先声明用哪套

| 项 | 表 3-32 的设计标准 | 表 3-33 的技术指标要求 |
|---|---|---|
| 空隙率 | 一个区间 | 另一个区间（上下界都不同） |
| 沥青饱和度 | 一个区间 | 另一个区间（下界不同） |
| 矿料间隙率 | 同一个下限 | 同 |
| 稳定度 | 未列 | 列了一个下限 |

两套都在转录里，矛盾成立；是否 OCR 丢字待原图。**先声明用哪一套，再谈落点**——两套混用会改变可行域。另有一处表头把筛孔单位印成厘米，按毫米读〔数值待核原图〕，照读会得到荒谬的粒径。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章唯一的 SMA 算例数值不可复算，**不进本段**；本卡也不拿它的体积参数作样本。下列三场只演「先声明、再判、判不了就停」，**0 个数值结果**，段内不出现任何数字。

**演练一（正常路径：先声明基准，再判骨架）**
输入：三组初试级配、每组的关键筛孔通过率、捣实间隙率、以及一份写明基准的粗集料比例。
① 先确认粗集料比例的分母写没写；
② 若写明 → 记下基准，全程不变，代入判据；
③ 判不等式，同时逐项读矿料间隙率、空隙率、饱和度；
④ 输出「四项中哪几项成立」，不输出任何百分率。

**演练二（否决：粗集料比例的基准没写）**
输入：同一份资料，比例只写「粗集料比例」，没有分母。
→ 输出「**停**」：两种读法会给出相反的设计级配，本章未定义基准；要么补测，要么判「不可判」，不许挑一个。

**演练三（否决：不等式通过就判合格）**
输入：报告写「骨架判据满足，故该级配满足要求」，后面没有逐项列矿料间隙率、空隙率、饱和度。
→ 输出「**出局**」：不等式只说明骨架没被撑开，是必要条件；四项要成套判。

**演练四（半覆盖：要求复算间隙率）**
输入：给式与表，要求「用式把表里的间隙率算一遍」。
→ 输出「**不可复算**」：两种读法都差出界，只能接受给定值或判不可判；不许声称复现。

**输出表固定四列**：`判据项｜门槛｜成立与否｜依据（表号／页）`，表头另起一行写「粗集料比例基准＝……」。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 粗集料比例的**基准**（分母） | 枚举：混合料／矿料 | **必需（第 1 步）** | 缺 → 停；两种读法结论相反 |
| 关键筛孔（按公称最大粒径定） | 数值＋单位 | 必需 | 缺 → 停 |
| 三组初试级配与各自的关键筛孔通过率 | 数值表 | 必需 | 缺 → 停 |
| 捣实状态间隙率（每组） | 数值 | 必需 | 缺 → 判据不可用 |
| 矿料间隙率下限 | 数值 | 必需 | 缺 → 该项不判 |
| 空隙率区间与饱和度区间 | 区间＋**用哪套** | 必需 | 缺 → 记「两套并存，未声明」 |
| 压实试件的实测密度 | 数值 | 条件必需 | 缺 → 只能接受给定间隙率 |
| 稳定度与流值 | 数值 | 建议 | 缺 → 不记；记了也不作主判据 |

**步骤**

1. **声明基准**：写清粗集料比例的分母。这是第 1 步，不是脚注。
2. **认筛孔**：按公称最大粒径定关键筛孔；不同规格的粗集料定义不同。
3. **判不等式**（形态判据）〔公式待核〕；数值若不可复算，标「接受给定值」。
4. **逐项读另三项**：矿料间隙率、空隙率、饱和度；先声明用哪套区间。
5. **过两条自检**（I.5）。超容差 → 该行不可验。
6. **成套装判**：四项同时成立才写「可用」；缺一项写「不可判」，不许写「基本满足」。
7. **多组都可用时**：取关键筛孔通过率大的那组（这是作者的取法，不是本卡加的规则）。
8. **写「不推出的项」**：用量定多少（转 K5）、性能是否合格（转 K6／K7）。

**停判点**

1. **粗集料比例的基准没声明** → 停。两种读法给出相反的设计级配，本章未定义。
2. **想把间隙率的数代进判据复算** → 停。两种读法都差出界，只能接受或判不可判；**不得声称复现**。
3. **不等式通过就写「满足要求」** → 停。必要条件不等于合格判定，四项要成套。
4. **要求 SMA 判据门槛** → 能给出（表 3-30 页图已核）：VV 3~4 %、VMA 按公称最大粒径 9.5→17.5／13.2→17.0／16→16.5／19→16.0、VFA 75~85 %、稳定度 ≥5.5 kN（非改性）／≥6.0 kN（改性）、流值 20~50（0.1 mm）。先问改性与否。
5. **把两套空隙率（或两套饱和度）混用** → 停，先声明用哪套。
6. **拿稳定度当 SMA 的主判据** → 停。作者自述 SMA 通常稳定度低、流值高，马歇尔不作主指标。
7. **按表 3-29 表头的厘米读筛孔** → 停，按毫米读。
8. **要求本卡复现设计流程图或三组级配的构造过程** → 停：图缺，只能由表反算或接受给定级配。

**输出契约**——固定格式：

`判据项｜门槛（含出处）｜成立／不成立／不可判｜这一项是必要条件还是合格判定`

表头另起一行：`粗集料比例基准＝（混合料／矿料）`；表下固定三行：

- **公式状态**：式 3-19／3-20／3-21 `〔公式待核〕`；分母口径原文未定义。
- **不推出的项**：最佳用量、性能合格、施工可行性。
- **依据页**：p122（三式与判据）、p123（三项体积参数与马歇尔不是主指标）、p127（例题三组）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **粗集料比例的基准未声明**：这是本卡的入口条件，缺它一切结论都可反转。
2. **想用表里的间隙率算一遍**：式与表不同源，复算差出界；只能接受或判不可判。
3. **想把不等式当合格**：它只说明骨架没被撑开。
4. **不分改性／非改性取 SMA 判据**：表 3-30 分两列，取错即误判。
5. **想拿马歇尔稳定度卡 SMA**：作者明说马歇尔不作 SMA 的主指标；本章算例却这么做了，是它自相矛盾的地方。
6. **想在本章内找到 SMA 的空隙率唯一值**：两套区间并存，先声明。
7. **想引用捣实间隙率的数值做跨级配排名**：它随级配与测法变，本章没有给出可比的统一条件。

**H2 — 用前必须声明**

1. **粗集料比例的分母**（混合料／矿料），全程不变。
2. **关键筛孔**（按规格定）。
3. **用哪一套体积参数标准**（两张表不一致）。
4. **数值状态**：哪些是给定值、哪些是复算值；凡不可复算的写「接受给定」。
5. **判据的成套性**：四项一起判，不许抽一项当结论。
6. **公式状态**：式 3-19／3-20／3-21〔公式待核〕。
