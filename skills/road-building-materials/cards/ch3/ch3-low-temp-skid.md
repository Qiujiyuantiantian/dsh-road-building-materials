## R — 原文论点（转述，非摘录）

低温这一半给了两条判据。

第一条是低温蠕变：小梁跨中加恒定集中荷载，记录变形随时间的发展；曲线分三段，取稳定那一段的速率作为指标〔公式待核〕。作者的方向是：速率越大，低温变形与松弛能力越好，抗裂性越好。

第二条是低温弯曲：在规定低温与规定加载速率下压到断裂，由破坏时的跨中挠度换算成破坏弯拉应变〔公式待核〕。方向同样是越大越好。

抗滑这一半给了两项。微观这一层交给石料的磨光值；宏观这一层交给铺砂法量出的深度，深度由砂的体积与摊平后的圆直径算出〔公式待核〕。作者的方向是：粗集料含量越高，宏观构造越大；开级配与半开级配能做大构造，但空隙率大、耐久性差。

门槛只出现在低温那一节的一张表里：按年极端最低温度分区给下限，普通与改性两档〔数值待核原图〕。构造深度这一项，全章没有给门槛。

（见 p94–p95，§第一节 二、2；p99，构造深度；p111，表 3-19）

> **口径提醒**：这一节是本章最「薄」的一节——两个指标都只有算法与方向，门槛一个取不到、一个根本不存在。卡片能交付的只有「怎么算」与「往哪边好」。

## I — 判据骨架

### I.1 两条低温判据不可互换

| 判据 | 量什么 | 单位 | 条件 | 能不能换 |
|---|---|---|---|---|
| 低温蠕变速率 | 稳定段的变形速率除以应力 | 时间的倒数乘应力的倒数 | 恒载、规定温度 | **不能** |
| 破坏弯拉应变 | 断裂时的最大弯拉应变 | 无量纲（微应变） | 规定低温、规定加载速率 | **不能** |

一个是「慢慢变形有多快」，一个是「压到断能拉多长」。前者与松弛有关，后者与极限变形有关。**两者都「越大越好」，但不可用一个代替另一个，也不可相加。**

蠕变速率还有一个未定义的量：应力怎么取，本章没写。因此它只能作相对比较（同条件、同试件之间），不能跨条件比。

### I.2 表 3-19 的三处结构问题：单位、标签、重复

1. **单位印错**：表头把破坏应变的单位印成微米〔数值待核原图〕。应变是无量纲量，正确写法是微应变（百万分之一）。照微米读，量纲就不成立。
2. **标签与数值个数不符**：九个分区标签，每组只有三个数值〔数值待核原图〕，无法一对一对号。
3. **标签重复**：同一个标签在九个位置里出现两次〔数值待核原图〕，即使个数对上也无法唯一回填。

**处置**：门槛**只报数、不判合格**。要判，回原图定位分区，或另找门槛来源。

### I.3 构造深度：算得出，没有门槛

定义式由砂的体积与摊平圆的直径算出〔公式待核〕。系数可以自证（砂体积比圆面积），但印出的系数是「两位整数＋三位小数」，而按毫升与毫米直接换算得到的是五位数量级——**两者差三个十进位**〔复算〕。所以单位口径（直径按毫米还是厘米）必须回原图核；照印出的系数直接代入，构造深度会小三个十进位。

**本章对这一项只到定义与趋势**：粗集料含量高则构造深度大；开级配能做大但耐久性差。全章没有给构造深度的合格值，也没有给分级。

所以本卡对构造深度的交付是：**能算、能比大小、不能判合格**。

### I.4 磨光值只作准入

磨光值出现在粗集料指标表里，按雨量区分四档下限〔数值待核原图〕。它是**材料准入**指标（这块石料能不能用），不是混合料的抗滑判据。试验方法在本章没有（在试验章）。

**不可把它换算成摩擦系数**，也不可据它判路面的抗滑等级。

### I.5 只判方向的四条

本章能确定给出的，只有方向：

| 指标 | 方向 | 依据 |
|---|---|---|
| 弯拉破坏应变 | 越大 → 低温抗裂越好 | 作者明写 |
| 低温蠕变速率 | 越大，松弛能力越强 | 作者明写 |
| 构造深度 | 越大，宏观构造越好（粗集料越多越大） | 作者明写 |
| 磨光值 | 越大，微观构造越耐久 | 指标表方向 |

**「只判方向」的意思是**：可以判「甲比乙好」，不可以判「甲合格」。凡输出里出现「满足要求」四个字，必须同时写出门槛出处——而本章这两项都没有可用的门槛。

### I.6 与相邻书的边界

抗滑的摩擦系数、水膜、附着与滑水判据，本章 0 处。构造深度在本章只到定义与趋势；宏观构造与抗滑等级的关系在书 3。**本卡不跨书代填**，也不做「构造深度换算成摩擦系数」这类桥。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章的低温门槛分区对不上号，构造深度又没有门槛，两处都不适合当演练样本。下列四场只演「算法走不走得通、方向对不对、门槛在不在」，**0 个数值结果**，段内不出现任何数字。

**演练一（正常路径：算得出、只报方向）**
输入：一份低温性能资料，含小梁尺寸、跨中挠度、断裂时的荷载—挠度曲线，以及另一组的蠕变曲线。
① 先判这两组数据各属哪条判据；
② 按各自的式子算（**不代入数**），核对量纲：一条是无量纲的应变，一条是「时间的倒数乘应力的倒数」；
③ 只给方向判断：同条件下哪个更大；
④ 输出「两条判据分别怎么读」，不写合格与否。

**演练二（否决：按微米读应变）**
输入：报告把破坏应变的单位写成微米，并用它和另一个长度量相比。
→ 输出「**停**」：应变无量纲，单位应为微应变；按微米读量纲不成立。

**演练三（否决：拿构造深度判抗滑合格）**
输入：报告写「构造深度满足抗滑要求」，未给门槛。
→ 输出「**出局**」：本章对构造深度没有门槛；抗滑判据在另一本书，不许代填。

**演练四（半覆盖：要按分区取低温门槛）**
输入：要求「按气候分区查出破坏应变的下限」。
→ 输出「**不可定位**」：标签九个、数值三组，且有一个标签重复；只能报数，不能判合格。

**输出表固定四列**：`指标｜算得出吗｜门槛在哪｜能不能判合格`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 判据类型（蠕变／弯曲） | 枚举 | **必需（第 1 步）** | 缺 → 停，两条不可混 |
| 试件尺寸（小梁） | 数值组 | 必需 | 缺 → 弯曲那条算不了 |
| 跨中挠度／应变随时间 | 数值 | 必需 | 缺 → 停 |
| 试验温度与加载速率 | 数值 | 必需 | 缺 → 不可比 |
| 年极端最低温度（定分区） | 数值 | 条件必需 | 缺 → 门槛不可定位 |
| 砂的体积与摊平圆直径 | 数值 | 条件必需（算构造深度） | 缺 → 停 |
| 门槛出处 | 表号 | 必需（若要判合格） | 缺 → 不判合格 |

**步骤**

1. **认判据**：先分清是蠕变还是弯曲，两条的量纲不同。
2. **算**：各按自己的式子〔公式待核〕；应变按无量纲处理。
3. **核量纲**：应变无量纲；构造深度的系数可自证〔复算〕。
4. **比方向**：同条件、同试件之间比大小；跨条件不比。
5. **找门槛**：表 3-19 只能报数（标签与数值个数不符且重复）；构造深度无门槛。
6. **写「不推出的项」**：是否合格、摩擦系数、抗滑等级。

**停判点**

1. **把破坏应变的单位按微米读** → 停。应变是无量纲量，单位应为微应变。
2. **把蠕变速率与破坏应变互换或相加** → 停。两者量的不是同一件事。
3. **拿构造深度判抗滑合格** → 停。本章无门槛，抗滑判据在书 3。
4. **按表 3-19 的分区标签取门槛** → 停。九个标签对三组数值，且有一个重复，不可定位；只能报数。
5. **用磨光值反推摩擦系数** → 停。磨光值只作材料准入。
6. **跨温度或跨加载速率比应变** → 停。条件不同不可比。
7. **要求本卡给出构造深度的合格值** → 停：本章 0 处。
8. **按印出的系数直接代入算构造深度** → 停。系数与单位口径差三个十进位〔复算〕，回原图核后再算。

**输出契约**——固定格式：

`指标｜值（单位）｜条件｜门槛出处｜方向（大好还是小好）｜能不能判合格`

表下固定三行：

- **公式状态**：式 3-3／3-4／3-6 `〔公式待核〕`；蠕变速率的应力取法本章未定义。
- **不推出的项**：合格与否、摩擦系数、抗滑等级、长期开裂。
- **依据页**：p94（蠕变）、p95（弯曲）、p99（构造深度）、p111（表 3-19）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **想判低温合格**：分区不可定位，门槛只能报数。
2. **想判抗滑合格**：本章对构造深度没有门槛，摩擦系数不在本章。
3. **想把微米当应变的单位**：量纲不成立。
4. **想用蠕变速率代替破坏应变**：两者量的不是一件事。
5. **想用磨光值推摩擦系数**：只作准入。
6. **想跨条件比大小**：温度、速率、试件尺寸任一不同就不可比。
7. **想引用表 3-19 的某一档门槛**：标签重复、个数不符，回填不唯一。

**H2 — 用前必须声明**

1. **判据类型**（蠕变／弯曲）与它对应的条件。
2. **单位口径**：应变无量纲，按微应变写。
3. **门槛状态**：表 3-19 只报数；构造深度无门槛。
4. **方向**：越大越好（正向指标），不要写成「越小越好」。
5. **公式状态**：式 3-3／3-4／3-6〔公式待核〕。
6. **跨书边界**：抗滑判据在书 3，本卡不代填。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |

| 表 3-19 标签与数值个数不符、标签重复 | 低温门槛只能报数；本卡的交付从「判合格」降为「判方向」 |
| 构造深度全章无门槛 | 抗滑这一半只能算、不能判；这是本卡 importance 只给 medium 的主因 |
