## R — 原文论点（转述，非摘录）

作者的顺序是：选类型、定范围、测原始数据、定各档比例、算合成级配、比对范围、不合就调。

定比例给了两条路，计算法与图解法。图解法四步：在相邻两档集料的级配曲线重叠段作一条垂线，使它在两条曲线上截出的纵坐标相等；该垂线与对角线交于一点；过交点作水平线；水平线在纵轴上截出的长度就是这一档的用量。例题给出的四个用量是整数，作者直接写「由图得」。

合成级配的算法没有给式号，只有一张逐格相乘再相加的表（表 3-22）。判定规则有三句：合成曲线要落在设计范围里；穿过范围带的次数不能多；调来调去之后如果还剩两个以上筛孔在范围外，就得换料或推翻重来。

例题的走法是：先按估计比例合成，发现最细一档筛孔超出上限，于是减一档、加一档、减矿粉，再合成，全部落进范围，并说「接近中值」。

（见 p111–p112，§第二节 四、1；表 3-21／3-22 在 p114／p116；图 3-23 在 p115）

> **口径提醒**：这一节里「能算的」与「不能算的」分得很干净——加权合成能逐格复算，图解法一个数都复现不出来。卡片必须把这条界线画在段首，否则读者会把四个整数当成自己的计算结果。

## I — 判据骨架

### I.1 加权合成：没有式号，但只有一种算法

合成级配的每一格都是「各档在该筛孔的通过率 × 该档比例」之和，再除以比例之和。本章按百分比给比例，所以分母是百分之百。

**本章无式号**，写法只能是：`合成通过率 = Σ（该档通过率 × 该档比例）`〔公式待核〕。表 3-22 是唯一的逐格示范，可以照着核，但不能引一个「式 3-x」。

三个易错处，表 3-22 全部踩到：

1. **调整前后的两套比例混在一张表里**（前者在括号外、后者在括号内），逐格乘的时候必须一整列用同一套；
2. **中间档的通过率在调整后会变**，不是只改比例就行；
3. **最细一档的矿粉量单独一变，其余筛孔全跟着变**。

### I.2 三处修正（引用前必须先改）

| 位置 | 书中记 | 应为 | 依据 |
|---|---|---|---|
| 表 3-22 调整列的关键筛孔 | 64.2 | **64.84** | 该列分量和与 64.2 不符，且 64.2 恰是旧比例算出的值〔复算〕；成因（印错／OCR）待原图 |
| 表 3-22 调整列最细档 | 11.3 | **11.09** | 同列另有两格可指认的偏差，且合成值反证〔复算〕；成因待原图 |
| 表 3-21 的关键筛孔中值 | 57 | **58** | 区间上下限之和的一半〔复算〕；相邻档的中值是四舍五入，故 57 不是舍入 |

三处都不改结论（越界判定不变），但会带进 0.6、0.2、1.0 三个偏差。引用时写「书中记 X，复算 Y」。

### I.3 判定：三个条件，第三条件是退改闸

| 条件 | 判法 | 失败处置 |
|---|---|---|
| 每孔落范围内 | 逐孔比上下限 | 有一孔越界 → 调比例 |
| 不得过多犬牙交错 | 曲线是否反复穿越范围带 | 反复穿越 → 调比例（无量化门槛） |
| 反复调整后仍有两个以上筛孔越界 | 数越界筛孔个数 | **换料或重新设计** |

第三条件有一个必须先声明的歧义：**「两个以上」按严格大于二，还是按大于等于二？**本章没有写明。卡里的处置是：**声明取哪一种，并记越界清单**（哪几个筛孔、越多少）。不声明，这条闸门就不确定。

另外要注意：例题只越了一个筛孔，它是**边界样本**，不是反例——不能拿它证明「越一个孔可以放过」。

### I.4 图解法：只能接受，不能复现

作图四步在 p115 可指认，但最后一步落在图 3-23 上，而图只有图注。

因此本卡把「四个用量」定性为**给定值**：可以拿它继续算合成级配，但不许说「我按图解法求出了用量」。凡报告写「图解法求得」而没附原图，一律记「不可复现」。

**可替代的部分**：合成校核（I.1）不依赖图，可以完整复算；所以「给定用量 → 验算是否落范围」这条链是通的，「原始数据 → 求用量」这条链在本章是断的。

### I.5 中值与偏置：方向会写反

两条偏好，作者写在同一页：合成曲线宜接近范围中限，尤其最细档、中间档与关键档三个筛孔；交通量大、轴载重的路可偏向范围下限；中小交通量或人行道宜偏向上限。

**「偏下」指通过率更低（更粗），不是用量更低。**这一条必须消歧，否则会把「粗一点」写成「少用一点」。

中值本身也要复算：上下限之和的一半，本章有一处印成 57（应为 58〔复算〕）。

### I.6 表 3-14 有两层问题，且要分清

1. **表在，内容不在**：正文表里现存三族（热拌密级配、稳定碎石、半开级配），续页本该接上旧代号密级配与排水式开级配，而那一页表体全空——于是这两族的范围取不到。
2. **引用本身也错**：正文有一处把级配范围指到密度空隙率那张表（表 3-15），而范围实际在表 3-14——双错：引用错＋目标内容缺。

**一条必须纠正的旧说法**：不能因为「表 3-14 缺了一族」就推出「SMA 的范围也缺」。SMA 的级配范围另有表 3-29，完整可用（表头单位印作厘米，是印误，按毫米读〔数值待核原图〕）。缺的只有 AC-I 系与 OGFC 系。

### I.7 一处与集料指标有关的方向错（只登记，不在本卡判）

同章两张表对同一指标给了相反方向：细集料那张写「不小于十二」，粗集料那张写「不大于十二」〔数值待核原图〕。四个值随公路等级降低而增大，方向只可能是「不大于」。**照抄会把不合格料读成合格**。本卡只登记，判据归本书集料章（粗集料那张表），不属 K1–K8 任何一张。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章那道配合比例题的四个集料用量是图解法的产物，图缺，因此**只作给定值**，不作演练样本。下列四场只演「先算合成、再判退、判不了就停」，**0 个数值结果**，段内不出现任何数字。

**演练一（正常路径：给定比例，验算落范围）**
输入：若干档集料的筛分表、一份设计范围、一组给定的用量比例。
① 逐孔加权求和，一整列只用同一套比例；
② 每孔比上下限，记越界清单（哪几孔、越多少）；
③ 数越界孔数，对照退改闸；
④ 输出「全部落范围／需调比例／须换料」，不输出任何通过率。

**演练二（否决：两套比例混用）**
输入：一张合成表，括号内外是调整前后的两套比例，某几格取了括号外、某几格取了括号内。
→ 输出「**停**」：一整列必须同源；混用会造出一个既不属调整前也不属调整后的级配。

**演练三（否决：越一个孔就换料，或越三孔还继续调）**
输入甲：只有一个筛孔越界，报告直接判「换料」。
→ 输出「**过头**」：例题就是只越一孔的边界样本，先调比例。
输入乙：反复调整后仍有三个筛孔越界，报告继续微调比例。
→ 输出「**出局**」：应触发退改闸，换料或重新设计。

**演练四（半覆盖：要求复现图解法）**
输入：只给各档筛分曲线与设计范围，要求「按图解法求出各档用量」。
→ 输出「**不可复现**」：作图最后一步落在缺失的图上；只能接受给定用量，或改走计算法并由本卡验算。

**输出表固定四列**：`筛孔｜合成值｜范围｜判定（落内／越界）`，表下附越界清单与「用了几分法」。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入计算）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 各档集料的筛分表 | 数值表 | 必需 | 缺 → 停 |
| 各档用量比例 | 数值组 | 必需 | 缺 → 只能接受给定值，不许反求 |
| 设计级配范围（表号＋族名） | 数值区间表 | 必需 | 缺 → 停；表 3-14 的 AC-I／OGFC 系取不到，须另找来源 |
| 比例的来源 | 枚举：图解法／计算法／给定 | 必需 | 缺 → 按「给定」处理并记「不可复现」 |
| 筛孔系列与单位 | 枚举 | 必需 | 缺 → 停（本章有一张表头印厘米） |
| 「两个以上」的取法 | 枚举：>2／≥2 | 必需 | 缺 → 退改闸不确定，先声明 |
| 交通量等级 | 枚举 | 条件必需 | 缺 → 偏置方向不可判 |

**步骤**

1. **认族认表**：先确认设计范围出自哪张表、哪一族；AC-I 系与 OGFC 系在表 3-14 里取不到，写「不可取」。
2. **认单位**：筛孔毫米、比例百分数；本章有一张表头印厘米，按毫米读。
3. **逐孔加权求和**〔公式待核〕，一整列只用同一套比例。
4. **逐孔判定**，记越界清单。
5. **数越界孔数**，对照退改闸（先声明 >2 还是 ≥2）。
6. **若需调整**：重算全列（中档集料的通过率也会变），不许只改一格。
7. **写偏置**：贴近中限还是偏上／偏下，并说明「偏下＝更粗」。
8. **写「不推出的项」**：这条级配是否通过马歇尔、是否耐磨耗，本卡不判。

**停判点**

1. **合成级配用两套比例混算** → 停。
2. **连续两个筛孔越界仍只调比例**（或已触发退改闸仍微调） → 停，按声明取法判「须换料」。
3. **去表 3-14 查 AC-I 系或 OGFC 系范围** → 停：续页表体全空，该范围不可取（不是不存在，是取不到）。
4. **声称复现了图解法** → 停：图缺，只能由表反算或接受给定用量，**不得声称复现**。
5. **把中值 57 照抄** → 停，按 58 复算〔复算〕。
6. **把「偏下」理解成用量更低** → 停，偏下指通过率更低。
7. **引用表 3-22 的 64.2／11.3 不改** → 停，按 64.84／11.09〔复算〕并标成因待原图。
8. **拿细集料坚固性判合格** → 停。转录里 Directions 印「≥12」，但**全书 OCR 的 ≯/≮ 都是 0 次**，这个「≥」很可能是「≯」被折过来的——**方向待原图核，不许按 ≥ 也不许按 ≤ 直接判**。

**输出契约**——两段：

第一段（合成表）：`筛孔｜各档分量｜合成值｜范围｜判定`
第二段（结论）：`越界孔数｜退改闸是否触发｜比例来源（图／算／给定）｜依据页`

表下固定三行：

- **公式状态**：加权合成无式号，写法 `〔公式待核〕`；图解法四步不可复现。
- **不推出的项**：是否满足马歇尔标准（K2）、骨架是否成立（K4）。
- **依据页**：p111（两条路与退改闸）、p115（作图四步与四个用量）、p116（表 3-22）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **想复现图解法**：最后一步落在缺失的图上，只能接受给定用量。
2. **想从表 3-14 取 AC-I 系或 OGFC 系范围**：续页表体全空；可核的只有正文给出的那一族。
3. **想用「两个以上越界」而不声明取法**：>2 与 ≥2 会给出不同的退改结论。
4. **想拿只越一孔的例题当「可以放过」的依据**：它是边界样本，不是反例。
5. **想用本卡判级配好不好**：本卡只判「落不落范围」，不判「这族级配适不适合这条路的层位」。
6. **想跳过单位核对**：本章有表头印厘米、流值两套单位，单位错一次数就错十倍。

**H2 — 用前必须声明**

1. **范围表的出处与族名**（表号＋族），并对缺的那两族写「不可取」。
2. **比例的来源**（图解法／计算法／给定），图解法一律标「不可复现」。
3. **「两个以上」的取法**（>2 还是 ≥2）与越界清单。
4. **单位**：筛孔毫米、比例百分数。
5. **公式状态**：合成算法无式号，标〔公式待核〕。
6. **两处更正值**：64.84 与 11.09〔复算〕，成因待原图；中值 58。
