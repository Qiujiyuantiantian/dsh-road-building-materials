## R — 原文论点（转述，非摘录）

作者先用摩尔—库仑的框架说强度由两部分构成：颗粒之间的嵌锁（内摩阻）与沥青的粘结（内聚力）〔公式待核〕。然后交代马歇尔这套指标的来路：它是经验性的，与路面实际抗车辙表现的相关性并不好；两句话之后又补一句更狠的——各项指标都合格的混合料，在实际路面上仍然可能出现车辙。

接着介绍车辙试验：板块试件在规定温度下，试验轮以固定频率沿同一轨迹反复行走，量试件表面的下陷；以产生一毫米下陷所需的行走次数作为动稳定度〔公式待核〕。式中含两个试验时刻、与它们各自对应的下陷量、单位时间的往返次数，以及两个修正系数。

再往下是因素分析：集料的棱角与表面构造决定嵌锁；沥青的高温粘度决定粘结；作者引国外研究给了一个分量比例〔数值待核原图〕。关于用量，他给了一句很有分量的话：就高温表现而言，用多少沥青，其分量可能压过用哪一种沥青。最后给两条方向：细粒式与中粒式可适当减油以利抗车辙；粗粒式与开级配不能简单靠减油。

（见 p92–p93，§第一节 二、1；式 3-2 在 p93；表 3-18 在 p110）

> **口径提醒**：这一节的两把尺不是「粗尺与细尺」，而是「经验指标与试验指标」。作者否的是「拿马歇尔当主尺」，不是「做马歇尔试验」——这半句必须留着。

## I — 判据骨架

### I.1 两把尺分工表

| 尺 | 指标 | 量什么 | 在本章的地位 | 能不能判合格 |
|---|---|---|---|---|
| 马歇尔 | 稳定度与流值 | 规定温度下的抗压能力与变形 | 经验指标，与抗车辙相关性差 | 表 3-16 给了门槛，但**只能判这一项**（列不可判，见 K2） |
| 车辙 | 动稳定度 | 产生单位深度所需的行走次数 | 判定指标（高等级路上中面层要做） | 表 3-18 给门槛，**但分区对不上号** |

**判据只有一条**：两把尺之间**没有换算**。稳定度合格推不出不车辙；动稳定度合格也不能反推稳定度。

### I.2 动稳定度的式子与它自带的缺口

式子由两组「时刻—下陷量」、单位时间的往返次数与两个修正系数组成〔公式待核〕。条件在本章可指认：两个时刻取 45 min 与 60 min，频率取 42 次/min〔数值待核原图〕。

缺口有两处：

1. **两个修正系数没有取法**——本章只说这两个系数分别对应试验机与试样，没给怎么定。
2. **上式只能算一个数，不能判合格**——判合格要门槛，而门槛的分区对不上号（见 I.3）。

### I.3 表 3-18：九个分区标签，五个数值

这是本卡最关键的一处缺陷。表中给出九个气候分区标签（三档温度 × 若干子区），而每个类型行只有五个数值〔数值待核原图〕。

后果有三层：

1. **无法一对一对号**：九个标签配五个值，回填不唯一。
2. **按顺序硬对会出错**：若照标签顺序从左往右填，得到的分区门槛与算例自己用的门槛不一致——算例用的是一千次那一档，硬对下来同一分区是八百〔数值待核原图〕〔复算〕。
3. **因此本章的算例门槛无法核**：它用的分区门槛在表里定位不到。

**处置**：只报动稳定度的数，**不判合格**；要判，回原图定位分区，或另找门槛来源。

### I.4 相关性差这件事，作者写了两处

一处在前（马歇尔是经验指标、与抗车辙相关性不好、全合格仍可能车辙），一处在 SMA 段（SMA 的稳定度通常偏低、流值偏高，马歇尔不作为主要指标，马歇尔在这一段的任务只是测体积参数、定级配）。

两处合起来给出本卡的立场：**马歇尔可以留着当工序卡，不能当验收尺**。这不是本卡加的判断，是作者的。

### I.5 温度与速率：只给方向，不给函数

作者给两条定性结论：温度升高、加载变慢，都会让粘结成分掉得比摩阻成分多。本章没有函数、没有三轴条件、没有试验数据。

**用处只有一个**：判断「两个动稳定度能不能直接比」。若温度或加载速率不同，比较不成立。**不许外推数值**。

（式 3-1 的四个符号在本章「有式无数」，只作机理，不作模型。）

### I.6 用量与品种：方向可用，量不可推

作者把这条写得很直接：就高温稳定性而言，用量的影响可能压过沥青品种。随后给两条方向：细粒式与中粒式可适当减油；粗粒式与开级配不能简单减油。

**用法**：只给方向，不给量。任何减量必须由本工程的车辙试验反推，不许按「细粒式减一点」这类话去调。

### I.7 一个符号三个意思（MS）

同一章里这三个字母有三种用法：马歇尔稳定度（本卡这一把尺）、微表处的型号代号（第三节后）、残留稳定度的前缀（水稳定那一节）。三者不可互认。**看到 MS 先认上下文**，尤其是型号代号那一种——它不是稳定度。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章的车辙算例门槛定位不到（分区对不上号），本卡不拿它当演练样本。下列三场只演「哪把尺管什么、能不能判、判不了就停」，**0 个数值结果**，段内不出现任何数字。

**演练一（正常路径：两把尺分开报）**
输入：一份混合料高温性能资料，含马歇尔稳定度与流值、含车辙试验的动稳定度与试验条件。
① 先判两个指标各属哪把尺；
② 记下动稳定度的试验条件（温度、两个时刻、频率、修正系数有没有给）；
③ 报两个数，各带条件；**不写「合格」**；
④ 输出「两把尺的数都报了／缺哪一把」。

**演练二（否决：拿稳定度推定不车辙）**
输入：报告写「马歇尔稳定度满足要求，故高温稳定性满足要求」，没有车辙试验。
→ 输出「**出局**」：两把尺没有换算；作者自己写了「都达标仍可能车辙」。

**演练三（否决：按标签顺序对号取门槛）**
输入：报告按气候分区的书写顺序，把表里的数值从左往右对到九个标签上。
→ 输出「**停**」：九个标签对五个值，顺序对号不唯一；本章算例的门槛就是这么对出来的，与它自己用的门槛不一致。

**演练四（半覆盖：只给动稳定度，没给条件）**
输入：只给一个动稳定度数值，没有温度、没有两个时刻、没有修正系数。
→ 输出「**不可比**」：这个数不可与其他数并列，也不可判合格。

**输出表固定四列**：`指标｜属哪把尺｜条件齐不齐｜本章能不能判合格`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 马歇尔稳定度与流值（含读温、单位） | 数值 | 建议 | 缺 → 少一把尺，明写 |
| 动稳定度（含试验温度、两个时刻、频率） | 数值＋条件 | 必需（若要判高温） | 缺 → 不许判高温 |
| 两个修正系数的取法 | 数值／文本 | 条件必需 | 缺 → 记「修正未交代」 |
| 气候分区（一级温度区＋子区） | 编码 | 必需（若要判合格） | 缺 → 只能报数 |
| 门槛出处（表号） | 文本 | 必需（若要判合格） | 缺 → 不判合格 |
| 沥青品种与用量 | 文本／数值 | 建议 | 缺 → 因素分析不可做 |

**步骤**

1. **分尺**：把稳定度、流值归到马歇尔；把动稳定度归到车辙。
2. **认条件**：动稳定度的温度、两个时刻、频率、修正系数逐项登记。
3. **报数**：两个数各带条件，不合并、不加权。
4. **判合格的入口**：只有拿到可定位的分区门槛才允许判；表 3-18 对不上号 → 不判。
5. **查相关性**：若报告用稳定度代替车辙结论，直接判越界。
6. **写「不推出的项」**：实际路面的车辙深度、使用寿命、温度与速率的定量影响。

**停判点**

1. **拿马歇尔稳定度当唯一判据** → 停。两把尺无换算，作者写明相关性不好。
2. **按表 3-18 的标签顺序对号取门槛** → 停。九个标签对五个值，顺序对号不唯一。
3. **动稳定度不带试验条件就并列比较** → 停。
4. **要求本卡给温度或加载速率对动稳定度的定量影响** → 停：本章只有定性方向。
5. **要求本卡给两个修正系数的取法** → 停：本章只写有这两个系数，没给取法。
6. **想按「细粒式可减油」直接减** → 停：只有方向，没有量；减多少要由本工程车辙试验反推。
7. **把 MS 当稳定度用** → 停：同章三种用法，先认上下文。

**输出契约**——固定格式：

`指标｜值（单位）｜试验条件｜属哪把尺｜本章能不能判合格`

表下固定三行：

- **公式状态**：式 3-1／3-2 `〔公式待核〕`；修正系数无取法。
- **不推出的项**：路面车辙深度、寿命、温度与速率的定量关系。
- **依据页**：p92（经验指标与相关性）、p93（式 3-2 与用量方向）、p110（表 3-18）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **想用一个指标代替另一个**：两把尺之间没有换算，这是本卡的底线。
2. **想按表 3-18 判合格**：分区标签与数值个数不符，定位不到。
3. **想用稳定度高的混合料推定不车辙**：作者自己否了这条路。
4. **想跨温度或跨加载速率比动稳定度**：本章只给方向，没给修正函数。
5. **想把「可减油」当成定量的减油幅度**：只有方向。
6. **想把 MS 当稳定度**：三种用法并存。

**H2 — 用前必须声明**

1. **哪把尺**（马歇尔／车辙），以及这一把尺在本章能判到什么程度。
2. **试验条件**：温度、两个时刻、频率、修正系数。
3. **门槛出处**；取不到就写「不判」。
4. **气候分区的编码口径**（一级区与子区）。
5. **公式状态**：式 3-1／3-2〔公式待核〕。
6. **本卡的立场**：否的是「当主尺」，不否「做试验」。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|
| 表 3-18 九分区对五值 | 动稳定度只能报数，判不了合格；算例的门槛无法核 |
| 图 3-9／3-10 无内容 | 下陷随时间的发展、厚度与下陷的关系都不可看，只能靠文字 |
| 无模量、无主曲线 | 高温性能与模量之间本章没有桥，本卡不跨 |

**不要用本卡做的事**：判水稳定（转 K7）、判低温（转 K8）、判 SMA 用量（转 K5）、给车辙深度预估。
