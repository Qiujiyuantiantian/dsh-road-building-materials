## R — 原文论点（转述，非摘录）

作者先立一个原则：SMA 的用量不是「取一个最优值」，而是被两头夹出来的。上界由谢伦堡析漏试验给——沥青多了会滴漏、会泛油；下界由肯塔堡飞散试验给——沥青少了会掉粒、会飞散。中间那一段由空隙率来定落点：热的地方取区间上沿，冷的地方取中下沿。

析漏试验的做法是：拌好的试样装进烧杯，在规定温度的烘箱里静置一段时间，称量倒出后杯壁粘住的那点玛蹄脂，算成损失百分率〔公式待核〕。温度分两档，改性与否不同。作者还补了一句关键的气候限定：他引的那套分级（好、可接受、不合格三档）适用于气候温和的地区；在我国炎热地区，析漏量到某一个值时用量已经偏高〔数值待核原图〕。

飞散试验把成型好的试件放进洛杉矶磨耗机里撞，以损失质量百分率计〔公式待核〕。两套条件：标准的一套是常温加长时间水养；多雨潮湿地区另有一套高温条件。

流程上，先按接近门槛下限的初试油石比成型试件，再以固定步长上下各取一点、做三组，画曲线，按设计空隙率定最佳油石比。

（见 p123–p124，§第三节 三、1(3)(4)；p126 的用量调整段）

> **口径提醒**：这一节里「条件」与「门槛」是绑在一起的。温度两档、养生两套、气候两条，任何一条换了，门槛就不再是那个门槛。作者写「这个标准适合温和地区」时，说的不是客气话。

## I — 判据骨架

### I.1 三个试验各管一头，谁也不替代谁

| 试验 | 管哪一头 | 判据形态 | 本章能不能给出门槛 |
|---|---|---|---|
| 谢伦堡析漏 | **上限**（不许滴漏、不许泛油） | 损失量不大于某值 | **不能**：表 3-30 缺；引用的分级带气候限定 |
| 肯塔堡飞散 | **下限**（不许掉粒） | 损失量不大于某值（同向小者好） | **不能**：门槛表缺 |
| 马歇尔体积参数 | **落点**（定在哪一段） | 空隙率落区间 | 能，但有两套区间，先声明用哪套 |
| 车辙 | 补充验证 | 动稳定度不小于某值 | **不能**：表 3-30 缺 |

**判据只有一条**：上界与下界都要有，中间靠空隙率落点；三个试验缺一个，用量就没有唯一解。反过来说——**只有一个方向的判据（只封顶或只托底）不构成用量判据**。

### I.3 门槛取不到，这是本章的第一缺陷

表 3-30 被正文引用三次（p123、p126 两处），但源文里既没有表题也没有表体。结果是：

- 析漏门槛取不到 → 上限只能靠作者转述的德国分级（还带气候限定）；
- 飞散门槛取不到 → 下限没有数；
- 稳定度门槛取不到 → 与「马歇尔不作 SMA 主指标」那句话撞在一起，不知道以哪个为准。

**处置**：凡需要这三个门槛的一步，一律写「门槛不可取」，不许用相邻表、相邻国家的值代填。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章那道 SMA 例题的四处矛盾全在数值层，**不进本段**；本卡也不拿它的任何体积参数当样本。下列三场只演「三头是否都在、门槛在不在、判不了就停」，**0 个数值结果**，段内不出现任何数字。

**演练一（正常路径：三头都在）**
输入：一份 SMA 用量设计资料，含析漏试验、飞散试验、以及三组不同油石比的试件体积参数。
① 先判三个试验是否都在——上界、下界、落点各一个；
② 再问门槛出自哪张表、是否带气候或养生条件；
③ 若门槛与条件都可指认 → 按「上界减下界得可行段、空隙率在段内定落点」的顺序读；
④ 输出「三头齐／缺哪一头」，不输出任何油石比。

**演练二（否决：只报一个区间）**
输入：报告写「各项指标都满足，故油石比在这个区间内」，附一张只有三条曲线的图，没有逐项边界。
→ 输出「**停**」：区间必须由逐约束定向后再取交集得到；没有逐项边界就没有区间；交集为空或过窄，应判该级配不成立，不许报一个「大致范围」。

**演练三（否决：只剩一个方向）**
输入：报告只用析漏试验封顶，说「用量不超过某个值即可」。
→ 输出「**出局**」：只有上界没有下界，用量没有唯一解；飞散这一头必须补。

**演练四（半覆盖：门槛表缺）**
输入：要求「按本章给出 SMA 的析漏门槛与飞散门槛」。
→ 输出「**不可取**」：门槛表整表缺失，只能给「需要有这个门槛」与「门槛带条件」，给不出数；不许用相邻表代填。

**输出表固定四列**：`试验｜管哪一头｜门槛出处｜本章能不能取`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入判定）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 析漏试验结果（含温度、时长） | 数值＋条件 | 必需 | 缺 → 上界没有，停 |
| 飞散试验结果（含温度、养生时长） | 数值＋条件 | 必需 | 缺 → 下界没有，停 |
| 三组油石比对应的空隙率 | 数值表 | 必需 | 缺 → 落点不可定 |
| 空隙率目标区间＋**用哪一套** | 区间＋枚举 | 必需 | 缺 → 停（本章有两套） |
| 析漏门槛、飞散门槛的**出处** | 表号 | 必需 | 缺 → 判「门槛不可取」 |
| 气候区（炎热／温和等） | 枚举 | 条件必需 | 缺 → 门槛的气候前提失配，记一处 |
| 初试油石比的取法 | 枚举：门槛附近／给定 | 条件必需 | 缺 → 记「取法失去依据」 |

**步骤**

1. **点三头**：上界、下界、落点，各对应哪个试验。缺一个就停。
2. **查门槛出处**：三个门槛各出自哪张表。表 3-30 缺 → 写「门槛不可取」。
3. **对条件**：温度、养生时长、气候区与门槛的标定条件是否一致；不一致记「条件失配」。
4. **定可行段**：上界与下界各自成一条线，段内即候选；段为空 → 判该级配不成立。
5. **在段内定落点**：按空隙率区间取上沿或中下沿（炎热取上沿、寒冷取中下沿）。
6. **写「不推出的项」**：性能是否合格（门槛缺）、施工是否可行。

**停判点**（前四条是本卡的必写项）

1. **要把混合料粗集料间隙率的三个值代进判据** → **停**。两种读法都算不出，只能接受给定值或判不可判。
2. **要报「满足要求的油石比区间」** → **停**。先逐约束定方向、再取交集；交集为空或过窄即判该级配不成立，不许报印象区间。
3. **要引「各项性能均满足」** → **停**。先逐行对门槛；本章例题里就有一行低于门槛却被写成满足。
4. **要写设计油石比** → **停**。它的依据是一个不成立的区间。
5. **要求本卡给出析漏或飞散的门槛值** → 停：表 3-30 整表缺失，**不可用**。
6. **把德国分级直搬炎热区** → 停：门槛带气候，作者自己写明了这条限定。
7. **把两套飞散条件混用** → 停：常温长养与高温长养是两套，混了就不是同一个指标。
8. **要求本卡复现体积参数与油石比的关系曲线** → 停：图缺，只能由表反算或接受给定用量，**不得声称复现**。

**输出契约**——两段：

第一段（三头）：`试验｜管哪一头｜条件（温度／时长／气候）｜门槛出处｜能不能取`
第二段（结论）：`可行段有没有｜落点依据｜哪些数是禁引｜依据页`

表下固定三行：

- **公式状态**：式 3-22／3-23 `〔公式待核〕`；门槛值一律不交付。
- **不推出的项**：用量是否合格、性能是否达标、能否施工。
- **依据页**：p123（析漏与气候限定）、p124（飞散两套条件）、p126（用量调整步骤）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **要引用例题 3-2 的任何数值**：**引其数值即越界。**它的间隙率复算不出、体积参数不自洽、区间不存在、有一行低于门槛却写满足、设计油石比建立在这些之上——五类都不许进任何结论。
2. **想按表 3-30 取门槛**：整表缺失，引用即越界。
3. **只有一个方向的判据**：只封顶或只托底，都不构成用量判据。
4. **想把温和地区的分级搬到炎热地区**：作者自己写了这条限定。
5. **想用本卡判 SMA 骨架**：那是 K4 的事，判据不同、口径不同。
6. **想报一个「大致区间」而不逐约束定界**：区间必须由交集得出，不是目测。
7. **想把两套空隙率标准混用**：先声明用哪套，再谈落点。

**H2 — 用前必须声明**

1. **三个试验各自的条件**（温度、时长、养生方式），条件变了指标就变了。
2. **门槛的出处与它的气候前提**；取不到就写「不可取」。
3. **空隙率用哪一套区间**。
4. **数值状态**：哪些是给定值、哪些是复算值、哪些是禁引。
5. **公式状态**：式 3-22／3-23〔公式待核〕。
6. **本卡与例题的分工**：流程可借，数值不可借。
