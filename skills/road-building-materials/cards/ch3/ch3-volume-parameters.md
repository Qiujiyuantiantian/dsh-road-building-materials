## R — 原文论点（转述，非摘录）

作者把压实混合料的体积关系拆成「两个入口、四个出口」。入口之一是把矿料与沥青全当实体、不含任何空隙时算出的理论最大密度；入口之二是试件自身的密度。四个出口依次是：先是空隙率，再是沥青体积百分率，然后是矿料间隙率，最后是沥青饱和度。

空隙率由两个入口的相对差给出〔公式待核〕；作者紧接着自己交代：同一个式子里换一种测法换一个密度，结果就换一套数，于是有了一张四组试件、三种测法的对照表（表 3-15，p108）。沥青体积百分率写了两版，按配合比的两种表示法分工〔公式待核〕。矿料间隙率被直接定义成前两者之和〔公式待核〕。沥青饱和度是沥青体积占矿料间隙的份额〔公式待核〕。

全段没有给这四个量排优先级，也没说哪一个可以独立测。后三个都由前两个导出——这件事只能靠式子本身看出来，作者没有点破。

（见 p107–p110，§第二节 三、1；表 3-15 在 p108；式 3-13／3-14 在 p109）

> **口径提醒**：这一节是本章唯一「链条闭合」的地方（例题 3-1 的五组六个参数逐格复算吻合，最大差 0.04〔复算〕），所以错的不是公式，是**口径**。口径不写，链条闭合也白搭。

## I — 判据骨架

### I.1 五个量里只有两个是输入

| 量 | 出处 | 输入／导出 | 本章允许的独立测法 | 报数必带的标签 |
|---|---|---|---|---|
| 理论最大密度 ρt | 式 3-7／3-8 | 输入 | 实测，或按配合比用两式之一算〔公式待核〕 | 实测／式算（并注明哪一式） |
| 试件密度（毛体积） | 式 3-9／3-10／3-11 | 输入 | 水中重、表干、蜡封、体积，四选一 | 测法名 |
| 空隙率 VV | 式 3-12 | 导出 | 不允许独立测 | 承 ρ 与 ρt 两个标签 |
| 沥青体积百分率 VA | 式 3-13／3-14 | 导出 | 不允许独立测 | 油石比／沥青含量（二选一） |
| 矿料间隙率 VMA | 式 3-15 | 导出 | 不允许独立测 | 由前两者相加得，不得独立报 |
| 沥青饱和度 VFA | 式 3-16 | 导出 | 不允许独立测 | 分母必须是 VMA |

**唯一判据**：这四个百分率里没有一个是能单独测出来的。凡报出一个数而说不出它的两个入口，这个数不成立——不是精度问题，是定义问题。

### I.2 两个必填标签，加上两个隐性条件

必填标签只有两个：**理论最大密度的来源**、**试件密度的测法**。缺任一个，四个出口都不许报。

隐性条件还有两个，作者写在别处、没写进公式：

1. **击实次数**——同一张标准表给了两档（75 与 50，表 3-16，p110〔数值待核原图〕）。跨档比较，比的是压实功，不是材料。
2. **读温**——稳定度与流值在 60℃ 读（p113）；常温混合料另有 25℃ 与 60℃ 双温（p130）。

这两个条件不进公式，但改一个，四个出口全变。**报体积参数时，试件怎么成型、什么温度读，跟密度测法一样重要。**

### I.3 式 3-13／3-14 的 ρs：我原先按表观密度读，读错了

两式（式 3-13 与式 3-14）的分子印着 ρs、分母是 γb 与 ρw〔公式待核〕。**2026-10-30 用户核原书定义：ρs 是试件毛体积密度**，不是表观密度。

我原先按「ρs＝表观密度」读，于是判这两式「分子分母取了两种口径、照抄会错」，并主张「只有取 ρb 才复现」。**那个判断撤回**：ρs 本来就是我说的那个量，公式没错，是我先假定了量名再宣布书错。

按书中转录值复算例题 3-1 的五组：只有把分子换成毛体积密度，表 3-23 的沥青体积百分率才复现（差 ≤0.05）〔复算〕；若照式面代表观密度，五组**全部偏高 0.05~0.12 个百分点**〔复算〕——这个量级在一位小数的报告精度里看不出来，属于「错了也像对的」。

处置规则（三条前提必须全齐，缺一条只能登记待核）：

1. 表观密度与毛体积密度**两个都算得出**；
2. 有**书中值可比**（本章表 3-23 提供了这个比对的锚）；
3. 换过来之后 **VMA 与 VFA 同时闭合**（见 I.4）。

三条全过 → 按印误处理，改写处标「式面印作 ρs，须回原图核」；缺一条 → 不许改写，只许写「该量口径待核」。

### I.4 第二条自检：只证伪、不证真

矿料间隙率与沥青饱和度是导出量，因此必然互约束。两条自检式（本章无式号，由式 3-15／3-16 直读）：

- VMA − VV 应等于 VA〔公式待核〕；
- VFA × VMA 应等于 VA〔公式待核〕。

容差按报告位数定：报一位小数就取 0.1。**超容差即该行数据不可验**——注意这里只判「不自洽」，不能反过来判「自洽所以对」。SMA 的两张参数表就卡在这一关上（差 0.26~0.36 个百分点〔复算〕，见 K4）。

### I.5 同一个「空隙率」在书里是四个数

这是本卡最该记住的一条。同一个试件、同一个空隙率定义，本章能给四个互不相等的数：

| 第几个 | 从哪来 | 例（同一试件，〔数值待核原图〕） |
|---|---|---|
| 一 | 表 3-15，水中重法 | 4.04 |
| 二 | 表 3-15，表干法 | 6.92 |
| 三 | 表 3-15，体积法 | 8.15 |
| 四 | 表 3-49 的密度列（列名印 ρs，却按空隙率用） | 口径错，不可与前三者并列 |

前三者的排序恒为「水中重 < 表干 < 体积」〔数值待核原图〕；同一试件的极差落在 **2.2~4.1 个百分点**〔数值待核原图〕。逐组复算的极差以第一组最大、第四组最小〔复算〕——下限与 2.2 有出入，按「数值待核原图」处理，不得据以下结论。

**第四个数的意义**：它说明「空隙率」在本章不仅能因测法而变，还能因**列名写错**而变。引用任何一个空隙率，先问三句：哪种密度、什么测法、哪张表。

### I.6 三处同名符号（写卡必带限定词）

| 符号 | 三处含义 | 消歧写法 |
|---|---|---|
| ρb | 式 3-10 是试件毛体积密度；式 3-19 指的是粗集料那一族的平均毛体积密度；式 3-20 又是试件实测毛体积密度 | 写成「试件毛体积密度」／「粗集料那一族的毛体积密度」，不许只写 ρb |
| m_d | 式 3-10 是饱和面干质量（g）；式 3-24 是磨耗值（g/m²） | 跨节引用前先认单位 |
| Pa／Pb | 油石比与沥青含量，两式并列 | 选公式前先认表示法；换算 Pb = Pa/(100+Pa)×100 可自证 |

> **拦截条**：本章 0 处出现「有效相对密度」这一术语，全文没有它的定义。凡有人拿它替换本章任一密度，先判「本章无此符号」，不许代。

### I.7 图 3-19／3-20：整块废弃，不是「图没画好」

这两张图讲的正是本卡 I.5 缺的那点趋势证据——空隙率随粗集料数量怎么变、随成型温度怎么变。但源文在这两处给出的不是图注，而是一段绘图代码，里面带着九个成对的坐标点。

按本章的编造纪律：数字密集、带坐标对、带绘图语法的块，一律当 OCR 编造，**整块废弃**。那九个点不是书里的数，任何卡、任何结论都不许引用，连它们的量级与走势也不许借。

后果：本卡对这两条趋势只能给方向（粗集料占比越高空隙率越大；成型温度越高空隙率越小），不能给点、不能给斜率、不能给相关系数。而这两张图本身也不存在可看的图——本章三十二幅图无一有内容。

> 顺带一句：另有两幅图在源文里指向外部占位图床，同样是工具残留，同样不许引。

## A1 — 演练（合成场景，无书中数字）

【合成演练，非书中案例】本章那道配合比例题的体积参数部分虽可复算，本卡仍不拿它当演练样本——它的标准行取自另一张表，与本卡要求的「标准来源登记」不是同一套（另见最佳沥青用量那张卡）。下列四场只走口径，**0 个数值结果**，段内不出现任何数字。

**演练一（正常路径：两个标签都齐）**
输入：一份体积参数汇总，每行四个字段——试件密度、密度测法、理论最大密度、理论最大密度的来源。
① 先判两组入口是否到场、来源是否写明；
② 再按空隙率式读出口，记下这个数挂的是哪一套口径；
③ 用两条自检式反向核对：矿料间隙率应等于沥青体积百分率与空隙率之和，沥青饱和度的分母必须是矿料间隙率；
④ 输出「口径齐／缺哪个标签」，不输出任何百分率。

**演练二（否决：沥青体积百分率代了表观密度）**
输入：同一份汇总里写明「按沥青体积百分率的两个版本之一，取表观密度」。
→ 输出「**停**」：式面印的是表观密度，可复现的算法要毛体积密度；两条前提（两个密度都算得出、有书中值可比）过了，第三条（矿料间隙率与饱和度是否随之闭合）没验就不能改写，只能登记「口径待核」。本卡不给替代值。

**演练三（否决：跨测法比较）**
输入：两份报告，同一材料，一份用水中重法、一份用体积法，两份的空隙率被并排放进一张对比表。
→ 输出「**出局**」：跨测法比较等于把测法差当成材料差，要求补齐测法字段后才能并列。

**演练四（半覆盖：只给一个密度）**
输入：只给理论最大密度与空隙率，没有试件密度、没有测法。
→ 输出「**无法核**」：四个出口都从试件密度出发，缺它只能停在「这个数无法复算」，不许反推。

**输出表固定四列**：`数｜它的两个入口｜口径标签齐不齐｜本章能不能核`。

## E — 执行步骤

**输入契约（缺任一「必需」项：先问，不进入计算）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 理论最大密度 ρt | 数值 | 必需 | 缺 → 停，空隙率无从算 |
| ρt 的来源 | 枚举：实测／式 3-7／式 3-8 | 必需 | 缺 → 停，记「来源未声明」 |
| 试件密度 | 数值 | 必需 | 缺 → 停 |
| 密度测法 | 枚举：水中重／表干／蜡封／体积 | 必需 | 缺 → 停，记「测法未声明」 |
| 击实次数（双面） | 整数 | 条件必需 | 缺 → 停，或退回原图核（表 3-16 列头缺） |
| 读温 | 数值＋单位 | 条件必需 | 缺 → 记一处「未交代」 |
| 配合比表示法 | 枚举：油石比／沥青含量 | 条件必需 | 缺 → 沥青体积百分率不许算 |
| 沥青密度、矿料密度 | 数值 | 条件必需 | 缺 → 只能走实测 ρt 这一条路 |

**步骤**

1. **登记两个标签**：ρt 来源、密度测法。不登记不往下走。
2. **算空隙率**：用试件密度与 ρt 的相对差〔公式待核〕，记下它承的两个标签。
3. **算沥青体积百分率**：先认表示法，再选版本〔公式待核〕；分子按 I.3 的三前提处置（能改写就改写并登记，不能就标待核）。
4. **加出矿料间隙率**〔公式待核〕，**除出沥青饱和度**〔公式待核〕。
5. **过两条自检**：VMA − VV 对 VA；VFA × VMA 对 VA。超容差即该行不可验。
6. **写「不推出的项」**：这套参数是否满足标准、是否够耐久、能否与别的测法比——都不在本卡。
7. **照固定格式报数**（见输出契约）。

**停判点**

1. **ρt 来源未声明** → 停。实测值与式算值不是同一个东西，混用等于换了一个空隙率定义。
2. **密度测法未声明** → 停。表 3-15 已证明三法差 2.2~4.1 个百分点〔数值待核原图〕，不标测法的空隙率不可比。
3. **沥青体积百分率直接代了表观密度** → 停。式面印 ρs、算例认毛体积，两条前提过了第三条没过，只能登记待核（I.3）。
4. **VMA − VV 不等于 VA，或 VFA × VMA 不等于 VA** → 停。该行数据不可验，不许「四舍五入抹平」。
5. **跨测法比空隙率** → 停。
6. **跨击实次数或跨读温比体积参数** → 停。
7. **流值没有单位** → 停。本章同一章里流值有两套单位（毫米与零点一毫米，差十倍），无单位一律退回。
8. **要求本卡复现三相比图（图 3-18）** → 停：本章图全缺，只有图注。

**输出契约**——固定五列，一行一个数：

`数｜值（单位）｜两个入口｜口径标签（ρt 来源＋测法＋击实次数＋读温）｜本章能不能核`

表下固定三行：

- **公式状态**：式 3-9~3-16 `〔公式待核〕`；式 3-13／3-14 的量名已核（ρs＝试件毛体积密度），**不再按印误处置**；其余符号仍待原图核。
- **不推出的项**：是否合格、是否耐久、能否跨测法互换。
- **依据页**：p108（表 3-15）、p109（式 3-13／3-14）、p110（表 3-16／3-17）。

## B — 边界

**H1 — 出现下列情形就别用本卡**

1. **只有一个密度**：本卡的链条从两个入口起算，缺一个就只剩「无法核」。
2. **想拿空隙率跨测法排名**：三法之差已达数个百分点（表 3-15），材料之间的真实差往往更小，排名会翻转。
3. **把 ρs 当表观密度代入**：ρs 是试件毛体积密度（已核原书定义）。用错口径会在「看起来对」的量级上偏 0.05~0.12 个百分点〔复算〕。
4. **想用体积参数判合格**：合格与否要看标准行取自哪张表，那是 K2 的事；本卡只保「数算得对」。
5. **想跨击实次数比**：75 与 50 是两档压实功（表 3-16），跨档比较不成立。
6. **想引用表 3-49 的空隙率列**：那一列的列名印 ρs 却按空隙率用，口径错，不可与表 3-15 并列。
7. **想用「有效相对密度」**：本章 0 命中、无定义，属外部术语，不许替换本章任一密度。

**H2 — 用前必须声明**

1. **ρt 来源**（实测／式算，并注明哪一式）——这是最容易被跳过的一步。
2. **密度测法**（四选一）——不声明则四个出口都不可比。
3. **击实次数与读温**——两个不进公式却改数的条件。
4. **配合比表示法**（油石比／沥青含量）——决定沥青体积百分率走哪一版。
5. **公式状态**：式 3-9~3-16 全部〔公式待核〕；式 3-13／3-14 的量名已核，不是印误。
6. **哪个「空隙率」**：报数时带表号。表 3-15 的三个数、表 3-49 的那一列，四个数都叫空隙率。

**本章三条覆盖缺口（对本卡的影响）**

| 缺口 | 对本卡 |
|---|---|

| 无模量、无主曲线（只有 0℃ 静态模量四数） | 体积参数与力学性能之间本章没有桥，本卡不跨 |
