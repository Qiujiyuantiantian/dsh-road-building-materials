# test-mortar-strength — 水泥胶砂强度：一组成绩怎么从三条算到一个数（补 ch4 的三件）

> **卡型：口径卡（补口卡）**——本篇里唯一一张能**直接改写前章停判**的卡。第四章的强度等级卡有三处悬空：一组几条、受压面积多大、代表值怎么取。这三处在本卡一次补齐。
>
> 主要取材：p321–p324（第二节全节，试验 11-5）、表 11-1（标准砂级配）、表 11-2（龄期与允许差）、式 11-3、11-4
>
> 挂靠候选（5 条）：`f05`、`p03`、`g07`、`ce03`、`ce06`

**卡头必读（六句）**

1. **本篇 35 个试验里，"多少算合格"只有一条**——水泥安定性的 C−A ≤ 5.0 mm（p320–321）。**胶砂强度这一项没有门槛**：它只给"一组三条怎么变成一个数"，等级门槛仍在第四章的表 4-4。所以本卡补的是**口径**，不是**判据**；它只问"**这个数在什么条件下才成立**"。
2. **一组成绩是三条试件、抗压六个值。** 抗折在三条上各得一个数（三个值）；折断后的六个半截各自抗压（六个值）。**"三个"与"六个"不是同一批数**，报"一组成绩"时必须说清是哪一个。
3. **抗压受压面积在本章被写死。** 式 11-4 的符号说明直接把面积写成四十乘四十等于一千六百平方毫米——**这是全书唯一一处把受压面积写进式子的地方**，第四章那处悬空到这里结清。
4. **取舍规则是两级、不是一级。** 抗压六值中一个超均值正负一成 → 剔掉、取余五值平均；余五值中再有一个超正负一成 → **整组作废**。抗折三值只有一级：一个超正负一成 → 剔掉再平均。
5. **第四章说的"三天"，在本章写作"七十二小时正负四十五分钟"。** 表 11-2 的五档是二十四小时、四十八小时、七十二小时、七天、二十八天；**七十二小时就是三天**，两边到这一句才对上号。
6. **本卡有一处物理上讲不通的尺寸。** 抗折的加荷与支撑圆柱被印成直径一百毫米（p321），而试件截面才四十乘四十、长一百六十。直径一百的圆柱比试件高度大两点五倍，三点弯曲架不起来——**疑为十毫米**。凡照该句验收抗折机，一律停。另外，**本篇 34 幅图无一有可读内容**，本章的图 11-8、11-9 只剩图注。

> **公式**：式 11-3（抗折：三倍荷载乘跨距，除以二倍边长乘高度平方）、式 11-4（抗压：荷载除受压面积）全部〔公式待核〕。本章抗压是"一步除法"，没有第二步。
>
> **数值**：配合比、龄期允许差、加荷速率、正负一成、重复性与再现性全部〔数值待核原图〕，条件为四十乘四十乘一百六十毫米棱柱、一比三、水灰比零点五、二十正负一摄氏度水中养护。
>
> **页码**：印刷页（本篇 283–341）。

## R — 原文说了什么（转述，非摘录）

配合比只有三个数：一份水泥、三份中国 ISO 标准砂、水灰比零点五。成型三条试件的一次称量为水泥四百五十（正负二）克、标准砂一千三百五十（正负五）克、水二百二十五（正负一）克。标准砂的级配按表 11-1 的六个筛孔给累计筛余与通过率两套数，两套互为补数。

搅拌分四段，每段误差正负一秒：低速三十秒；第二个三十秒里把砂均匀加入（分级砂从最粗一级起）；转高速再拌三十秒；停九十秒，停的头十五秒用胶皮刮具把叶片与锅壁上的胶砂刮回锅心；高速续拌六十秒。成型时试模与下料漏斗卡在振动台台面中心，全部胶砂装入漏斗，开振动台，胶砂经漏斗流满试模的时间应为二十到四十秒，判据是漏斗三格中有两格见空；超出这个窗口就调下料口或划动加速。振动一百二十（正负五）秒停车。刮平、编号，**同一试模的三条要分到两个以上龄期**——这一句把三天与二十八天分成了两批料，不是同一批。

养护：放进雾室或湿箱的水平架上，湿空气要能接触到试模各边，不许把试模摞在别的试模上。脱模时间分两种：二十四小时龄期的在破型前二十分钟内脱模；超过二十四小时龄期的在成型后二十到二十四小时之间脱模。硬化慢的水泥允许延期，但要记录。脱模后水平或竖直放进二十（正负一）摄氏度的水槽，六个面都要接触水，试件之间的间距或上表面以上的水深不小于五毫米。除二十四小时龄期或延到四十八小时脱模的以外，任何到龄期的试件在破型前十五分钟取出，擦去表面沉积物，湿布覆盖到试验为止。

龄期从加水搅拌起算，各龄期的破型时间按表 11-2 的五档执行：二十四小时正负十五分钟、四十八小时正负三十分钟、七十二小时正负四十五分钟、七天正负两小时、二十八天正负八小时。

抗折：试件以侧面搁在两个支撑圆柱上，长轴与圆柱正交；加荷圆柱压在相对的那个侧面，速率五十（正负五）牛每秒，直到折断，式 11-3 得抗折强度，精确到零点一兆帕。抗折以三条的平均为结果，三个值中有一个超出平均值的正负一成时，剔除后再平均。

抗压：在折断后的半截棱柱上做，受压面是成型时留下的那两个侧面，尺寸四十乘四十；半截试件的中心必须与压板中心对齐，偏差在正负零点五毫米以内；露在压板外的部分约十毫米；以二千四百（正负二百）牛每秒加荷到破坏，式 11-4 得抗压强度，精确到零点一兆帕。**式 11-4 的符号说明把面积直接写成四十乘四十等于一千六百平方毫米。**抗压以三条试件上得到的六个值的算术平均为结果；六值中只要有一个偏离组内均值超出正负一成，就剔掉它、取余五值平均；若五值中再有一个超出它们平均值的正负一成，**此组结果作废**。

精密度用变异系数表示：二十八天抗压的重复性要求变异系数落在一个百分点到三个百分点之间，再现性要求不超过六个百分点。报告要包括全部单个结果、算出的平均值，以及按规定舍去的结果。

## I — 判据骨架

### I.1 一组成绩的形状〔数值待核原图〕

| 层级 | 数量 | 来源 | 页 |
|---|---|---|---|
| 试件 | 三条四十乘四十乘一百六十毫米棱柱 | 一次成型，同一试模 | p321–322 |
| 抗折值 | 三个 | 每条折断时一个 | p323 |
| 抗压值 | 六个 | 三条断成六个半截，每截一个 | p323 |
| 抗折代表值 | 一个 | 三值中一个超均值正负一成则剔除再平均 | p323 |
| 抗压代表值 | 一个 | 六值中一个超均值正负一成则剔一取五；五值中再超则整组作废 | p324 |

**这张表就是第四章缺的那张。**第四章只说"一组几条"没给，本章给了；说了"受压面积无定义"，本章在式 11-4 里写死；说了"代表值取法无规定"，本章给了两级剔除。

### I.2 受压面积：一千六百平方毫米写死在式子里

式 11-4 的符号说明原文即"受压部分面积（四十毫米乘四十毫米等于一千六百平方毫米）"。意义有三：

1. **不必再问"压四十乘四十还是四十乘八十"**——本章答案是四十乘四十，另一半在压板外。
2. **面积不进误差预算**：它是常数，六个值的差异只来自荷载与成型。
3. **跨章不可搬**：混凝土立方体一百五十毫米见方是二万二千五百平方毫米，稳定土小试件直径五十毫米约一千九百六十三平方毫米（〔复算〕按公称直径），三套面积不同，尺寸效应与端部约束都不同。

### I.3 两级剔除：六值怎么变成五值、又怎么作废

写成流程：

1. 六值求平均 → 逐值比，看有无超出均值正负一成者。
2. 有一个超 → 剔掉它，余五值再平均，**报五值的平均**。
3. 五值里再有一个超它们平均值的正负一成 → **整组作废**，不出数。
4. 第一次就超两个及以上 → **书未规定**。本书只写了"有一个"的情形；本卡不替它补规则，只标"超出书本覆盖"，要处置须另立规则并声明来源。

抗折只有第 1、2 步，没有"整组作废"这一档——三条里剔一条还剩两条，仍可平均。**这就是"抗折三值"与"抗压六值"在取舍上的不对称。**

### I.4 抗折的几何与那处讲不通的尺寸

- 式 11-3 的形状是三点弯曲：跨距乘三倍荷载，除以二倍边长乘高度平方。要成立，支撑与加荷圆柱必须**细到不改变试件的受力状态**。
- 书上把加荷与支撑圆柱的直径写成一百（正负零点一）毫米〔数值待核原图〕。试件截面四十乘四十，长一百六十。**直径一百的圆柱放上去，比试件高度还大两点五倍**，两个支撑之间的净距都不够——三点弯曲架不起来。
- 处置：这一处按"疑为十毫米"登记，不改数；凡要验收抗折机、或用该直径做夹具设计，一律停。**这是本篇三处单位／尺寸量级错之一，另外两处见卡 6。**

### I.5 本卡补上了第四章的三件（全文的重心）

| 第四章缺的 | 本卡给的 | 页 |
|---|---|---|
| 一组几条 | 抗折一组三条；抗压"一组三个棱柱体上得到的六个测定值"——**三条试件、六个抗压值** | p322–323 |
| 抗压受压面积无定义 | 受压面取成型时的两个侧面；**式 11-4 把面积写成四十乘四十等于一千六百平方毫米** | p323 |
| 代表值取法无规定 | 抗折：三值中一个超均值正负一成则剔除再平均；抗压：六值中一个超则剔一取五，五值中再超则**整组作废** | p322–324 |

**附带补上的三件小事：**

1. **三天就是七十二小时。** 第四章的龄期写作三天与二十八天；本章表 11-2 的五档是二十四、四十八、七十二小时与七天、二十八天。**三天在表里写成七十二小时正负四十五分钟**，两边的龄期坐标到这一句才对齐。
2. **同一试模的三条要分到两个以上龄期。** 于是三天与二十八天不是同一批料，第四章"3d 与 28d 各测一次"的动作在本章有了成型端的约束。
3. **养护水温二十正负一摄氏度**，试件间距或上表面水深不小于五毫米，二十四小时龄期在破型前二十分钟内脱模、其余在成型后二十到二十四小时脱模。

**没有补上的那一半**：第四章判等级用的是表 4-4 的门槛。本章从头到尾**不给任何一个等级的门槛值**。所以第四章的结论仍然是"口径去本章取、门槛留在表 4-4"。

### I.6 三个"三天／七天"不是一回事（`ce03`、`g07`）

- 胶砂的三天：表 11-2 的七十二小时档，属水泥出厂等级的龄期，与二十八天配对。
- 胶砂的七天：表 11-2 的七天档，属早期强度，同样配二十八天看。
- 稳定土的七天：**六天保湿加一天浸水**的合称（p336 前后），属混合料配比的龄期。

三者不可互换。把稳定土的七天当二十八天用、或把胶砂的三天当七天用，等级或配比都会判错。

### I.7 审查清单（拿它审一份胶砂强度报告）

1. 抗折报的是三个值还是一个平均？抗压报的是六个值还是三个平均？
2. 受压面积写明了没有？是不是四十乘四十？
3. 剔除按哪一级走的？是剔一取五，还是已经整组作废？
4. 龄期写的是三天／二十八天，还是七十二小时／二十八天？换算对上了没有？
5. 同一试模的三条分龄期了吗？
6. 抗折机的圆柱直径写的是多少？照 p321 那句验收了吗？
7. 报告有没有把本章的兆帕直接与混凝土立方体抗压、稳定土无侧限抗压并列？

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】五段演练，输入是"一份成绩单 + 一个诉求"，输出只写走不走得通、停在哪一步。**不出现任何数值结果**：不写强度值、不写平均值、不写超限几个百分点；数字只作龄期、式号、页号与"三条／六个"这类结构的计数出现。

**演练一（把六个值报成三个）**
输入：报告只给了三条试件的抗压平均值，说"一组成绩就这三个数"。
→ 判：I.1。抗压是六个值，三级（剔一取五、再超作废）都要在六值上做；三个平均把信息压掉一半。
→ 输出：**停**。要六个单值。
→ 不输出：任何强度、任何"三个平均也差不多"的判断。

**演练二（受压面积另填）**
输入：报告按四十乘八十算了受压面积，理由是"半个棱柱更长"。
→ 判：I.2。本书面积写死在式 11-4 的符号说明里，且另一半露在压板外。
→ 输出：**停**。按四十乘四十重算。
→ 不输出：两个面积各自的强度值。

**演练三（该作废却报了数）**
输入：六值剔掉一个之后，余五值里又有一个明显偏离，报告仍给了平均。
→ 判：I.3 第 3 步。第二级命中即整组作废。
→ 输出：**停**。整组作废，不出数；要数就重做一组。
→ 不输出：任何"作废后剩下的值"。

**演练四（龄期对不上号）**
输入：报告写"三天强度"，附的却是七天龄期的破型时间。
→ 判：I.5 附带第 1 条、I.6。三天在表里是七十二小时正负四十五分钟。
→ 输出：**停**。龄期坐标不对，后面的比较全部作废。
→ 不输出：任何"折合"关系。

**演练五（照 p321 验收抗折机）**
输入：设备验收单引 p321 那句"加荷与支撑圆柱直径一百毫米"，判"符合"。
→ 判：I.4。该尺寸与试件几何不相容。
→ 输出：**停**。要求核原图；不核不能声称符合。
→ 不输出：任何"应为多少"的建议值（书里没有，不补）。

**预期输出表**：`报告项｜三条还是六个值｜受压面积｜剔除走到第几级｜龄期写法｜同模分龄期｜抗折机几何｜判到哪一步｜停判点｜依据页`。

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 试件条数与尺寸 | 二元组 | 必需 | 缺 → 停；条数决定层级 |
| 抗折三个单值 | 数值组 | 必需 | 缺 → 抗折代表值不出 |
| 抗压六个单值 | 数值组 | 必需 | 缺 → 停（停判点 1）；三个平均不够 |
| 受压面积（是否四十乘四十） | 数值 | 必需 | 缺或另填 → 停（停判点 2） |
| 龄期写法与破型时间 | 二元组 | 必需 | 缺 → 停（停判点 4） |
| 剔除走到哪一级 | 枚举 | 必需 | 缺 → 无法判"作废"还是"取五值" |
| 养护条件（水温、脱模时间、水深） | 四元组 | 必需 | 未写 → 结论降级为"仅在该口径下成立" |
| 抗折机圆柱直径 | 数值 | 条件必需 | 照 p321 验收即停（停判点 5） |

**步骤**

1. **定层级**：先写"抗折三值、抗压六值"，不要混（I.1）。
2. **核面积**：确认四十乘四十等于一千六百平方毫米（I.2）。
3. **走剔除**：六值一级 → 剔一取五；五值二级 → 命中即整组作废（I.3）。
4. **抗折单走**：三值一级，只有剔除、没有作废档。
5. **对龄期**：把三天对到七十二小时正负四十五分钟（I.5 附带第 1 条）。
6. **查同模分龄期**：同一试模三条是否分到两个以上龄期（I.5 附带第 2 条）。
7. **验几何**：抗折机圆柱直径不与试件相容时登记并停（I.4）。
8. **加声明**：两条必备声明（B 段 H2 第 1、2 条）。

**停判点**（命中任一条即停，不再往后走）

1. 只给三个抗压平均值 → 停（I.1，六个值缺四个）。
2. 受压面积不是四十乘四十、或另按四十乘八十算 → 停（I.2）。
3. 五值二级命中却仍报平均 → 停（整组作废，I.3）。
4. 龄期写成三天却不给七十二小时窗口、或拿七天顶三天 → 停（I.5、I.6）。
5. 照 p321 的圆柱直径验收抗折机 → 停（I.4）。
6. 同一试模三条全压在一个龄期，却要报"两个龄期对比" → 停（I.5 附带第 2 条）。

8. 要本卡给等级门槛 → 停（本章不给门槛，门槛在表 4-4）。

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **把六个抗压值报成三个平均。** 两级剔除无处落脚（I.1）。
2. **用四十乘八十算受压面积。** 面积写死在式 11-4（I.2）。
3. **五值二级命中后仍报平均。** 应整组作废（I.3）。
4. **把三天与七天当同一档。** 表 11-2 是五档，不是两档（I.5、I.6）。
5. **照 p321 的圆柱直径验收抗折机。** 与试件几何不相容（I.4）。
6. **拿胶砂兆帕与混凝土立方体抗压、稳定土无侧限抗压并列。** 三套面积不同（I.2 第 3 条）。
7. **在本章找等级门槛。** 本章不给（I.5 末段）。
8. **把稳定土的七天当胶砂的七天。** 一个是六加一，一个是七天正负两小时（`ce03`）。
9. **用表 11-5 的换算系数处理胶砂试件。** 那张表是混凝土试模的，与四十乘四十乘一百六十无关（`ce06`，详解在卡 6）。

### H2 — 用前必须声明

1. 本卡的兆帕属**试验篇的口径**：四十乘四十乘一百六十毫米棱柱、一比三、水灰比零点五、二十正负一摄氏度水中养护、规定的五个龄期。离开这套口径，同名强度不是同一个量。
2. 正负一成、精密度、龄期允许差都是**有效性判据与取舍规则**，不是合格线。本篇只有一条真合格线（安定性 C−A ≤ 5.0 mm），与本卡无关。
3. 等级门槛仍在第四章表 4-4；本卡只补口径，不补门槛。
4. 抗折机圆柱直径按"疑误"登记，引用该句必须注"须核原图"。
5. 本卡不回答"这组水泥是几级"；要定级，回第四章的等级卡。
