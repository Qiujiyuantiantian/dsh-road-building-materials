# test-concrete-workability-strength — 混凝土：和易性 → 试模 → 三种强度（补 ch5 的两件）

> **卡型：流程卡（补口卡）**——本卡把"拌制 → 测和易性 → 选模与成型 → 养护 → 三种强度"串起来，补上第五章缺的坍落度与维勃稠度两件；同时把本篇三处单位／量级错逐一定位。
>
> 主要取材：p324–p329（第三节、第四节，试验 11-6～11-12）、表 11-3～11-7、式 11-5、11-6、11-7
>
> 挂靠候选（4 条）：`f06`、`p02`、`ce04`、`ce06`

**卡头必读（六句）**

1. **本篇 35 个试验里，"多少算合格"只有一条**——水泥安定性 C−A ≤ 5.0 mm（p320–321）。**混凝土这一节也没有合格线**：它给的是"这个强度在什么试模、什么养护、什么加荷速率下成立"，强度等级的门槛在第五章。所以本卡只问"**这个数在什么条件下才成立**"，不问"这个强度够不够"。
2. **和易性先于试模。** 坍落度或维勃稠度决定用振动台还是人工插捣；成型方式又决定试件的密实程度；密实程度再决定强度能跟谁比。**顺序不能倒。**
3. **三种强度是三套几何，不是一个量的三个写法。** 抗压是立方体受压，抗折是三分点弯拉，劈裂是垫条对径劈裂。三者的面积、跨距、垫层各不相同。
4. **本卡有三笔单位与量级错，加一笔单位混用。** 负压筛的"兆帕"（应为帕）、胶砂抗折支撑圆柱的"直径一百毫米"（疑十毫米）、试模换算表里抗压两行的粒径与系数双错位，还有人工成型门槛的"七十厘米"（应为毫米）。**四笔都按登记处理，不替书改值。**
5. **换算系数那一栏，同一张表内自相矛盾。** 劈裂与抗折对一百毫米试件都取小于一的系数，抗压却取大于一的系数——**不必查外部资料，同表内即可判死。**
6. **34 幅图无一有内容。** 图 11-10～11-13 只留图注，试件摆放、垫条位置、抗折装置都只能凭文字。

> **公式**：式 11-5（抗压：荷载除受压面积）、11-6（抗折：荷载乘跨距除宽乘高平方）、11-7（劈裂：二倍荷载除圆周率乘面积）全部〔公式待核〕。
>
> **数值**：试模尺寸、粒径、换算系数、插捣次数、加荷速率、坍落度读数精度全部〔数值待核原图〕，条件为试件尺寸、集料最大粒径、强度等级区间。

## R — 原文说了什么（转述，非摘录）

拌制以质量计，精确度：集料正负一个百分点，水、水泥、砂正负零点五个百分点。机械拌和先用少量同配比砂浆涮膛并刮出，再按石子、砂、水泥的顺序投料，边拌边徐徐加水，全部加料不超过两分钟；水加完后继续拌两分钟，倾到铁板上人工翻拌一到两分钟。人工拌和来回翻拌至少六遍，拌和时间按表 11-3 的体积分档给（少于三十升、三十一到五十升、五十一到七十五升三档）。测性质要在拌和后五分钟内做。

坍落度：适用条件是坍落度大于十毫米、集料最大粒径不超过四十毫米；粒径超过四十毫米改用加大筒。筒按集料最大粒径从表 11-4 选：标准筒底面直径二百、顶面一百、高三百；加大筒三百、一百五十、四百五十。装料分三层，每层插捣二十五次，沿螺旋线由边缘到中心，下层插到底、上两层插透本层再进入下层二十到三十毫米。提筒五到十秒完成，从开始装筒到提起不超过两分半。量木尺底面到试样顶点的距离，读数精确到五毫米。两次结果相差二十毫米以上要做第三次；第三次仍与前两次都相差二十毫米以上则整个试验重做。用加大筒时乘零点六七折算。

维勃稠度：适用于最大粒径小于四十毫米、稠度在五到三十秒之间的干硬性拌合物。振动台工作频率五十赫兹，空载振幅零点五毫米。按坍落度的方法装三层、提筒、放下透明圆盘，读滑杆得坍落度；开振动台同时按秒表，圆盘底面刚被水泥浆布满即停表，读数精确到一秒。

试件制作：先测坍落度与维勃稠度，认为品质合格再制件；拌和后十五分钟内装模、四十五分钟内成型完毕。试模尺寸按表 11-5 与强度类型对应：抗压标准件一百五十立方、粒径四十、系数一点零零；非标准件二百立方配粒径三十、系数零点九五，一百立方配粒径六十、系数一点零五；劈裂标准件一百五十立方、粒径四十、系数一点零零，非标准一百立方配粒径三十、系数零点八五；抗折标准件一百五十乘一百五十乘五百五十、粒径四十、系数一点零零，非标准一百乘一百乘四百配粒径三十、系数零点八五。

成型分机械与人工。坍落度小于七十毫米用标准振动台，振动到表面泛浆为止，时间约为维勃稠度的两到三倍、一般不超过九十秒；坍落度不小于七十毫米用人工，分两层，每层插捣次数按表 11-6（该表六行：一百立方十二次；一百乘一百乘四百五十次；一百乘一百五十乘一百五十、二十五次；二百立方五十次；一百五十乘一百五十乘三百、七十五次；一百五十乘一百五十乘五百五十、一百次）。表面与模边高差不得超过零点五毫米。养护：成型后湿布覆盖，室温二十正负五摄氏度、相对湿度大于五十个百分点，静放一到两昼夜，拆模并作外观检查；然后标准养护，温度二十正负三摄氏度、相对湿度九十个百分点以上，试件间距三十到五十毫米；也可放水槽（二十正负三摄氏度）。

抗压：以成型侧面为上下受压面，几何对中（偏离五毫米以内）；强度等级低于 C30 取每秒零点三到零点五兆帕，不低于 C30 取每秒零点五到零点八兆帕；式 11-5 得立方体抗压强度，精确到零点一兆帕。三个试件取算术平均；任一测值与中值之差超过中值的十五个百分点则取中值为测定值；有两个超则整组无效。

抗折：中部三分之一长度内如有大于直径七毫米乘二毫米的蜂窝，试件立即作废。成型侧面朝上，几何对中，先加约一千牛的初荷载，再以每秒零点五到零点七兆帕加荷。断面落在两个加荷点之间时按式 11-6 算，精确到零点零一兆帕；断面在加荷点外侧则该试件无效，两个无效则整组作废。取舍原则同抗压。

劈裂：钢垫条加三合板或纤维板垫层，垫层宽十五到二十毫米、厚三到四毫米、不得重复使用。劈裂面与成型顶面垂直；低于 C30 取每秒零点零二到零点零五兆帕，不低于 C30 取每秒零点零五到零点零八兆帕；式 11-7 得劈裂抗拉强度，精确到零点零一兆帕。取舍原则同抗压。

### I.2 表 11-5 的双错位：同表内即可判死

| 抗折 | 一百五十乘一百五十乘五百五十（标准） | 四十 | 一点零零 |
| 抗折 | 一百乘一百乘四百（非标准） | 三十 | 零点八五 |

两处错位，逐条说明为什么**不需要外部知识就能判死**：

1. **粒径与试模对不上，而方向由同表另两栏自己给出。** 劈裂与抗折两栏是一致的：标准件配四十、一百毫米的非标准件配三十——即**大试模配大粒径**。抗压这两行恰好倒过来：二百立方配三十、一百立方配六十。同一张表里三栏两个方向，不必查外部资料。
2. **系数方向与同表另两栏相反。** 劈裂与抗折对一百毫米试件都取零点八五（小于一）；抗压对一百毫米试件取一点零五（大于一）。**同一张表里，同一个"非标准小试件"被要求既缩小又放大**——不可能同时成立。

后果：把一百毫米立方的抗压强度乘一点零五再与一百五十毫米比，会把小试件本已偏高的强度**再放大一次**；按同表另两栏的方向，反而该乘小于一的系数。**两个方向差出一成以上，且都不报错。**

### I.7 劈裂：两种劈裂不可互换（`ce04`）

- 本卡的是**水泥混凝土**劈裂：立方体、上下各一条垫条加垫层、对径受压，式 11-7 为二倍荷载除圆周率乘劈裂面面积。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】五段演练，输入是"一份试件单 + 一个诉求"，输出只写走不走得通、停在哪一步。**不出现任何数值结果**：不写强度、不写坍落度、不写系数、不写系数换算后的值；数字只作表号、式号、页号与强度等级符号出现。

**演练一（坍落度没测就选成型方式）**
输入：报告直接写"用振动台成型"，没有坍落度或维勃记录。
→ 判：I.1。成型方式由和易性定；和易性没有记录，成型方式就没有依据。
→ 输出：**停**。先补和易性，再谈成型。
→ 不输出：任何"应当用哪种"的判断。

**演练二（套表 11-5 的抗压换算）**
输入：一百毫米立方的抗压试件，报告按该表抗压那一行取了大于一的系数，与一百五十毫米试件的数据并列。
→ 判：I.2。该行粒径与系数双错位，且与同表劈裂、抗折方向相反。
→ 输出：**停**。换算系数不出数；只写"书印如此、方向自相矛盾，须核原图"。
→ 不输出：任何换算后的强度、也不给"正确系数是多少"。

**演练三（七十厘米）**
输入：报告写"坍落度不小于七十厘米时用人工成型"，据此选了人工。
→ 判：I.3 第四行。厘米与毫米混用，七十厘米超出坍落度可能范围。
→ 输出：**停**。按毫米读；读数单位不明就是口径不明。
→ 不输出：任何坍落度值。

**演练四（作废的级别）**
输入：组内一块试件尺寸不合、另一块断面落在加荷点外侧，报告把整组作废。
→ 判：I.5。三级要分开：尺寸不合废试件、断面在外废该次；两个无效才整组废。
→ 输出：**停**。先定级，再决定是否补做。
→ 不输出：任何"整组是否成立"以外的数值判断。

**演练五（拿混凝土劈裂补沥青混合料）**
输入：报告用式 11-7 算沥青混合料的劈裂强度。
→ 判：I.7、`ce04`。试件、垫条、加载方向全不同。
→ 输出：**停**。承认第十章缺口，不给替代。
→ 不输出：任何劈裂强度。

**预期输出表**：`报告项｜和易性记录｜成型方式｜试模与粒径｜换算系数方向｜作废级别｜养护条件｜加荷速率｜判到哪一步｜停判点｜依据页`。

**步骤**

1. **先测和易性**：坍落度或维勃，读数精度与两次差规则一并记（I.1）。
2. **按和易性选成型**：小于七十毫米振动台、不小于七十毫米人工（I.1）。
3. **选模对表**：尺寸、粒径、系数三列一起抄；抗压两行按"错位"处理（I.2）。
4. **定系数方向**：声明乘的是大于一还是小于一，并与劈裂、抗折两栏方向比（I.2 第 2 条）。
5. **成型与养护**：表面高差、静放时间、标准养护温湿度写全。
6. **破型**：按强度等级取加荷速率；抗折先加初荷载；劈裂垫层不得重复使用。
7. **定作废级别**：按 I.5 三栏逐项对，写清废的是哪一级。
8. **加声明**：两条必备声明（B 段 H2 第 1、2 条）。

**停判点**（命中任一条即停，不再往后走）

1. 没有和易性记录却已选定成型方式 → 停（I.1）。
2. 套表 11-5 抗压两行的换算系数、或未声明方向 → 停（I.2）。
3. 按"七十厘米"读坍落度门槛 → 停（I.3）。
4. 照 p321 的圆柱直径验收抗折装置 → 停（I.3）。
5. 把负压筛的"兆帕"当实际负压值引用 → 停（I.3）。
6. 把试件废、该次废、整组废混成一句"作废" → 停（I.5）。
7. 拿本卡的劈裂式算沥青混合料劈裂 → 停（I.7、`ce04`）。
8. 要本卡补含气量 → 停（四章零命中，仍未补，I.6）。
9. 要拿本卡的兆帕与胶砂四十乘四十乘一百六十、稳定土小试件并列 → 停（三套面积，H1 第 8 条）。

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **没有和易性记录就谈成型方式。** 顺序倒了（I.1）。
2. **直接用表 11-5 抗压两行的系数。** 粒径与系数双错位（I.2）。
3. **认为抗压与劈裂、抗折的系数方向一致。** 同表内相反（I.2 第 2 条）。
4. **按"七十厘米"读门槛。** 厘米与毫米混用（I.3）。
5. **照 p321 的直径验收抗折装置。** 与试件几何不相容（I.3）。
6. **把负压筛的兆帕当实际值。** 量级差一百万倍（I.3）。
7. **把三级作废混成一句。** 数据无法追溯（I.5）。
8. **拿混凝土劈裂式算沥青混合料。** 两回事（I.7、`ce04`）。
9. **指望本卡给含气量。** 四章零命中（I.6）。
10. **拿本卡兆帕与胶砂、稳定土并列。** 三套面积（H2 第 1 条）。

### H2 — 用前必须声明

1. 本卡的兆帕属**试验篇的口径**：立方体或棱柱或立方体劈裂、按表 11-5 的试模、二十正负三摄氏度标准养护、按强度等级取的加荷速率。离开这套口径，同名强度不是同一个量；与胶砂四十乘四十乘一百六十（一千六百平方毫米）、稳定土小试件（直径五十毫米）三套面积不可互比。
2. 坍落度两次差、插捣次数、表面高差、作废三级都是**有效性判据与取舍规则**，不是合格线。本篇只有一条真合格线（安定性），与本卡无关；强度等级门槛在第五章。
3. 表 11-5 抗压两行按"错位、方向自相矛盾"登记，卡片不替书选方向；任何引用都要写"须核原图"。
4. 三处半的缺失（含气量未补、沥青混合料劈裂未写）按缺口处理，不得用别章内容顶替。
5. 本卡不回答"这组混凝土是什么等级"；要定级，回第五章的门槛表。
