# test-mix-specimen-flow — 混合料试件流：试件怎么来，结果就只能跟谁比

> **卡型：流程卡（不产生数值结论）**——本卡把"拌和温度 → 成型方式 → 高度把关 → 体积参数 → 马歇尔 → 车辙"串成一条流，重点不在每一步怎么做，而在**每一步的产出决定了下一步能跟谁比**。
>
> 主要取材：p304–p315（试验 10-4～10-8）、表 10-3、式 10-1～10-7、图 10-7～10-13
>
> 挂靠候选（6 条）：`f04`、`p05`、`ce07`、`ce04`、`g03`、`g06`

**卡头必读（六句）**

1. **本篇 35 个试验里，"多少算合格"只有一条**——水泥安定性 C−A ≤ 5.0 mm（p320–321）。其余全是有效性判据、取舍规则、统计换算。**本章连一条合格线都没有**：马歇尔稳定度、流值、动稳定度的门槛一律在第三章，本章只给"这个数怎么来"。用本卡的话说：只问"**这个数在什么条件下才成立**"。
2. **试件的制备方式就是结果的适用范围。** 击实件与轮碾件不能互比；轮碾件与现场钻芯件不能互比；标准件与大型件不能互比。**比之前先对齐制备方法。**
3. **本章有三条断链，且不在算术上，在输入端。** 空隙率的分母（最大理论相对密度）只有"实测或计算"四个字；两条要读的曲线（修正原点、车辙两点）无图；吸水率超限后要用的蜡封法**零步骤**。
4. **内容提要承诺五项，正文只出两项。** 劈裂强度、冻融劈裂、弯曲试验**一条没写**（`ce04`）。所以凡是拿"第十章有劈裂"当依据的，都是把第十一章的水泥混凝土劈裂张冠李戴。
5. **两个"残留稳定度"不是一回事。** 浸水马歇尔只泡水；真空饱水马歇尔先抽真空再泡水。符号不同、分子不同、分母相同（`ce07`）。
6. **34 幅图无一有内容。** 本章要读的图 10-11（修正原点怎么取）与图 10-13（两个时刻的变形怎么读）都只有图注。

> **公式**：式 10-1、10-2、10-3、10-4、10-5、10-6、10-7 全部〔公式待核〕；其中 10-1～10-4 与 10-5、10-6 的式号在原文块里脱落，只能按正文引用回推。
>
> **数值**：温度、次数、高度、荷载、速率、修正系数一律〔数值待核原图〕，并连条件（试件尺寸、成型方式、温度、轮压）。

## R — 原文说了什么（转述，非摘录）

先定两个温度。有粘度条件时，画粘温曲线，取运动粘度一百七十（正负二十）平方毫米每秒对应的温度为拌和温度，取二百八十（正负三十）对应的为压实温度；用赛波特粘度则取八十五秒与一百四十秒两档。没有粘度条件时查表 10-3：石油沥青拌和一百三十到一百六十、压实一百一十到一百三十；改性沥青拌和一百六十到一百七十五、压实一百四十到一百七十。针入度小取高限，针入度大取低限，一般取中值；聚合物改性沥青在基质沥青基础上提高十五到三十摄氏度，掺纤维再提十摄氏度左右。

备料：矿料在烘箱里烘到恒重，一般不少于四到六小时；矿粉单独加热，炉温比拌和温度高出十五摄氏度以上（石油沥青常取一百六十三、改性沥青一百八十）；按一组四到六个试件备料。拌和机预热到拌和温度以上十摄氏度左右；先拌粗细集料，再加已加热到拌和温度的沥青，拌一到一点五分钟，暂停后加矿粉，续拌到均匀，总时间约三分钟。

成型两条路。击实法：标准锤四千五百三十六克、落高四百五十七点二毫米，双面各击七十五、五十或三十五次；大型锤一万零二百一十克、落高四百五十七点二毫米（公差二点五），大型的七十五次相当于标准的五十次，一百一十二次相当于标准的七十五次。标准试件一个约一千二百克，大型约四千零五十克。击完立即量试件离模口的高度折算实际高度；高度不合就作废，并按"要求高度乘原用质量除以所得高度"调下一件的料量。轮碾法：试模内平面三百乘三百，深五十、四十或一百；轮宽三百，线荷载三百牛每厘米，总荷载九千牛；先在一个方向压两个往返，卸荷、抬起、掉头，再压到马歇尔标准击实密度的一百（正负一）个百分点为止，正式件前先试压定次数，一般十二个往返。板块总质量按体积乘标准击实密度再乘一点零三。切棱柱时板边缘二十毫米不得用；钻芯可选一百或一百五十毫米钻头，钻前堆干冰速冷，没有干冰就开冷却水。

体积参数走表干法三称量：干重、水中重、表干重。式 10-1 得吸水率；式 10-2、10-3 得毛体积相对密度与毛体积密度；式 10-4 得空隙率。吸水率大于二个百分点时"应改用蜡封法"，而蜡封法在本书没有任何步骤与仪具。同页还点了四个名字：沥青体积百分率，以及矿料间隙率与沥青饱和度，再加粗集料骨架间隙率——**一式未给**。

马歇尔：试件高度标准六十三点五（正负一点三）毫米、大型九十五点三（正负二点五）毫米，两侧高差大于二毫米作废；六十（正负一）摄氏度水浴保温三十到四十分钟（大型四十五到六十分钟）；加荷速率五十（正负五）毫米每分；从水浴取出到读出最大荷载不超过三十秒。稳定度以千牛计、精确到零点零一；流值以毫米计、精确到零点一。自动仪记录荷载—变形曲线后，要在切线方向延长与横轴相交取修正原点，再从这个原点量最大荷载对应的变形。式 10-5 得浸水残留稳定度（泡水四十八小时），式 10-6 得真空饱水残留稳定度（先抽到九十七点三 kPa 即七百三十毫米汞柱以上、维持十五分钟、负压进水浸十五分钟、恢复常压后再泡四十八小时）。一组数据里某个值偏离组内均值超过标准差的若干倍时舍弃，样本数为三、四、五、六时该倍数分别为一点一五、一点四六、一点六七、一点八二。

车辙：板块三百乘三百乘五十，六十（正负一）摄氏度，轮压零点七（正负零点零五）兆帕，总荷载七百牛上下，轮外径二百、宽五十、行走二百三十（正负十）毫米、往返四十二（正负一）次每分；成型后常温放置不少于十二小时（改性沥青宜二十四小时，但不超过一周），恒温室保温五到二十四小时。跑约一小时或变形到二十五毫米为止，读四十五分钟与六十分钟的变形，式 10-7 得动稳定度，带两个修正系数：试验机类型（曲柄连杆变速为一点零、链驱动等速为一点五）与试件系数（室内三百毫米宽为一点零、路面切割一百五十毫米宽为零点八）。三个平行件的变异系数小于二十个百分点才取平均；算出来超过六千次每毫米就记作大于六千。

## I — 判据骨架

### I.1 试件流：五个关口，每个关口都改变"能跟谁比"

| 关口 | 决定什么 | 关键量〔数值待核原图〕 | 页 |
|---|---|---|---|
| 拌和／压实温度 | 老化程度与可压实性 | 粘度两档或表 10-3 两行 | p304–305 |
| 成型方式 | 空隙结构 | 击实七十五／五十／三十五；大型一百一十二／七十五 | p307 |
| 高度把关 | 体积参数的分母 | 六十三点五±一点三；九十五点三±二点五；两侧差大于二作废 | p307、p313 |
| 密度基准 | 轮碾件的目标 | 马歇尔标准击实密度的一百±一个百分点 | p307、p309 |
| 保温与加载 | 稳定度与流值 | 六十±一摄氏度，三十到四十分钟；五十±五毫米每分 | p312 |

**读法**：这五关任何一关变了，"同一批料"的稳定度就不再是同一个数。**报告必须把这五关写全，否则读者无法判断两批数能不能比。**

### I.2 两个密度的关系：轮碾件为什么必须对着马歇尔件调平

轮碾件的验收标准不是"压多少遍"，而是"压到马歇尔标准击实密度的一百（正负一）个百分点"。于是流程上有一个来回：先按击实法做一组标准件测密度，再用这个密度去定轮碾件的遍数与总质量（体积乘击实密度再乘一点零三）。**这一步把两种成型方式绑在了同一个密度基准上**，也是本书唯一一处明确写出"两法可对接"的地方。反过来，板块切出的棱柱件、钻出的芯件，只在这个基准成立时才能与击实件比较。

### I.3 三条断链（本章的可执行度上限）

1. **式 10-4 的分母没有来源。** 空隙率 =（一 − 毛体积相对密度／最大理论相对密度）× 百分数，而后者只有"实测"或"计算"四个字：没有实测步骤、没有算式、没有试样量。**这就是本章唯一一条半链**——只到毛体积相对密度为止，空隙率算不出来。
2. **四个体积参数只有名字。** 沥青体积百分率，以及矿料间隙率与沥青饱和度，再加粗集料骨架间隙率，一句话"计算"，一式不给。要它们只能回第三章；其中粗集料骨架间隙率另有第九章的式 9-15 可用（`g06`）。
3. **蜡封法零步骤。** 吸水率超二个百分点时被要求"改用蜡封法"，而全书没有该法的任何一步、任何一件仪具。现场钻芯件吸水率普遍偏高，因此**这一类试件在本书内测不了体积参数**。

另有两处读图断点：图 10-11 的修正原点、图 10-13 的两个时刻变形，图都无内容。

### I.4 马歇尔族的四个量（`g03`）

| 符号 | 含义 | 单位与精度 | 分母／来源 | 页 |
|---|---|---|---|---|
| MS | 稳定度（最大荷载） | 千牛，零点零一 | 直接读 | p313 |
| FL | 流值（修正原点后的变形） | 毫米，零点一 | 需修正原点 | p313 |
| MS0 | 浸水残留稳定度 | 百分数 | 分子为泡水四十八小时后的稳定度 | p313 |
| MS0′ | 真空饱水残留稳定度 | 百分数 | 分子为先真空后泡水的稳定度 | p313 |
| DS | 动稳定度 | 次每毫米 | 式 10-7，带两个修正系数 | p315 |

**MS0 与 MS0′ 的分母是同一个标准稳定度，分子是两个不同处理的稳定度。**两者都叫"残留稳定度"就会失去区分度——这正是水损害评价最容易糊掉的一处。

### I.5 车辙的两个修正系数与一个记录规则

- c1（试验机类型）：曲柄连杆驱动试件变速行走取一点零，链驱动试验轮等速取一点五。
- c2（试件系数）：室内三百毫米宽取一点零，路面切割一百五十毫米宽取零点八。
- 记录规则：算出来超过六千次每毫米，记作"大于六千"，不记具体值。这是**记录规则**，不是合格线。
- 有效性：三个平行件的变异系数小于二十个百分点才取平均；超了要分析原因并追加试验。

**c1 与 c2 是乘上去的，方向只能是放大或缩小，不能"反过来除"。**把 c2 当除数用，等于把现场件的动稳定度再放大一次。

### I.6 本章的结构缺口（`ce04` 的来源）

内容提要在 p299 承诺五项：马歇尔、车辙、劈裂强度、冻融劈裂、弯曲。正文到 p315 的车辙为止，**后三项一条没写**。后果有三条：

1. 第三章的冻融劈裂比与弯拉破坏能，在本源文里没有测法；
2. 第二章的水稳定性评价，只能停在残留稳定度；
3. **第十一章确有劈裂抗拉（式 11-7，二倍荷载除以圆周率乘面积），但那是水泥混凝土的**——试件形状、垫条、加载方向、破坏机理都不同，**不可互换**。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】五段演练，输入是"一份马歇尔或车辙报告 + 一个比较诉求"，输出只写能不能比、停在哪一步。**不出现任何数值结果**：不写稳定度、不写流值、不写空隙率、不写动稳定度；数字只作式号、页号与条件（温度、次数）出现。

**演练一（两批稳定度能不能比）**
输入：甲批是标准击实件、乙批是轮碾板块切出的棱柱件，报告把两批稳定度并列排序。
→ 判：I.1、I.2。成型方式不同，高度把关与密度基准也不同。
→ 输出：**停**。先对齐成型方式与密度基准；对不齐只能说"两批不可比"。
→ 不输出：任何排序、任何"高多少"。

**演练二（空隙率算不出来）**
输入：报告给了毛体积相对密度，要求接着算空隙率，并说"最大理论相对密度按计算取"。
→ 判：I.3 第 1 条。分母无算式、无实测步骤。
→ 输出：**停**。要么补最大理论相对密度的来源（本章没有），要么把空隙率留空。
→ 不输出：任何空隙率、任何"取一个常见值"的建议。

**演练三（现场钻芯件）**
输入：报告是路面钻芯件，吸水率超过二个百分点，仍按表干法报了四个体积参数。
→ 判：I.3 第 3 条。超限应改蜡封法，而蜡封法零步骤；四个参数本身也一式未给。
→ 输出：**停**。体积参数不出数；只说"本书内无法测"。
→ 不输出：任何体积参数、任何"近似按表干法"的替代。

**演练四（两个残留稳定度混用）**
输入：报告把浸水马歇尔的残留稳定度与真空饱水马歇尔的残留稳定度当作同一指标，挑了高的那个报。
→ 判：I.4。两者分子不同、分母相同（`ce07`）。
→ 输出：**停**。两个符号分开报，并注明各自的前处理。
→ 不输出：任何残留稳定度数值。

**演练五（拿第十一章的劈裂补第十章）**
输入：报告引"劈裂强度"说本章五项俱全，式子用的是二倍荷载除以圆周率乘面积。
→ 判：I.6、`ce04`。本章正文没有沥青混合料劈裂；那个式子是水泥混凝土的。
→ 输出：**停**。承认缺口，不给替代。
→ 不输出：任何劈裂强度、任何"可类比"的判断。

**预期输出表**：`报告项｜成型方式｜高度与两侧差｜密度基准｜温度与保温｜分母来源｜符号是哪一个｜判到哪一步｜停判点｜依据页`。

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 成型方式（击实／轮碾／切割／钻芯） | 枚举 | 必需 | 缺 → 停（停判点 1） |
| 试件尺寸与高度、两侧高差 | 三元组 | 必需 | 缺 → 停；高度是体积参数的分母 |
| 拌和与压实温度（或粘度／表 10-3 依据） | 数值对 | 必需 | 缺 → 结论降级为"温度不明" |
| 击实次数或轮碾遍数与总荷载 | 数值组 | 必需 | 缺 → 无法判密度基准 |
| 三个称量与吸水率 | 数值组 | 条件必需 | 走体积参数时必需 |
| 最大理论相对密度的来源 | 枚举 | 必需 | 缺 → 停（停判点 2，本章无算法） |
| 稳定度、流值及是否修正原点 | 三元组 | 条件必需 | 走马歇尔时必需；未修正 → 停（停判点 5） |
| 车辙的温度、轮压、时刻与变形 | 五元组 | 条件必需 | 走车辙时必需；缺 → 停 |
| 平行件数与变异系数 | 数值对 | 必需 | 缺 → 无法判有效性 |

**步骤**

1. **对制备**：先写成型方式与尺寸，再决定这个数能跟谁比（I.1）。
2. **核高度**：高度与两侧高差先过关；不过关整件作废，不进入后面任何一步。
3. **定基准**：轮碾件要对着马歇尔标准击实密度调平（I.2）；未调平即降档。
4. **算密度**：三称量 → 式 10-1～10-3；吸水率超限即停（I.3 第 3 条）。
5. **留空隙率**：分母来源不明就不出空隙率（I.3 第 1 条）；四个体积参数一律标"本章未给"。
6. **读马歇尔**：确认是否用了修正原点；未修正的流值不能报（I.4）。
7. **分符号**：MS0 与 MS0′ 分开报，前处理写清（I.4）。
8. **读车辙**：确认两个时刻的变形、两个修正系数、变异系数；超六千按记录规则写（I.5）。
9. **加声明**：两条必备声明（B 段 H2 第 1、2 条）。

**停判点**（命中任一条即停，不再往后走）

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **跨成型方式比较稳定度或动稳定度。** 空隙结构不同（I.1）。
2. **用本章给空隙率。** 分母无来源（I.3 第 1 条）。
3. **在本章找矿料间隙率与沥青饱和度、沥青体积百分率的式子。** 只有名字（I.3 第 2 条）。
4. **在本章找蜡封法。** 零步骤（I.3 第 3 条）。
5. **把浸水马歇尔与真空饱水马歇尔当同一指标。** 分子不同（`ce07`）。
6. **拿混凝土劈裂式算沥青混合料劈裂。** 见 I.6（`ce04`）。
7. **把"大于六千"当合格线。** 它是记录规则（I.5）。
8. **把 c1／c2 反过来除。** 方向错（I.5）。
9. **用图 10-11 或图 10-13 读数。** 图无内容（卡头第 6 条）。

### H2 — 用前必须声明

1. 本章的量属**试验篇的口径**：标准马歇尔件为直径一百零一点六毫米、高六十三点五毫米，六十摄氏度水浴三十到四十分钟，加荷五十毫米每分；车辙板为三百乘三百乘五十，六十摄氏度、零点七兆帕。离开口径，同名量不是同一个量。
2. 高度、两侧高差、变异系数、真空度都是**有效性判据**，不是合格线。本章无合格线，门槛在第三章。
3. 一切体积参数的完整算法在第三章；本章只给到毛体积相对密度与（半链的）空隙率。
4. 三项缺失（劈裂、冻融劈裂、弯曲）按缺口处理，**不得用第十一章的混凝土劈裂顶替**。
5. 本卡不回答"这块混合料能不能用"；要判合格，回第三章的配合比设计指标表。
