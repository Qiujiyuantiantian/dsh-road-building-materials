## R — 原文说了什么（转述，非摘录）

击实试验的目的句写得很直：在规定试筒里按规定程序击实，由击实件的密度与含水量反求最优含水量与最大干密度，供强度试验与施工指导。仪具：锤底直径五十毫米、总质量四点五千克、落高四百五十毫米；垫块的外径与试筒内径一致、高五十毫米；试筒由套环与底座组成，尺寸见表 12-1。

表 12-1 三行：甲法内径十厘米、高十二点七厘米、容积九百九十七立方厘米、五层、每层二十七击，限二十五毫米；乙法内径十五点二、高十二点零、容积二千一百七十七立方厘米、五层、每层五十九击，限二十五毫米；丙法同筒、三层、每层九十八击，限四十毫米。（本轮按内径与高反算三行容积〔复算〕：九百九十七点五、二千一百七十七点五、二千一百七十七点五立方厘米，与表给三值相合。）

选法：细粒土过五毫米筛，在甲乙两法里选；试样里若已有二十五毫米颗粒，最好用乙法。含大于五毫米的颗粒时先过二十五毫米筛，筛上留量不超过二十个百分点就用甲乙法；留量过多则过四十毫米筛、改用丙法。风干含水量在试验前一天测，细粒土取一百克以上、中粒土一千克以上、粗粒土二千克以上。

含水量取五到六个，依次相差一到两个百分点，其中至少两个高于最佳、两个低于最佳；中粒土在最佳附近取一个百分点、其余两个百分点，细粒土一律两个百分点，重粘土可能要三个百分点。表 12-2 按土种给经验范围，五行从砂性土一直到细土偏多的砂砾土。加水量由式 12-1 算：三项相加乘目标含水量，再减素土自带的水、再减结合料自带的水。

浸润时间查表 12-3：粘性土十二到二十四小时、粉性土六到八小时、砂性土一类四小时、未筛分碎石（含土很少）两小时。浸润完再加结合料拌匀；**掺水泥的料必须在一小时内击实完，超时作废**（石灰与石灰粉煤灰不受此限）。

击实：甲法每层取四百到五百克（击实后约达筒高的五分之一），整平稍压，击二十七次；第一层打完检查层高，据此调后面几层的料量；层间把表面拉毛。最后一层打完，试件超出筒顶不得大于六毫米，超出过多作废。刮平、拆底板、擦净、称筒加试样总质量（准确到五克）。用脱模器推出，上下各取一个有代表性的样测含水量（取样量见表 12-4），两样含水量之差不得大于一个百分点，只取一个样则质量加倍。**用过的试样一律不再用。**

乙法用于缺十厘米试筒、或还要拿击实件去做承载比等其它试验的场合；每层取约九百克（稳定细粒土）或一千一百克（稳定中粒土），每层五十九击，加料前先把五十毫米垫块放进筒底。丙法每次取一点八千克左右（约达筒高三分之一），每层九十八击，含水量取样不少于七百克、只取一个则不少于一千四百克。

结果：式 12-2 得含水量、式 12-3 得湿密度、式 12-4 得干密度（精确到零点零一克每立方厘米）。以干密度为纵轴、含水量为横轴作图，驼峰的最高点即最大干密度与最优含水量；点太少、连不成完整驼峰时要补做。最优含水量的报法分三档：大于十二个百分点取整数、精确到一个百分点；六到十二之间用一位小数、精确到零点五个百分点；小于六个百分点用一位小数、精确到零点二个百分点。超尺寸颗粒含量小于五个百分点不校正；五到三十个百分点按式 12-5、12-6 校正。精度：两次平行试验的最大干密度之差不超过零点零五（细粒土）或零点零八（中粒土与粗粒土）克每立方厘米，最优含水量之差不超过零点五（最优含水量小于十个百分点）或一个百分点（大于十个百分点）。

第二节做强度。表 12-5 给三行：细粒土最少六个试件、试模五十乘五十毫米、剔除十毫米以上颗粒、测含水量取样一百克、单个试样用料一百八十到二百一十克、平行试样变异系数小于十个百分点；中粒土九个、一百乘一百、剔除二十到二十五毫米、取样一千克、用料一千七百到一千九百克、变异系数小于十五个百分点；粗粒土十三个、一百五十乘一百五十、剔除四十毫米、取样二百克、用料五千七百到六千（克）、变异系数小于二十个百分点。（本轮按试模体积乘干密度区间复核用料量〔复算〕：九十八点二、七百八十五点四、二千六百五十点七立方厘米，配一点七到二点二克每立方厘米，落在表给区间内，合。）

制件：由式 12-7 得计算干密度（最大干密度乘施工压实度），式 12-8 得一个试件所需的混合料质量（计算干密度乘试模体积再乘一加最优含水量）。细粒土可一次称六个试件的土、中粒土一次三个、粗粒土一次一个。细粒土先按比最优含水量少三个百分点加水，拌结合料时再把预留的三个百分点补进去；中粒土与粗粒土直接按最优含水量加。水泥类结合料的混合料一小时内制成试件，超时作废。成型时下压柱放进试模下部、外露两厘米左右，混合料分两到三次灌入，用夯棒插实；上压柱也外露两厘米（上下相等）。用反力框架配千斤顶加压，直到上下两个压柱都完全进入试模，维持压力一分钟；脱模后称质量（小试件准确到一克、中试件二克、大试件五克），游标卡尺量高（准确到零点一毫米）。

养生：脱模称量后立即放进密封湿气箱与恒温室保湿保温；中号与大号试件先裹一层塑料薄膜，条件允许时再蜡封保湿。养生时间视需要，工地控制通常取七天。整个养生期的温度：**北方二十正负二摄氏度，南方二十五正负二摄氏度。**养生期最后一天把试件泡进水里，**水面在试件顶上约二点五厘米**；泡水之前再称一次质量，养生期间的质量损失（前后两次称量之差）**小试件不超过一克、中试件不超过四克、大试件不超过十克**，超了就作废。

破型：从水中取出、毛巾吸去表面自由水、称质量、量高（零点一毫米）。置于路面材料强度试验机的升降台，台上预先放扁球座，使形变等速增加、速率约每分钟一毫米，记下破坏荷载；再从破型件内部取样测含水量。式 12-9 得无侧限抗压强度（荷载除截面积），式 12-10 得九十五个百分点保证率的代表值（均值减一点六四五倍标准差）。报告要给颗粒组成、结合料种类、最优含水量与最大干密度、剂量、试件干密度与含水量，以及强度的五项统计量（均值、最小、最大、标准差、变异系数）与保证率强度值。修约规则：计算值低于二点零兆帕时写两位小数、数值取偶；高于二点零兆帕时写一位小数。

选法的动作只有一条链：先过五毫米 → 看有没有大于五毫米的颗粒 → 过二十五毫米 → 看筛上留量是否超过二十个百分点 → 定甲乙还是丙。**这条链走错，后面每一个数都换了意义。**

### I.2 式 12-1 的末项：一处可以用"素土"证伪的错

书印的加水量式，末项的分母与第二项相同（都以素土质量与素土风干含水量为底）。按符号表，末项该是"结合料自带的水"，底数应是结合料质量与结合料原始含水量。

**证伪一步就够**：令结合料质量为零（纯素土，不掺水泥也不掺石灰），末项按符号表应得零；按书印的式子却不为零，还会被减掉，于是算出来的加水量偏小。本轮以干土一千九百六十点八克、素土含水量两个百分点、结合料含水量三个百分点、目标含水量十个百分点代入〔复算〕：末项得五十八点八二克，加水量从一百五十六点八六克掉到九十八点零四克，偏小三十七点五个百分点。**这是本章唯一一处"按符号表读就错、按物理意义读才对"的式子**，也是本篇公式符号类错的代表。

三点读法：

1. **"五十×五十"是直径×高还是边长×边长，书未写明。** 按圆柱反算体积与"单个试样用料一百八十到二百一十克"相符〔复算〕，所以按圆柱读；这条读法必须写进报告，否则体积不确定。
2. **条数由变异系数上限定，不由仪器定。** 三个上限递增，条数也递增——土越粗、离散越大，要的件数越多。**不能拿"六个"套到粗粒土上。**
3. **用料量与试模体积自洽。** 本轮按体积乘干密度区间复核〔复算〕，三档都落在表给区间内，所以这张表在数值上是可信的（与本篇"正文数值基本可信"的结论一致）。

### I.5 代表值：式 12-10 是下限，不是均值

- 式 12-9：单值 = 破坏荷载 / 截面积。
- 式 12-10：代表值 = 均值 − 一点六四五 × 标准差。
- 一点六四五这个系数属"九十五个百分点保证率、单侧"的换算，**是统计换算，不是判据**。它与均值是两个量：报均值不能说"代表值"，报代表值不能省掉标准差。
- **截面积的取法书未定义**（F5）：只说"试件的截面积"，没说按试模公称直径还是实测直径。以直径五十为例，公称与实测差二个百分点量级，同一个荷载下强度就差同比例。**这与第四章"受压面积无定义"是同一类问题，换了个地方又出现一次。**处置：报告必须写"截面积按公称直径"或"按实测直径"，并全文一致。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】六段演练，输入是"一份配合比资料 + 一个诉求"，输出只写走不走得通、停在哪一步。**不出现任何数值结果**：不写干密度、不写含水量、不写强度、不写代表值；数字只作表号、式号、页号与土类档位出现。

**演练一（选法选错）**
输入：料里有一批超出细料档的大颗粒，筛上留量不少，报告仍用乙法击实。
→ 判：I.1。超过二十五毫米颗粒多时要过四十毫米筛、走丙法；乙法本身不排斥大颗粒料，但筒与层数都为细料设计。
→ 输出：**停**。先按"过五毫米 → 过二十五毫米 → 看留量"这条链重定法。
→ 不输出：任何干密度、任何"两法差不多"的判断。

**演练二（加水量末项）**
输入：素土不掺结合料，报告仍按书印式子算了末项并扣掉。
→ 判：I.2。结合料质量为零时末项应为零；按书印式子会被减掉一块。
→ 输出：**停**。按符号表重算；并在报告里写明"末项底数为结合料质量"。
→ 不输出：加水量、也不给偏差百分数。

**演练三（七天当成七天泡水）**
输入：试件从成型当天起泡在水里七天，然后破型。
→ 判：I.4。七天是六天保湿加一天浸水；全程泡水不是同一条链。
→ 输出：**停**。按六加一重做；水面高度与浸水前称量一并补。
→ 不输出：任何强度。

**演练四（质量损失没报）**
输入：试件在养生期掉了些质量，报告没记，直接破型。
→ 判：I.4 末两行。浸水前要称一次，损失超限作废；没有这一步就没有作废判据。
→ 输出：**停**。补称、补记；超限按作废处理。
→ 不输出：任何"损失多少算超"以外的判断（上限本身是书值，见 I.4）。

**演练五（报均值当代表值）**
输入：报告只给一组强度的算术平均，标题写"九十五个百分点保证率代表值"。
→ 判：I.5。代表值要减一点六四五倍标准差，与均值是两个量。
→ 输出：**停**。要么报均值、要么报代表值并附标准差，不许混名。
→ 不输出：代表值、标准差、任何换算。

**演练六（截面积不声明）**
输入：报告给了破坏荷载，截面积只写"按试件截面积"，未说公称还是实测。
→ 判：I.5 末段。两种取法给出的强度不同，且差多少取决于直径差。
→ 输出：**停**。声明取法并全文一致。
→ 不输出：任何强度值。

**预期输出表**：`资料｜哪一法｜粒径与法对不对｜加水量末项底数｜浸润与一小时限｜含水量分布｜平行差｜表 12-5 哪一行｜养生温度与六加一｜质量损失｜均值还是代表值｜截面积取法｜判到哪一步｜停判点｜依据页`。

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **拿三个击实法当三档精度。** 它们限的粒径不同（I.1）。
2. **按书印式 12-1 的末项算加水。** 素土时会被扣掉一块（I.2）。
3. **把七天当七天泡水。** 是六加一（I.4）。
4. **养生温度不分南北。** 两档差五摄氏度（I.4）。
5. **不称浸水前质量就破型。** 作废判据没有落点（I.4）。
6. **把均值当九十五个百分点保证率代表值。** 两回事（I.5）。
7. **截面积取法不声明。** 差二个百分点量级（I.5）。
8. **拿"六个试件"套粗粒土。** 条数由变异系数上限定（I.3）。
9. **在本章找七天强度的标准值。** 在第六章表 6-4（I.6）。
10. **把 p338–p341 当章内容。** 那是全书参考文献（卡头第 2 条）。

### H2 — 用前必须声明

1. 本卡的干密度与兆帕属**试验篇的口径**：甲／乙／丙三法各自的试筒与层数击数、规定浸润时间、六天保湿加一天浸水的七天、北方或南方的养生温度。离开这套口径，同名量不是同一个量；与胶砂四十乘四十乘一百六十、混凝土立方体的强度也不可互比。
