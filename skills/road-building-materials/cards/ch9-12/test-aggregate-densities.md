# test-aggregate-densities — 集料的五种密度与两个空隙率：名字一换，分母就换

> **卡型：口径卡（不产生数值结论）**——本卡回答的不是"这批砂好不好"，而是"你手上这个密度数，是用哪套分母称出来的"。同一组称量能长出五个密度，差别全在分母；空隙率的分母还要跟着集料的去向再换一次。
>
> 主要取材：p286–p292（第二节全节，覆盖试验 9-4～9-8）、表 9-4（水温修正）、表 9-6（容量筒规格）、式 9-3～9-15
>
> 挂靠候选（4 条）：`f01`、`g01`、`p02`、`ce05`

**卡头必读（六句）**

1. **本篇 35 个试验里，"多少算合格"只有一条**——水泥安定性的 C−A ≤ 5.0 mm（p320–321）。剩下 34 条给的全是**有效性判据、取舍规则、统计换算**。所以本卡从头到尾不问"这块集料够不够格"，只问"这个密度值在什么条件下才成立"。
2. **五种密度不是五个试验，是五套分母。** 分母里装什么，密度就叫什么；名字是结果，不是定义。
3. **空隙率有两个，分母不一样。** 走水泥混凝土那条线，n 的分母是表观密度（式 9-14）；走沥青集料骨架，VCA_DRC 的分母是毛体积密度（式 9-15）。同一堆料套两式，得两个数，且都不算错。
4. **本卡入口处就埋着一处符号互換**（p286–p287）：试验步骤里把"含试样的那次称量"叫 m1、不含的叫 m2，而符号表与式 9-3 的要求恰好相反。按步骤的编号代进去，结果不是偏一点，是掉到真值的零头。
5. **34 幅图没有一幅能读出内容。** 本卡要用到的几何（图 9-3 的漏斗与容量筒、图 9-5/9-6 的受压钢模、表 9-6 后面的筒形状）只能凭文字复原，凡"看图取尺寸"的环节一律降档。
6. **平行差管的不是质量，是这次测量算不算数。** 细集料两次相差超 0.01 g/cm³ 重取试样、粗集料密度差超 0.02 g/cm³ 与吸水率差超 0.2% 要重做——这三条都是有效性判据，判的不是料的等级。

## R — 原文说了什么（转述，非摘录）

第二节把"集料的密度"拆成一条流水线：先缩分取样，再对一份料做一组称量，最后按要报的名字挑一个分母。细集料走容量瓶：称干样、称"瓶加水"、称"瓶加水加样"，三次称量进式 9-3，出来的是表观密度；水温在 15–25 ℃ 之间变动时，用表 9-4 的六档修正系数把水的相对密度拉回 4 ℃ 基准，系数从 0.002 到 0.007。

粗集料走网篮：一份料在水里称一次、在饱和面干状态下称一次、烘干后再称一次，三次称量分别记作水中重、表干重、干重；式 9-9 到 9-11 拿这三个数的不同组合做分母，一次给出表观密度、饱和面干密度、毛体积密度；式 9-12 再把表干与干重之差除以干重，得吸水率。这里也查同一张表 9-4。

装填密度是另一条支线：细集料用固定容积约一升的容量筒，分堆积与颠实两态（式 9-4、9-5）；粗集料用表 9-6 按最大粒径配筒，分堆积、振实、捣实三态（式 9-13）。空隙率随后跟上：细集料的 n 除以表观密度（式 9-6），粗集料给水泥混凝土用时也除以表观密度（式 9-14），给沥青混合料用的骨架间隙率则除以毛体积密度（式 9-15）。

棱角性另立一条：用一只 100 mL 铜容器接住从标准漏斗自由落下的细集料，刮平后称量，式 9-7 得堆积密度，式 9-8 得空隙率，而**这个空隙率就是棱角性**——书里没有直接量颗粒形状，而是用"装得松不松"去间接表征棱角与表面构造。

## I — 判据骨架

### I.1 五种密度：分母里装了什么〔数值待核原图〕

| 报出的名字 | 分母里装的东西 | 分子用哪个称量 | 式 | 页 |
|---|---|---|---|---|
| 表观密度 ρ_a（细） | 只算矿质实体，可透水孔不算 | 干样质量 | 9-3 | p287 |
| 表观密度 ρ_a（粗） | 同上 | 干重 | 9-9 | p290 |
| 饱和面干密度 ρ_s | 矿质实体 + 开口孔里的水 | 表干重 | 9-10 | p290 |
| 毛体积密度 ρ_b | 矿质实体 + 全部开口孔 | 干重，分母用表干重减水中重 | 9-11 | p290 |
| 装填密度（堆积／振实／捣实） | 颗粒 + 颗粒之间的空隙 | 筒加料总质量减筒质量 | 9-4、9-5、9-13 | p288、p292 |

读法只有一句：**先看分母，再看名字。** 分母里出现"水"的那一项，密度值一定比表观密度小；分母里再掺进颗粒间空隙，值会更小。反过来，若某个报告的毛体积密度大于表观密度，不必查别的，先怀疑它把两次称量的角色调换了。

### I.2 两个空隙率：分母是分水岭

- 水泥混凝土用集料：n =（1 − 装填密度 / 表观密度）× 100%，式 9-14，分母是 ρ_a。
- 沥青混合料用粗集料骨架：VCA_DRC =（1 − 捣实密度 / 毛体积密度）× 100%，式 9-15，分母是 ρ_b。
- 细集料的 n：式 9-6，分母同样是 ρ_a；而棱角性那一支用式 9-8，分母却换成 ρ_b。

**为什么不能通用**：沥青集料要的是"骨架里还剩多少空间给沥青"，颗粒自身的开口孔是要被沥青填进去的，所以分母必须把开口孔算进体积（毛体积）；水泥混凝土那边要的是"矿质实体占了多少"，开口孔归水，所以分母用实体。**换分母不是笔误，是两个问题。** 书上式 9-14 的符号说明把装填密度限定为"按振实法"，但同一条目的正文允许堆积、振实、捣实三种状态，三态共用一条式子而分母只对其中一类料成立——这处分工没写清，是式 9-14 的固有缺陷（〔公式待核〕）。

### I.3 一次称量能长出几个指标：两条路

**细集料（容量瓶）**：干样质量 m0、瓶加水的质量、瓶加水加试样的质量 → 表观密度（式 9-3）；再配一只容量筒，得堆积密度与振实密度（式 9-4、9-5），进而空隙率（式 9-6）；若走棱角性装置，得式 9-7 与式 9-8。

**粗集料（网篮）**：干重 m_a、水中重 m_w、表干重 m_f → 三个密度（式 9-9～9-11）加吸水率（式 9-12）；再配表 9-6 的筒，得三态装填密度（式 9-13）与两个间隙率（式 9-14、9-15）。

注意粗集料这一路对符号的用法与细集料不平行：细集料那边式子里出现的是"瓶加水"这一类容器质量，粗集料这边全部是试样自身的三个状态质量。**跨粗细集料套式子，必然错。**

### I.4 两个门槛：温度修正与平行差

- **水温修正**（表 9-4）：15 ℃ 取 0.002，16–17 ℃ 取 0.003，18–19 ℃ 取 0.004，20–21 ℃ 取 0.005，22–23 ℃ 取 0.006，24–25 ℃ 取 0.007〔数值待核原图〕。修正量是"减去"还是"加上"，要跟式子里 α_T 前面的符号一致；式 9-12 把 α_T 从"两个质量之比"里减掉，这一步在量纲上讲不通（吸水率是两个质量之比，不带水的相对密度），是本卡的登记项而非可执行项〔公式待核〕。
- **平行差**（有效性判据，不是合格线）：
  - 细集料表观密度两次之差 > 0.01 g/cm³ → 重新取样〔数值待核原图〕；
  - 粗集料密度两次之差 > 0.02 g/cm³、吸水率两次之差 > 0.2% → 重做〔数值待核原图〕；
  - 装填密度：两次结果取算术平均，书未给差值阈值——这是一处**缺判据**，不是"没有要求"。

### I.5 本卡必记的三处硬伤

1. **式 9-3 的步骤与符号表互換（p286–p287）。** 步骤把"瓶 + 水 + 试样"记成 m1、把"瓶 + 水"记成 m2；而同一页的符号表与式 9-3 要求 m1 里没有试样、m2 里才有试样。分母是"m0 + m1 − m2"：按符号表，它是"试样排开的水的质量"；按步骤编号，它变成 m0 再减一次排水质量，结果随试样质量一起塌下去。本轮以 300 g、2.65 的砂代入两种编号〔复算〕：按符号表得 2.650，按步骤编号得 0.616——只有真值的 23%。**这不是精度问题，是编号问题。**
2. **式 9-12 减了 α_T。** 吸水率是（表干 − 干）/ 干，两个质量之比，量纲一；把水的相对密度修正量减在这个比值上，等于把两个不相干的量相减。同时吸水率本身也不该随水温变。登记为不可执行〔公式待核〕。
3. **表 9-6 的 53 mm 那一行。** 内径 355、净高 305，按圆柱反算容积 30.19 L，而表里标 20 L〔复算〕。用这一行算装填密度，分母小了三分之一，密度值会偏大三成。表里其余六行复算全合（10／20／30／3／10／15 L，偏差 ≤0.7%），所以不是体例问题，是单行错。

### I.6 审查清单（拿它审一份密度报告）

1. 报的是哪个密度？分母写清了没有（实体／实体加水／实体加开口孔／加颗粒间空隙）？
2. 细集料的 m1／m2 是按符号表的含义填的，还是按试验步骤的编号填的？
3. 水温记了没有？α_T 查的哪一档？式子里 α_T 前面是加还是减？
4. 空隙率的分母是 ρ_a 还是 ρ_b？这份料是给水泥混凝土还是给沥青混合料？
5. 平行差报了吗？差多少？超阈值是"重做"还是"取平均"？
6. 装填密度用了表 9-6 的哪一行？是不是 53 mm 那一行？
7. 棱角性报的是空隙率本身，还是另给了一个"棱角指数"？后者本书没有。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】四段演练，输入是"一份资料加一个诉求"，输出只写走不走得通、停在哪一步。**不出现任何数值结果**：不写密度值、不写差值的数、不写偏差的百分数；文中的数字只作式号与页号出现。

**演练一（报了个密度，没说分母）**
输入：一份集料检测单只写"密度"加一个数，没说是哪一种密度；委托方要把这个数填进配合比设计的体积参数表。
→ 判：I.1。名字没给，分母就定不下来；毛体积与表观密度可以差到影响空隙率的量级。
→ 输出：**停**。先问"这是哪一个密度、分母里装了什么"。
→ 不输出：任何密度值、任何"大约相当于"的换算。

**演练二（照步骤编号代式子）**
输入：记录本上写着"按 p287 的步骤，先称瓶加水加试样，再称瓶加水"，两次数都编了号，代进式 9-3。
→ 判：I.5 第 1 条。步骤编号与符号表相反，代进去分母会被重复扣一次试样质量。
→ 输出：**停**。要求把两次称量按符号表的含义重新对号，再代。
→ 不输出：重新代入后的密度值，也不给"差多少倍"。

**演练三（空隙率换了分母）**
输入：报告给沥青混合料粗集料算骨架间隙率，分母用的是表观密度，理由是"上一份水泥混凝土的报告也这么算"。
→ 判：I.2。两式的分母分属两个问题；沥青那边要的是毛体积。
→ 输出：**停**。分母换回毛体积后重算；并注明这是式 9-15 而非式 9-14。
→ 不输出：两个分母各得多少、差几个百分点。

**演练四（用表 9-6 的某一行）**
输入：装填密度报告写"容量筒容积按表 9-6 取"，没写取哪一行，也没写内径与净高。
→ 判：I.5 第 3 条。该表有一行反算与标称不符；不点行号就无法判断分母对不对。
→ 输出：**停**。要行号；落在被疑那一行就整条重做。
→ 不输出：该行反算容积、也不给偏差百分数。

**预期输出表**：`诉求｜报的是哪个密度｜分母写清没有｜符号按哪套对号｜料去向（水泥混凝土／沥青）｜平行差状态｜判到哪一步｜停判点｜依据页`。

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 集料粗细（决定走容量瓶还是网篮） | 枚举 | 必需 | 缺 → 先问；两套符号不通用 |
| 要报的密度名（表观／饱和面干／毛体积／装填） | 枚举 | 必需 | 缺 → 停（停判点 1） |
| 三次称量的原始记录（含各自对应哪个状态） | 数值组 | 必需 | 缺 → 停；只有结果没有称量，无法判分母 |
| 试验水温 | 数值 | 必需 | 缺 → 修正项无依据，结论降级为"未修正" |
| 集料去向（拌水泥混凝土／拌沥青混合料） | 枚举 | 必需 | 缺 → 空隙率分母无法定（停判点 3） |
| 平行试验次数与两次之差 | 数值对 | 必需 | 缺 → 无法判有效性（停判点 5） |
| 容量筒的规格（内径、净高、标称容积） | 三元组 | 条件必需 | 走装填密度时必需；缺 → 停（停判点 4） |
| 筛孔制（方孔／圆孔） | 枚举 | 条件必需 | 走棱角性或网篮时必需 |

**步骤**

1. **定名**：先问要报哪个密度，把名字与分母一起写下（I.1）。
2. **对号**：把三次称量按符号表的含义贴上符号；细集料特别注意 m1 里不含试样（I.5 第 1 条）。
3. **取修正**：按水温查表 9-4，确认 α_T 在式子里的符号（I.4）。
4. **代式**：按名字选式（细集料 9-3；粗集料 9-9～9-11），不带任何换算。
5. **补空隙率**：按料去向选分母（水泥混凝土 ρ_a，沥青 ρ_b），选式 9-6／9-14／9-15（I.2）。
6. **验有效性**：查平行差阈值；超阈值按"重做"，不按"取平均"（I.4）。
7. **查筒**：若走装填密度，把表 9-6 的行号、内径、净高、标称容积一起抄进报告；落在 53 mm 行则整条不走（I.5 第 3 条）。
8. **加声明**：两条必备声明（B 段 H2 第 1、2 条）。

**停判点**（命中任一条即停，不再往后走）

1. 只给"密度"两个字、不给名字 → 停（分母未定，I.1）。
2. 细集料的 m1／m2 按试验步骤的编号填、未按符号表对号 → 停（I.5 第 1 条；这不是精度问题）。
3. 空隙率的分母与料的去向不匹配 → 停（I.2）。
4. 装填密度用表 9-6 的 53 mm 行、或未写行号 → 停（I.5 第 3 条）。
5. 平行差超阈值却打算取平均 → 停（I.4，有效性判据）。
6. 想把式 9-12 的 α_T 当"温度补偿"直接照减 → 停（量纲不通，I.4）。
7. 要把本卡的密度直接当第三章的 VMA／VV 用 → 停（跨章不可互换，B 段 H1 第 6 条）。
8. 报告引了图 9-3／9-5／9-6 的尺寸当依据 → 降档；该图无内容，尺寸只能凭文字（卡头第 5 条）。

**输出契约**——字段固定：

`报的是哪个密度｜分母｜符号对号依据｜水温与 α_T｜平行差状态｜料去向｜筒规格与行号｜判到哪一步｜停判点｜依据页`

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **只凭一个"密度"数字做配合比体积参数。** 分母不明，填进去就是错的（I.1）。
2. **照试验步骤的编号代式 9-3。** 结果掉到真值零头（I.5 第 1 条，〔复算〕）。
3. **拿水泥混凝土集料的空隙率式去算沥青骨架间隙率。** 分母该换（I.2）。
4. **用表 9-6 的 53 mm 行。** 反算与标称差五成，密度跟着偏大三成（I.5 第 3 条，〔复算〕）。
5. **把平行差阈值当"合格线"。** 它判的是这次测不测得准，不是这批料能不能用（卡头第 6 条）。
6. **把本卡的密度当第三章的 VV／VMA／VFA 用。** 试验篇只给"数怎么来"，不给"数够不够"，也不给配合比的体积换算（BRIEFING 第五节的跨书规则）。
7. **用式 9-12 做温度修正。** 吸水率不带水的相对密度（I.4）。
8. **引图取尺寸。** 图 9-3、9-5、9-6 无内容（卡头第 5 条）。
9. **把"细集料棱角性"当颗粒形状的直接量。** 它是空隙率，是间接表征（R 段末）。

### H2 — 用前必须声明

1. 本卡的密度与空隙率属**试验篇的口径**：细集料 15–25 ℃ 容量瓶法、粗集料网篮法、水温按表 9-4 修正。离开这套口径，同名密度不是同一个量。
2. 平行差、两次差值是**有效性判据**，不是合格线；本篇只有一条真合格线（安定性），与本卡无关。
3. 式 9-3 的符号按**符号表**对号；凡是按试验步骤编号记录的原始数据，都要先对号再代。
4. 表 9-6 的 53 mm 行已标"疑误"，任何引用该行的密度值都要注明"分母待核"。
5. 本卡不回答"这块集料能不能用"；要判合格，回第一章的表 1-16 一类门槛表（BRIEFING 第十一节）。

### 本章缺口对本卡的影响

| 缺口 | 对本卡 |
|---|---|
| 式 9-3 步骤与符号表互換（F1） | 不先对号，分母就错，整条链废 |
| 式 9-12 减 α_T（F2） | 吸水率只能按"两个质量之比"算，修正项不用 |
| 表 9-6 53 mm 行（T1） | 该行不能用于装填密度 |
| 式 9-14 分母三态混用（F7） | 三态共式，分母只对一类料成立 |
| 图 9-3／9-5／9-6 无内容（G1） | 尺寸只能凭文字，凡"看图"即停 |
| 装填密度无平行差阈值 | 缺判据，只能标"书未给" |

**不要用本卡做的事**：判集料合格与否、给跨章体积参数、给"看图取尺寸"的结果、给未对号数据的密度、给吸水率的温度修正、给 53 mm 行的密度。
