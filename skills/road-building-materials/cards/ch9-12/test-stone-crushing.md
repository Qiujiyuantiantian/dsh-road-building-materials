# test-stone-crushing — 石料抗压与三种"抗碎"：同名不同物，先判测的是哪一个

> **卡型：口径卡（不产生数值结论）**——"压碎值""压碎指标值""磨耗率"三个名字都像在说"碎了多少"，实际是三套荷载、三个筛孔、三种分子方向。本卡先把这三家分清楚，再说石料本体那一项。
>
> 主要取材：p283–p286（试验 9-1～9-3）、p295–p298（试验 9-11～9-13）、表 9-1、9-2、9-3、式 9-1、9-2、9-17、9-18、9-19
>
> 挂靠候选（4 条）：`f02`、`ce01`、`g02`、`p04`

**卡头必读（六句）**

1. **本篇 35 个试验里，"多少算合格"只有一条**——水泥安定性 C−A ≤ 5.0 mm（p320–321）。其余全是有效性判据、取舍规则、统计换算。**本卡给出的压碎值、磨耗率、抗压强度，只回答"这个数在什么条件下才成立"，不回答"这个数够不够"。**要判合格，回第一章门槛表。
2. **三个"抗碎"是三道不同的题。** 石料本体压到破坏；洛杉矶／狄法尔靠钢球撞击与互磨；压碎值靠逐级加荷。荷载从几千牛到四百千牛，筛孔从 1.7 mm 到 2.36 mm，两两不通用。
3. **三个压碎量的分子方向彼此不一致。** 卵石碎石是"损失／总"，沥青粗集料是"通过／总"，砂是"通过／（通过 + 筛余）"。把一式的式子搬到另一式，得到的往往是补数。
4. **本卡的入口有一处单位量级错（p283）。** 压力机写成"三百到两千牛"，而试件截面是五十毫米见方；这个量级的机器连岩石表面都压不出裂纹。**本卡不替它改数，只登记。**
5. **34 幅图无一有内容。** 三种受压钢模（图 9-5、9-6、9-7）的尺寸取不到，模子的内径与压头形状只能凭文字。
6. **第一章表 1-16 的方向印反了。** 那张表把压碎值要求写成"≥"，而四个值随公路等级降低而增大——正确方向是"≤"。**照抄会把不合格料判成合格**（BRIEFING 第十一节已核实）。本卡只说这件事，不改表。

> **公式**：式 9-1、9-2、9-17、9-18、9-19 全部〔公式待核〕；式 9-2 被洛杉矶与狄法尔两处引用，同一个式子两次出现。
>
> **数值**：书里的荷载、筛孔、平行差阈值、试件尺寸一律〔数值待核原图〕，并连条件（试件形状、加荷速率、筛制、转动次数）。凡标〔复算〕的是本轮自己算的。
>
> **页码**：印刷页（本篇 283–341）。

## R — 原文说了什么（转述，非摘录）

石料本体那一项，先做试件：从岩芯或岩块上切出边长五十毫米的立方体，或直径与高都为五十毫米的圆柱，六个一组；有层理的岩石要多取一组，沿平行与垂直层理各六个，两个方向的强度分别报，最后取两者平均。试件上下端面要磨平且互相平行。量尺寸精确到零点一毫米：立方体取各面平行两边的平均，圆柱取顶面与底面两个方向的直径平均，再把顶底两个面积平均，作为受力面积。

饱水程序写得相当具体：试件放进真空干燥器，加水漫过顶面，抽到二十毫米汞柱的真空，保持到表面不再冒气泡为止（且不少于四小时），关泵后再在水中放两小时，随后自由浸水两天，水面始终高出试件。取出擦干、查缺陷、标受力方向、编号，按方向放到压力机上，以每秒零点五到一兆帕的速率加荷至破坏，记下破坏荷载。强度由式 9-1 给出：破坏荷载除以受力面积，精确到一兆帕。六个试件的算术平均为测定值；若其中两个与另外四个的平均相差"三倍以上"，就只取相近的四个平均。

磨耗有两条路。洛杉矶法用一只内径七百一十毫米、内侧长五百一十毫米的钢筒，转速三十到三十三转每分，筒里放十二个直径约四十八毫米的钢球，总质量五千克；水泥混凝土用集料按表 9-1 配粒级、总质量五千克、转五百转；沥青路面用集料按表 9-2 分 A 到 G 七类，A 类五百转，E、F、G 三类一千转、总质量十千克。转完用一点七毫米方孔筛（沥青料）或二毫米圆孔筛（水泥混凝土料）筛去石屑，洗净烘干称量，式 9-2 得磨耗率，两次平行差不超过百分之二。狄法尔法用两只内径二百毫米、深三百四十毫米、倾斜三十度的钢筒，石块互磨，转一万转；碎石取五十到七十五毫米的两份、每份五十块上下、每块约一百克，砾石按表 9-3 配四千克；筛孔碎石用二毫米、砾石用二点五毫米；同样用式 9-2，但两次平行差收紧到百分之一。

压碎分三家。砂用的是单粒级：每级三百三十克，装进受压钢模，以每分钟五百牛的速率加到二十五千牛，稳五秒再卸，取下限筛过筛，式 9-17 得该粒级的压碎指标值，三级各做三次取平均，最后以最大那一级的数值代表整个试样。卵石碎石用九点五到十九毫米的粒级三千克，分两层装、每层颠二十五下，以每秒一千牛加到二百千牛，稳五秒，二点三六毫米筛过筛，式 9-18 得压碎指标值，三次平均。沥青路面粗集料取十三点二到十六毫米约三千克，分三层各夯二十五下，十分钟内加到四百千牛后立即卸荷，二点三六毫米筛称通过量，式 9-19 得压碎值，两次平行。

### I.2 三个分子方向：为什么不能互换

- 式 9-18：`Q_a =（m0 − m1）／m0`。m0 是试前质量、m1 是筛余质量，所以分子是**被压碎掉的那部分**。
- 式 9-19：`Q_a′ = m1／m0`。这里 m1 是**通过二点三六毫米筛的细料**，分子是通过量本身。
- 式 9-17：`Y_i = m2／（m1 + m2）`。分母是"筛余 + 通过"的合计，分子是通过量。

三者都是"碎掉的比例"，但一个用减法、一个用除法、一个把分母写成合计。**把式 9-18 套到沥青粗集料上，得到的是"一减压碎值"**——数值看起来同样落在合理区间，因此不会报错，只会把方向反过来。这是本卡最贵的一处。

另有一处同式内的不一致：式 9-19 的符号说明写"通过三毫米筛孔"，而步骤用的是二点三六毫米筛。同一个式子里两个筛径，取哪个要看步骤，但报告上必须写明"按步骤的二点三六毫米"〔公式待核〕。

### I.3 剔除与重做：两级，不是一级

- **石料抗压**：六个一组，其中两个与其余四个的平均相差"三倍以上"才剔除，取相近四个平均；有层理者先按方向各自平均，再把两个方向的平均再平均一次。**"三倍"这个阈值宽到近乎失效**——强度差三倍的两个试件已经不是同一种材料了，疑为百分之三十或三倍标准差〔数值待核原图〕。这是登记项。
- **磨耗**：洛杉矶两次平行差 ≤2%，狄法尔 ≤1%，超了重做。**两个数不一样，不能互相套。**
- **压碎**：砂三级各三次取平均；卵石碎石三次平均；沥青粗集料两次平行取平均。书**没有**给这三家的平行差阈值——缺判据，只能标"书未给"。

### I.5 第一章表 1-16 的方向问题（跨章，只说一次）

第一章那张压碎值要求表把四个数印成"≥26／30／35／40"，而四个数随公路等级降低而**增大**——要求越松数越大，所以正确方向是"≤"。照"≥"读，最差的料也满足最严的要求，**不合格会被判成合格**。本卡的作用是把这件事挂在"压碎值"这个名字旁边：只要有人拿表 1-16 的限值来对本章的压碎值，先问方向。

## A1 — 演练（合成场景，非书中案例，0 个数值结果）

【合成演练，非书中案例】五段演练，输入是"一份委托 + 一份记录"，输出只写走不走得通、停在哪一步。**不出现任何数值结果**：不写强度、不写压碎值、不写磨耗率、不给偏差倍数；数字只作式号与页号。

**演练一（只写"压碎值"三个字）**
输入：委托单写"测压碎值"，料是沥青路面表面层用的碎石。
→ 判：I.1。同名三项，荷载与筛孔完全不同；料的去向已经指向沥青粗集料那一家。
→ 输出：**走**沥青粗集料那一条；同时要求委托方确认不是水泥混凝土用料的压碎指标值。
→ 不输出：任何压碎值、任何"两者差不多"的话。

**演练二（把减法的式子搬到除法那一家）**
输入：记录完整，报告却用卵石碎石那条式子的形式去算沥青粗集料的压碎值。
→ 判：I.2。分子方向反了，得到的是一减压碎值。
→ 输出：**停**。换回该家的式子重算；并在报告里写"分子为通过量"。
→ 不输出：重算后的值、也不给"差多少"。

**演练三（量级不对的机器）**
输入：报告引 p283 的机器规格，说"设备满足要求"。
→ 判：I.4 第 1 行。该处单位量级与试件截面不匹配。
→ 输出：**停**。要求核对设备铭牌；不核就不能声称满足。
→ 不输出：任何"应该用多大的机器"的建议值（书里没有，不补）。

**演练四（平行差用错了家）**
输入：狄法尔法的两次结果差落在洛杉矶法的阈值内，报告写"合格"。
→ 判：I.3。两家的阈值不同，宽的不能套到严的上。
→ 输出：**停**。按狄法尔那一家判；不够就重做。
→ 不输出：具体差值、也不给"超了多少"。

**演练五（拿限值直接判）**
输入：报告拿第一章那张表的限值直接与本章的压碎值比，结论"满足"。
→ 判：I.5。那张表方向印反；且本章三项压碎量互不通用。
→ 输出：**停**。先把方向改过来、把"哪一家的压碎值"对上，再比。
→ 不输出：任何"满足／不满足"的判定。

**预期输出表**：`委托｜料的去向｜走哪一家｜荷载与筛孔对不对｜分子方向｜平行差阈值｜限值来源与方向｜判到哪一步｜停判点｜依据页`。

## E — 执行步骤

**输入契约（缺任一"必需"项：先问，不判）**

| 字段 | 类型 | 必需性 | 缺失时处置 |
|---|---|---|---|
| 料的去向（水泥混凝土／沥青路面／石料本体） | 枚举 | 必需 | 缺 → 停（停判点 1） |
| 要报的量名（抗压／磨耗／压碎值／压碎指标值） | 枚举 | 必需 | 缺 → 停；同名不同物 |
| 试件或料的粒级与质量 | 数值组 | 必需 | 缺 → 停；粒级决定式与筛孔 |
| 加荷速率或转动次数 | 数值 | 必需 | 缺 → 停（速率与转数是口径的一半） |
| 筛制与筛孔（方孔／圆孔，几个毫米） | 枚举 | 必需 | 缺 → 停；三家筛孔不同 |
| 平行次数与两次之差 | 数值对 | 必需 | 缺 → 无法判有效性（停判点 4） |
| 石料抗压的饱水记录（真空度、保持时间、水中时间、浸水时间） | 五元组 | 条件必需 | 走抗压时必需；缺 → 结论降级为"未饱水" |
| 层理方向 | 枚举 | 条件必需 | 有层理岩石必需；缺 → 只能报"未分方向" |

**步骤**

1. **分家**：先按料的去向定"哪一家"，再定量名（I.1）。
2. **对口径**：把荷载、筛孔、粒级、次数逐项与 I.1 的行对齐；任一项对不上即停。
3. **定分子**：确认式子里的分子是"损失"还是"通过"（I.2）。
4. **查有效性**：按家取平行差阈值；超了重做，不取平均（I.3）。
5. **抗压的饱水**：真空度、保持时间、水中时间、浸水时间、水面高差五项写全；缺一项即降档（卡头第 4 条之外的另一处）。
6. **层理**：有层理者两方向各一组，先各自平均，再两方向平均（I.3 第 1 条）。
7. **核限值来源**：若要判合格，写明限值出自哪张表、方向是"≤"还是"≥"（I.5）。
8. **加声明**：两条必备声明（B 段 H2 第 1、2 条）。

**停判点**（命中任一条即停，不再往后走）

1. 只写"压碎值"、未定料的去向 → 停（I.1）。

## B — 边界

### H1 — 出现下列情形就别用本卡

1. **把三家压碎量当同一个指标。** 荷载、筛孔、分子方向三处都不同（I.1、I.2）。
2. **用式 9-18 的减法形式算沥青粗集料。** 得到的是补数（I.2）。
3. **按 p283 的机器规格声称"设备满足"。** 量级差一千倍（I.4）。
4. **把 2% 与 1% 两个平行差阈值互换。** 一个洛杉矶、一个狄法尔（I.3）。
5. **拿表 1-16 的"≥"直接判合格。** 方向印反，会把不合格判成合格（I.5）。
6. **把磨耗率与压碎值排在一张表里比大小。** 不同物，不可排序。
7. **未饱水的石料抗压当饱水强度报。** 饱水程序是这一项定义的一部分（R 段、卡头）。
8. **用本卡的压碎值去推第一章的强度等级。** 压碎是间接推测，不是强度本身（R 段原话即"间接地推测"）。
9. **把三种受压钢模的尺寸当已知。** 图 9-5／9-6／9-7 无内容（卡头第 5 条）。

### H2 — 用前必须声明

1. 本卡的量属**试验篇的口径**：石料本体为五十毫米饱水试件、每秒零点五到一兆帕；磨耗为两法各自的转数与筛孔；三种压碎各按自己的荷载与筛孔。离开口径，同名量不是同一个量。
2. 平行差、试件高度、末层超出量都是**有效性判据**，不是合格线。本篇只有一条真合格线（安定性 C−A ≤ 5.0 mm），与本卡无关。
3. 书里的单位量级误记（p283 的牛、p295–296 的分／秒）**按登记处理**，卡片不替书改值；引用该处必须注"须核原图"。
4. 表 1-16 的方向须按"≤"读，引用时要写明"原书印反"。
5. 本卡不回答"这块石料能不能用"；要判合格，回第一章的门槛表。
