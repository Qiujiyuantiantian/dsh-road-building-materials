# K8 乳化沥青：代号两维、九项指标、三张判据表

> 挂载 verified：p15、p16（2 条）
> 背景 reference：f14、p14（不单独支撑动作，只作口径与读法）
> 审查清单：ce-B33、ce-B34（B 类书伤，作停判依据）
> 互引：K3｜K9
> 一句话：代号是「用途×离子型」拼出来的，门槛绑在代号上；九项指标都能做，但判据表的两个列头印成同一个词，破乳分级只在两组矿料内成立。

## R 原文论点

p73–83 是三个材料分支里的第二支，也是全章唯一「材料＋工艺」并重的一节：前面讲怎么把沥青分散进水里，后面讲怎么判这支乳液合不合格。

**代号两维（p80–81）。** 前一位是用途：P 是喷洒型，B 是拌和型。后一位是离子型：C 阳离子、A 阴离子、N 非离子。末位是序号。改性乳液另用一套（PCR／BCR），判据在另一张表。两维定代号，门槛绑代号走——同一试验项目在不同代号下门槛不同，蒸发残留物含量就有两个值并存（50 与 55）〔数值待核原图：表 2-16 两列、质量百分数〕。

**九项指标（p79–80）。** 筛上剩余量（过 1.18mm 筛）、蒸发残留物含量与残留物性质（针入度、延度、软化点）、粘度（恩格拉 E25 或标准粘度 C25,3，二选一）、粘附性、储存稳定性（5d 与 1d）、低温储存稳定性（−5℃ 放 30min、25℃ 放 10min、循环两次）、微粒电荷（6V 直流 3min）、破乳速度、水泥拌和与矿料拌和试验。

**两套粘附试法（p79–80，p16）。** 阳离子型：石料先浸水、再浸乳液、空气中放、水中摆洗，看裹覆面积。阴离子型：规定粒径的碎石称量、排于筛上、浸乳液、室温放一天、温水浸，再看裹覆。两套的粒径、温度、时长全不同，只有「裹覆面积占比」这一个共同出口。不可互换。

**破乳分级只在两组矿料内成立（p80，p15）。** 表 2-15 把乳液与「A 组矿料」和「B 组矿料」分别拌和，按裹覆均匀程度分快裂、中裂、慢裂。换矿料即失效——破乳是乳液与矿料表面的相互作用，不是乳液单独的属性。表里慢裂那一行的 A 组是空的：A 组矿料下没有慢裂这一档的结果，不能说「它在 A 组也是慢裂」。

**两张判据表的伤（p81–82，ce-B33／B34）。** 表 2-16 的表头把阳离子列与阴离子列印成同一个词，PC 与 PA 两列靠列头分不开，只能靠代号里的字母反推；行题字序被打乱，一处延度用了百分号（延度是长度），还有两行各重复出现一次。表 2-17 是改性乳液，两个行题被拆进上下两格，值挂在哪一行要靠猜。

**HLB 只有一个方向。** p77 讲亲水亲油平衡值：数越小越偏亲油，数越大越偏亲水，给了几个标定点与两段区间；但乳化剂配比怎么算，本章没有给公式。

## I 判据骨架

| 维度 | 取值 | 怎么读 |
|---|---|---|
| 用途位 | P 喷洒／B 拌和 | 决定用在透层、粘层、表面处治，还是拌和类路面 |
| 离子型位 | C 阳／A 阴／N 非离子 | 决定用哪套粘附试法与哪一列判据 |
| 序号 | 同一用途同一离子型下的第几档 | 门槛随序号变 |

九项指标与判据归属：

| 指标 | 试法要点 | 判据在哪 | 能不能判 |
|---|---|---|---|
| 筛上剩余量 | 过 1.18mm 筛 | 表 2-16 一行 | 能 |
| 蒸发残留物含量 | 脱水称量 | 表 2-16，绑代号 | 能，但两值并存要认代号 |
| 残留物性质 | 针入度、延度、软化点 | 表 2-16 数行 | 部分；延度单位印错 |
| 粘度 | 恩格拉或标准粘度计，二选一 | 表 2-16 两行 | 能，但两套口径要先选 |
| 粘附性 | 阳离子／阴离子两套 | 表 2-16 一行 | 能，须带试法 |
| 储存稳定性 | 5d 与 1d | 表 2-16 两行 | 能 |
| 低温储存稳定性 | −5℃ 循环两次后过筛 | 表 2-16 | 能 |
| 微粒电荷 | 6V、3min | 表 2-16 | 能（定离子型） |
| 破乳速度 | 与 A／B 组矿料拌和 | 表 2-15 | 只在两组矿料内 |

骨架不引式体〔公式待核〕：这一节只有一张界面能公式，属定性引用，判据不靠它。

## A1 演练

**【合成演练，非书中案例】**

一份乳液报告写着某个代号，粘附性一栏填了「裹覆面积达标」，问能不能判合格。这一段只走问答。

第一问，拆代号。前一位是用途、后一位是离子型？拆错就查错列。答不出即停。

第二问，试法。粘附性用的是哪一套？阳离子与阴离子两套的粒径、温度、时长都不同，报告没写试法，这个数就不可判。

第三问，那一列能不能读。判据表的列头两个印成同一个词，PC 与 PA 分不开；只能靠代号里的字母反推，反推不出即停。

第四问，破乳速度。判的是哪一组矿料下的结果？表里慢裂那一行的 A 组是空的，若来人说「A 组也慢裂」，直接驳回。

第五问，粘度。恩格拉度还是标准粘度计的秒？两者二选一，不许两个都用、也不许互换。

第六问，延度那一栏。单位印成了百分号，而延度是长度；这一格只能标停，等原图。

第七问，HLB。来人问「HLB 多少配比合适」。本章只给方向，没有公式，配比算不出来。

## A2 触发场景

- 「这支乳液是 PC 还是 PA，怎么分？」
- 「粘附性达标了，用的是哪套试法？」
- 「慢裂型在 A 组矿料下是什么表现？」（表里没有）
- 「粘度用恩格拉度还是标准粘度计？」
- 「改性乳液（PCR）的判据在哪张表？」
- 「HLB 能不能算出乳化剂用量？」（不能，本章无式）

## E 执行步骤

**输入契约（要用户提供）**：①乳液代号或「用途＋离子型」；②每一项指标的读数与试法；③破乳试验用的是哪组矿料；④是否改性乳液；⑤出处印刷页。

1. 拆代号：用途位、离子型位、序号。
2. 定表：普通乳液查表 2-16，改性乳液查表 2-17。
3. 定列：先按代号里的字母定位，不按列头文字定位（列头坏了）。
4. 定试法：粘附性问清阳离子还是阴离子；粘度问清恩格拉还是标准粘度计。
5. 破乳：确认矿料组别，A 组为空的行不许外推。
6. 出口：代号、列、试法、结论；任一项缺，只写「不可判」。

**【停判点】**出现下列任一情形必须停下：

- 按列头文字区分 PC 与 PA → 停（列头重字，ce-B33）。
- 把阳离子与阴离子的粘附试法互换 → 停（p16）。
- 把慢裂在 A 组矿料下也说成慢裂 → 停（表 2-15 该格为空，p15）。
- 把延度那一格按百分数读 → 停（单位错）。
- 两种粘度口径混用或互换 → 停（二选一）。
- 要求用 HLB 算乳化剂配比 → 停（本章只有方向）。
- 改性乳液套普通乳液的判据表 → 停（表 2-17 另立）。

## B 边界

**H1 硬边界（不适用）**：靠列头分阴阳离子；两套粘附试法互换；把空的矿料组读成有结论；把长度当百分数；两套粘度口径互换；替书补乳化剂配方；把破乳分级推广到任意矿料。

**H2 软边界（降级使用）**：表 2-16 的行题字序被打乱、两行重复，逐列判读前要停一次；表 2-17 的两个行题被拆进两格，值挂哪一行只能靠猜——这两处都不影响「九项指标能测」这个结论，只影响「测出来往哪一格填」。HLB 只作方向标，不作计算量。
