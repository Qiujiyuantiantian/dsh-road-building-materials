# K4 PG：只能命名，不能判

> 挂载 verified：无（0 条）
> 背景 reference：f12（不单独支撑动作，只作口径与读法）
> 审查清单：ce-B01、ce-B02、ce-B03、ce-B04（B 类书伤，作停判依据）

> 一句话：本章交得出 PG 的命名规则与两条设计温度公式，交不出任何一条判据阈值——承载阈值的那张表在源文里已经损坏，这不是没找到，是不存在。

## R 原文论点

p64–67 这一节给的是 PG 的**命名规则**与**两条设计温度公式**，不是判据。先把能做的三件事写清，再说做不到的那一件。

**命名（p64）。** 等级写作 PG 加两个脚标。前一个脚标是路面设计的最高温度，书把它定义成七天平均的最高**路面**温度，不是气温；后一个是最低设计温度，取年极端最低。书给了一个读法：PG58-28 表示这一档适用的地区，路面设计的最高温度不超过 58℃、最低不低于 −28℃〔数值待核原图：等级名读法、℃、路面温度而非气温〕。

**两档温度怎么排（p64）。** 高温一侧从 52 到 82℃，每 6℃ 一档；低温一侧从 −10 到 −46℃，每 −6℃ 一档〔数值待核原图：档位边界、℃、路面设计温度〕。同一页正文说高温有七个等级，可按它自己给的区间与级差展开只有六档；表 2-8 的表头又印着从 PG46 起、52 缺席的六列（ce-B04）。三处互不吻合，本卡并列，不改。

**两条公式（p67）。** 式 2-33〔公式待核〕把七天平均最高气温与地理纬度，换成一个规定深度处的路面高温设计值；式 2-34〔公式待核〕把平均年最低气温线性换成路面低温设计值。两条都是「气温＋地理」入口，出口是温度，不是等级，也不是合格与否。

**这里真的没有数——四件可当场核的事。** 本章给出了 PG 的命名规则与上面两条公式，但没有给出任何一条 PG 判据阈值。承载阈值的那张表在源文里已经损坏。不是「我没翻到」，也不是「作者省略了」，是四件可以自己数一遍的事：

1. **表 2-8（p66）只剩三行表体，其中一格塌成 4,590 字符的乱码**，`-34~40` 在这一格里重复 163 次，整行长度 4,609（ce-B01）。正常表格不可能长成这样，所以它不是「有些格子没印清」，是整块不可读。
2. **等级清单表在本源文里不存在（ce-B02）。** p64 正文句末写「见表 2-7」，翻到 p65，那个位置印的却是道路用液体石油沥青的表，两张表内容毫无交集。原书显然有那张清单，转录把它丢了——书自己引用了它，这是最硬的一条证据。
3. **表 2-8 的表头本身就不是一张完整档位表（ce-B04）。** 六列表头里 46 低于正文给的下限，52 反而缺席；正文说七个高温等级，表头只给六列。三处数对不上，说明这条表在转录里已经被压扁。
4. **组合指标连名字都没有。** 全章检索 `sin`、车辙因子、疲劳因子，命中都是 0；`G*` 只有五处，全是「这是什么」的解释（p60 的定义段、p62 的正文、式 2-31 与小结）。DSR 那一节讲到 G* 与 δ 的定义就停住了。

一句话：命名与两条公式是完整的，档位清单与判据阈值是缺的；缺的方式是「整表损坏＋整表被顶替」，不是「某一格可疑」。这个区别决定了本卡只能给命名，不能给判。

## I 判据骨架

骨架式（只用输入—输出关系，不用任何数值）：

- 式 2-33〔公式待核〕：输入七天平均最高气温与地理纬度；输出某个规定深度处的路面高温设计值。
- 式 2-34〔公式待核〕：输入平均年最低气温；输出路面低温设计值。

判据项清单——只列阶段、试验、各判一个量，**不列限值**：

| 阶段 | 试验 | 判哪一个量 | 限值 |
|---|---|---|---|
| 原样沥青 | DSR | 复数剪切模量 G\* 与相位角 δ | 本源文里取不到 |
| RTFOT 残留 | DSR | 同上 | 本源文里取不到 |
| PAV 残留 | DSR | 同上 | 本源文里取不到 |
| PAV 残留 | BBR | 蠕变劲度 S 与斜率 m | 本源文里取不到 |
| PAV 残留 | DTT | 应力 σ 与破坏应变 ε | 本源文里取不到 |

这张清单的骨架来自表 2-8 的表头：列是阶段（原样、RTFOT 后、PAV 后），行是项目，格里是限值。表头这六个列名与「原样／RTFOT／PAV」三个阶段是本源文里唯一还读得出来的东西；**行与格已经毁了**，所以这张表只能列到「判哪个量」，列不到「多少算合格」。

两档的构造也只到档位边界：高温一侧的边界与低温一侧的边界都写在这里，但**每档对应的限值一栏是空的**——不是本卡留白，是源文里那一栏不存在。

## A1 演练

**【合成演练，非书中案例】**

某地要选 PG 档。来人给三个输入：七天平均最高气温、当地纬度、平均年最低气温，问「该选哪一档，这支沥青合不合格」。

第一步，认入口。两个脚标是**路面**温度，不是气温；手上有气温，先走式 2-33 与式 2-34〔公式待核〕。三个输入缺任一个即停：纬度只服务高温那一式，缺了它高温一极算不出来，低温那一式又不需要它。

第二步，认口径。式 2-33 出来的是某个规定深度处的最高温度，而命名规则里前一个脚标说的是七天平均最高路面温度。「深度」与「平均」是两层口径，本卡不替书裁定两者相等，只让来人把这一点写进结论。

第三步，落到档。把两个温度各自去比档位边界，选出靠近的一档，拼成等级名。**到这一步本卡不给任何档位，也不给任何数**：档位清单表在本源文里不存在，表 2-8 的表头又只留六列且首档越界，两处都不足以当「档位表」用。

第四步，问合格。来人接着问「那这支沥青按这个等级合不合格」。停——判据值一条也取不到，本章没有这个能力。要判，得另找规范原文；本卡不给替代路径，也不给「一般取多少」。

第五步，换体系。来人又说「我们手上只有标号，能不能换算成 PG」。停，转 K9：本章四条证据都说不能换，唯一接口是气候，而那条链上不出现任何沥青指标。

## E 执行步骤

**输入契约（要用户提供）**：①要的是命名、算温度，还是判合格；②若是命名，给等级名；③若是算温度，给七天平均最高气温、当地纬度、平均年最低气温；④若涉及判合格，先问一句「依据哪份文件」。

1. **第一句就停。** 只要问题里出现「合不合格」「达不达标」「限值多少」，先答这一句：表 2-8 在源文里不可读（单格 4,590 字符），任何 PG 门槛取不到，不得外接。到此为止，不往下走。
2. 若只要命名：读出两个脚标各指什么温度，各是「不超过」还是「不低于」，并说明这是路面温度而不是气温。
3. 若只要由气候算温度：两式代入，输出两个温度；同时声明本章没有一处气候算例、档位清单表不存在，算出的温度无处落档。
4. 若问档位有几个：把「正文说七个」与「区间加级差只有六个」与「表头六列、首档越界」三说并列，不选边。
5. 若问两套体系：只写并置与不可互换，把那四条证据页交给 K9（p51、p54、p62–66、p64–67）。

**【停判点】**出现下列任一情形必须停下：

- 要求任何一条 PG 门槛值（含 DSR／BBR／DTT 的限值）→ 第一句就停，不外接。
- 要求「按经验取一个常用等级」或「一般取 PG 多少」→ 停。
- 要求把针入度标号换成 PG，或把 PG 换回标号 → 停（转 K9 的四条证据）。
- 要求补上车辙因子或任何 G\* 的组合指标 → 停（全章零命中）。
- 引「七个高温等级」而不提六档之争 → 停（书内两说，须并列）。
- 拿表 2-8 的表头当档位清单用 → 停（46 越界、52 缺席）。
- 要求把式 2-33 的输出直接当脚标里的那个温度 → 停（深度与平均两层口径）。

## B 边界

**H1 硬边界（不适用）**：`G*/sinδ` 与 `G*·sinδ` 在本源文里出现 0 次（`sin`、车辙因子、疲劳因子均 0 命中），**不得代补**——这个词在文献里太常见，不写死，下一个用卡的人一定会顺手填上，而那正是本章最容易被「记忆编造」污染的一格。表 2-8 的任何格子不得凭记忆或凭外部规范填；不得引任何外部 PG 表；不得把式 2-33 的输出直接当脚标；不得把「PG 判不了」写成「本章质量差」。

**H2 软边界（降级使用）**：高温档数在本章有两说（正文说七个，区间与级差展开是六个，表头六列且首档越界），引用时三说并列；表 2-8 的表头六个列名可以当「有三个阶段」的旁证，但不能当档位清单。**这一节的真相是：命名与两条设计温度公式完整，档位清单与判据阈值缺失，缺失的形态是整表损坏与整表被顶替。** 这是源文状态，不是作者偷懒——书里 p64 明明引用了那张清单表，说明原书有它，是转录丢了它。
