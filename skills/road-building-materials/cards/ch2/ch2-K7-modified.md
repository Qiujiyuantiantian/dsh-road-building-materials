# K7 改性沥青：类×级与四项专用试验

> 挂载 verified：p12、p13、ce-A06、ce-A11（4 条）
> 背景 reference：f13、p10（不单独支撑动作，只作口径与读法）
> 审查清单：ce-B26、ce-B27、ce-B28（B 类书伤，作停判依据）
> 互引：K2｜K3｜K5｜K9
> 一句话：改性沥青按改性剂定类、按级定位，四项专用试验都能照做；但判据表属第三份文件，且「级按什么分」书里给了两句话。

## R 原文论点

p67–72 是三个材料分支里的第一支。它的结构是：先按改性剂分类，再补四项基质沥青没有的试验，最后落一张判据表；表后面跟三张单点试验结果。

**类与级（p69）。** 类按改性剂走：I 是 SBS，II 是 SBR，III 是 EVA 或 PE。级是 A 到 D，方向是针入度变小、软化点变高，也就是高温性能上去、低温性能下来——所以 A 级最软，不是「最好」。级按什么分，书给了两句互斥的话：一句说按软化点高低分四级，另一句说等级划分以针入度为主要依据（p10，reference；ce-B28）。表 2-9 里这两列恰好同向变化，所以在这张表上两种读法不冲突，但定义量没有定论——引用时两句都要写。

**四项专用试验（p68–69）。** 离析：163℃ 静置 48h，取上下两段测环球法软化点，看差值；PE／EVA 类改看高温存放后有没有结皮凝聚。弹性恢复：延度件拉伸后剪断、保持一小时、量恢复率（判据表把它记作 25℃ 的指标，试验段本身没写温度）。粘韧性：25℃、500mm/min 拉伸，荷重—变形曲线下面两块面积分别是粘韧性与韧性。测力延度：5℃、5cm/min，记录拉力—变形曲线。

**判据表（p69，表 2-9）。** 属 JTJ 036—98，与表 2-5、表 2-6 不是一条线（ce-A11）。表里 SBS 类四项齐全，SBR 与 EVA／PE 类多列是空的。两处条件与单位错：针入度一行的括注末字写成了质量；135℃ 那一行标的是运动粘度、单位却印成动力粘度的（ce-B27）。所以第三类那一列的门槛连单位都不可依。

**三张单点表（p70–72）。** 表 2-10 是 5% 掺量下星形与线形 SBS 的对比；表 2-11 是 SBR 四个掺量的梯度；表 2-12 是 EVA 三个牌号加 PE、SBR 的横向对比。三张表各只有一个基质沥青、一个或几个掺量，只能读趋势（p13）。书在表 2-12 的评述里把三种改性剂的偏科并列写出来：PE 提粘最多而低温延度还不如基质，SBR 提粘有限而低温延度改善很大，EVA 居中且随两个牌号参数变——三句合起来就是「没有全能选手」（ce-A06）。所以按单一指标排名次，必然自相矛盾。

**同一性能两个口径（p12）。** 表 2-9 判的是 25℃ 的弹性恢复，给的是下限；表 2-10 记的是 15℃ 的回弹率，是单点读数、没有判据。两个名、两个温度，不可互比（ce-B26：不是「同名」，是同一性能的两个口径）。

## A1 演练

**【合成演练，非书中案例】**

来人拿一份改性沥青的单点试验报告，说「回弹率这么高，弹性恢复肯定达标」。这一段只走问答。

第一问，名与温度。报告上那个数是什么温度下测的？判据表那一列是什么温度？两个名不同、两个温度不同，就不是同一个量；即便数看着漂亮，也不能对上判据。

第二问，类与级。这是哪一类、哪一级？判据是按类和级给的，不是按项目给的；类答不出、级答不出，就无法定位到哪一列。

第三问，那张表的列全不全。SBR 与 EVA 类在判据表里多列是空的，先问一句「这一列有值吗」；没有值就是「本章未给」，不是「不限」。

第四问，单点能不能排序。来人说「星形比线形好」，依据是一组同掺量的对比。按 p13 只能读趋势：一个掺量、一种基质，排不出改性剂的优劣；再说三种改性剂各有偏科，换个指标排名次就翻过来。

第五问，能不能用基质沥青的表判。改性之后针入度普遍掉一大截，拿基质的针入度区间去卡，合格品也会判成不合格。

第六问，单位。判据表里有一行标着运动粘度、单位却印成动力粘度，去问来人「这个数是什么单位测的」，答不出即停。

## E 执行步骤

**输入契约（要用户提供）**：①改性剂类型（定类）；②等级或针入度与软化点（定级）；③四项试验各自的读数与条件（温度、速率、时长）；④这个数准备对哪张表的哪一列；⑤单位。

1. 定类：按改性剂归入 I／II／III。
2. 定级：先看针入度，再看软化点；两句定义都写上，不选边。
3. 认表：改性沥青只查表 2-9（改性乳液转 K8），不许用表 2-5 或表 2-6。
4. 认列：这一列在这一类下有值吗？空的就写「本章未给」。
5. 认口径：弹性恢复看 25℃，回弹率看 15℃，两者不互比。
6. 读趋势：单点表只给方向，不给排名；结论要带掺量与基质沥青。

**【停判点】**出现下列任一情形必须停下：

- 拿基质沥青的表判改性沥青（或反过来）→ 停（ce-A11）。
- 把 15℃ 的回弹率对 25℃ 的弹性恢复下限 → 停（p12、ce-B26）。
- 按单一指标给改性剂排名次 → 停（ce-A06、p13）。
- 把表 2-9 的空列读成「不限」→ 停。
- 忽略表 2-9 那两处单位错，直接引用第三类的门槛 → 停（ce-B27）。
- 把「级」当质量等级（A 最好）→ 停（A 级最软）。
- 要求「级到底按什么分」给唯一答案 → 停（两句并存，ce-B28）。

## B 边界

**H1 硬边界（不适用）**：跨规范串判据；跨类比较「级」；把两个温度的回弹口径互比；替表 2-9 补空列；用单点试验给改性剂排序；把「本章未给」写成「不限」。

**H2 软边界（降级使用）**：级的定义量两说并存，本卡只要求两句都写、不替书裁决；「星形优于线形」在本章只有 5% 一个掺量、一种基质沥青作证据，引用时必须带这两个限定；三张单点表能读方向，读不出优劣。
