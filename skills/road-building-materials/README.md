# road-building-materials

《道路建筑材料》（第四版）的 60 张能力卡。

## 一句话

**一本指标口径手册。** 它回答的不是"这个材料合不合格"，而是"**这个数在什么条件下才成立**"。

## 为什么值得单独做一本

这本书是教材，不是规范。它的价值不在给参数，在**把条件写清楚了**——
所以才能被复算，才能发现它自己错在哪。

60 张卡里：

| 项 | 数 |
|---|---|
| 卡 | 60 张 |
| 停判点 | 400+ 条（每卡平均 7 条） |
| **照抄就错的方向性错误** | **3 处**（表 1-16、式 3-5、表 3-9） |
| **书里有算例但算不通** | 5 个（例题 1-3、3-2、5-4，例 6-1 半截） |
| **能算出数的闭合链** | 全书 42 条试验链里 40 条一步闭合，但只有 **1 条真合格线** |
| **OCR 编造** | 2 处（图 3-19/3-20、图 6-2） |

## 三处「照抄就错」（一为书误，二为转录陷阱）

| 位置 | 书上印的 | 应读作 | 后果 |
|---|---|---|---|
| 表 1-16（p38） | 压碎值 **≥** 26/30/35/40 | **≤** | 把不合格料判成合格 |
| 式 3-5（p97） | 按式面算 TSR | 符号与数值方向相反 | 强度比算成 150% |
| 表 3-9（p93） | 坚固性 **≥** 12 | **≤** 12 | 同上 |

表 1-16 有**章节内部自证**：p40 填隙碎石对同一指标写"不大于"，基层 26%、底基层 30%，数值完全相同。

## 每张卡六段

`R` 转述+页码 → `I` 判据骨架 → `A1` 合成演练（0 个数值结果）→ `A2` 触发场景 → `E` 步骤+**停判点** → `B` 硬边界

## 页码

**印刷页 = PDF 页锚 − 24**（12 个章首交叉验证一致）。卡里的页码可直接翻书核对。

## 试验篇的特殊位置

它补上了前八章的**口径**缺口，但没补**合格线**：

- ✅ 补上：ch4 的三件（一组几条 / 受压面积 / 代表值）、ch6 的两件（试件尺寸 / 养生温度）、ch5 的坍落度与维勃
- ❌ 没补：ch1 的抗冻与矿渣活性、ch2 的 PG 判据、ch3 的 SMA 与 VA/VMA/VFA、ch5 的含气量

**35 个试验，真正的合格线只有 1 条**（水泥安定性 C−A≤5.0mm）。

## 来源与限制

源文是扫描件（零文字层），本次用 Qwen3-VL 重新 OCR：365/365 页、0 错误、248,139 汉字。

**已知限制**（每条都在卡里标了）：

- **图全部不可用**——只有图注，没有图内容

- **公式未与原版面图逐字核对**——一律〔公式待核〕
